Дискриминант

Одно число, которое заранее говорит, сколько корней у квадратного уравнения — ещё до того, как мы начнём их искать.

Формула дискриминанта

D = b2 − 4ac

a, b, c — коэффициенты уравнения a·x² + b·x + c = 0

Зачем он нужен

Дискриминант — это «разведчик»

Слово «дискриминант» значит «различающий». Он различает три ситуации: у уравнения будет два корня, один или ни одного.

Главное заблуждение: «раз уравнение квадратное — значит, корня всегда два». Это не так. Подставил три числа, посчитал одно выражение — и сразу ясно, чего ждать. Не нужно гадать и подбирать.

Что вспомнить с прошлого шага

Уравнение сначала приводим к виду a·x² + b·x + c = 0.

a — число при x², b — при x, c — свободное число.

Коэффициенты берём вместе со знаком: если стоит −7x, то b = −7.

Три случая — вся суть темы

Смотрим на знак D

Посчитали D — и по его знаку сразу называем число корней:

D > 0
Два корня
Парабола пересекает ось в двух точках.
D = 0
Один корень
Парабола касается оси в одной точке.
D < 0
Нет корней
Парабола не достаёт до оси.

Запомни как считалочку: плюс — два, ноль — один, минус — ни одного.

Каждый случай на живых уравнениях

Считаем D и смотрим на знак

По два примера на каждый случай — посчитай D сам и сверься:

D > 0 · два корня
x² − 7x + 10 = 0
D = (−7)² − 4·1·10 = 49 − 40 = 9
2x² + 5x − 3 = 0
D = 5² − 4·2·(−3) = 25 + 24 = 49
D = 0 · один корень
x² + 4x + 4 = 0
D = 4² − 4·1·4 = 16 − 16 = 0
9x² + 6x + 1 = 0
D = 6² − 4·9·1 = 36 − 36 = 0
D < 0 · нет корней
x² + 2x + 5 = 0
D = 2² − 4·1·5 = 4 − 20 = −16
3x² − 2x + 5 = 0
D = (−2)² − 4·3·5 = 4 − 60 = −56

Одно семейство, меняем только последнее число (c) — а a = 1, b = −6 держим теми же. Смотри, как D «съезжает» через ноль:

x² − 6x + 5 D = 36 − 20 = 16 D > 0 · два
x² − 6x + 9 D = 36 − 36 = 0 D = 0 · один
x² − 6x + 13 D = 36 − 52 = −16 D < 0 · нет

Чем больше свободный член, тем меньше D — и в какой-то момент корни пропадают. Вот эту границу дискриминант и ловит.

Покрути сам · интерактив

D и парабола — это одно и то же

Двигай ползунки a, b, c и смотри: корни уравнения — это точки, где парабола пересекает ось. Дискриминант заранее говорит, сколько таких точек будет.

D = 25 > 0 · два корня

y = x² − 7x + 3

Поймай момент, когда парабола только касается оси — это и есть D = 0, граница между «два корня» и «ни одного». (При a = 0 это уже не парабола, а прямая — потому дискриминант и требует a ≠ 0.)

Разбираем вместе

Эталонный пример

2x² − 7x + 3 = 0  →  сколько корней?

  1. Выписываем коэффициенты со знаками: a = 2, b = −7, c = 3.
  2. Возводим b в квадрат: (−7)² = 49. Квадрат минуса — плюс, поэтому 49, а не −49.
  3. Считаем 4ac: 4 · 2 · 3 = 24.
  4. Дискриминант: D = 49 − 24 = 25.
D = 25 > 0 → у уравнения два корня.

Теперь ты · нажми, чтобы проверить

Мини-практика

x² − 5x + 6 = 0применение
a=1, b=−5, c=6;  D = 25 − 24 = 1 > 0 → два корня.
4x² + 4x + 1 = 0применение
a=4, b=4, c=1;  D = 16 − 16 = 0 → один корень.
x² + x + 1 = 0применение
a=1, b=1, c=1;  D = 1 − 4 = −3 < 0 → корней нет.
Найди ошибку: x² − 3x − 4 = 0анализ
Ученик написал D = (−3)² − 4·1·(−4) = 9 − 16 = −7. Ошибка в знаке: −4·1·(−4) = +16, значит D = 9 + 16 = 25 → два корня.

Тренажёр · бесконечная практика

Реши квадратное уравнение сам

Нажми «Новое уравнение» и реши его через дискриминант. Введи корни через точку с запятой (дробные — с точкой), или напиши «нет», если корней нет. Потом проверь себя или посмотри пошаговое решение.

2x² − 7x + 3 = 0

Где чаще всего ошибаются

Лови эти три ловушки

  • Теряют знак у b. Если b = −7, то b² = 49, а не −49. Квадрат любого числа неотрицателен.
  • Думают, что при D = 0 корней нет. При D = 0 корень есть — один. «Ноль корней» — это только при D < 0.
  • Забывают возвести b в квадрат. В формуле именно b², а не b. Проверяй, что у b стоит степень.

Что дальше

Дискриминант — это половина пути. Когда знаем, что корни есть, находим их по формуле:

x = (−b ± √D) / (2a)

Тот же D, только теперь из-под корня — и знак ± даёт сразу два корня.

Проверка на выходе: запиши формулу D по памяти · сколько корней при D = 0? · назови a, b, c в 2x² − x − 6 = 0.
