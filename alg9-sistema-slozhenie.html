Метод сложения

Домножаем уравнения так, чтобы при одной переменной оказались противоположные коэффициенты — складываем, и переменная исчезает. От системы остаётся одно простое уравнение.

Идея метода

{
3x + 2y = 16
5x − 2y = 8
складываем почленно ↓   2y + (−2y) = 0
8x = 24  →  x = 3

Переменная y пропала — осталось уравнение с одним неизвестным. Дальше находим x, потом y.

Зачем это нужно · когда сложение удобнее

Самый быстрый инструмент для линейных систем

Система двух уравнений — это язык задач, где две неизвестные величины связаны сразу двумя условиями: «два взрослых и один детский билет стоят столько-то, а один взрослый и три детских — столько-то», «лодка по течению и против», «сплав двух металлов». Способ сложения решает такие системы быстрее всего, когда коэффициенты при переменной удобно «обнулить».

«Способ подстановки и способ сложения дают разные ответы?»

Нет. Метод решения свободный — ответ у правильной системы один и тот же. Просто подстановка часто ведёт к дробям: выразишь x = (…)/5 — и дальше воюешь со знаменателями. А сложение позволяет убрать переменную без деления, целыми числами. Поэтому там, где коэффициенты «просятся» (например +2y и −2y), сложение короче.

Ещё это точка пересечения двух прямых: каждое уравнение — прямая на плоскости, а пара (x; y), где они встречаются, и есть решение системы. Сложение находит эту точку алгеброй, без чертежа.

Что вспомнить перед стартом

Линейные системы и метод подстановки. Ты уже решал системы, выражая переменную и подставляя. Сложение — второй способ для тех же линейных систем; ответ — по-прежнему пара чисел (x; y).

Равносильные преобразования. Если умножить всё уравнение (обе части!) на число, не равное нулю, — получится равносильное уравнение с теми же корнями. Именно поэтому уравнения можно «домножать», подгоняя коэффициенты.

Сложение равенств. Если в каждом уравнении левая часть равна правой, то и сумма левых частей равна сумме правых. Складывать два верных равенства — законная операция.

Ядро — весь метод в четырёх шагах

Алгоритм способа сложения

Дана система из двух линейных уравнений, приведённых к виду ax + by = c (переменные слева, числа справа):

{a₁x + b₁y = c₁a₂x + b₂y = c₂

Как решаем

  1. Уравняй коэффициенты. Домножь уравнения на числа так, чтобы при одной переменной коэффициенты стали противоположными (равны по модулю, разного знака), например b₁ и −b₁.
  2. Сложи уравнения почленно (левую с левой, правую с правой). Выбранная переменная исключается — остаётся уравнение с одним неизвестным.
  3. Реши это уравнение — найди первую переменную.
  4. Подставь её в любое исходное уравнение и найди вторую. Запиши ответ парой (x; y).

Если коэффициенты при переменной уже одинаковы (оба +), уравнения не складывают, а вычитают — тогда переменная тоже уйдёт. Считалочка:

Противоположные — складываем, одинаковые — вычитаем, разные — сперва уравниваем.

Эталонный пример с домножением

Держи в голове цвет-код действий — на каждом шаге понятно, что именно ты делаешь:

уравнять коэффициенты сложить — исключить решить уравнение найти вторую

{2x + 3y = 134x − y = 5

  1. Уравниваю коэффициенты. Выгодно исключить y: в первом при нём +3, во втором −1. Домножу второе уравнение на 3 — всё, обе части: 4x − y = 5  |·3  →  12x − 3y = 15. Теперь при y стоят +3 и −3 — противоположны.
  2. Складываю почленно. (2x + 12x) + (3y − 3y) = 13 + 15. Столбец с y обнуляется — переменная ушла. Ради этого и выбирал множитель.
  3. Решаю. Осталось 14x = 28  →  x = 2.
  4. Нахожу y. Подставляю x = 2 во второе исходное: 4·2 − y = 5 → 8 − y = 5 → y = 3.
  5. Ответ: (2; 3).
Проверка в 1-м: 2·2 + 3·3 = 4 + 9 = 13 ✓

Как это выглядит · столбиком

Складываем «по столбцам»

Запиши уравнения одно под другим — x под x, y под y, числа справа. После домножения второй строки сложение делается по столбцам, как обычное сложение в столбик.

  2x + 3y = 13
+12x − 3y = 15  14x + 0 = 28

Столбец с y даёт ноль — переменная «ушла». Остаётся 14x = 28, дальше x = 2.

Сколько решений — и почему

Что покажет исключение переменной

Обычно после сложения остаётся нормальное уравнение и система имеет одно решение. Но иногда при исключении пропадают обе переменные — и тогда по тому, что осталось справа, видно, сколько у системы решений. Геометрически это положение двух прямых:

14x = 28
Одно решение
Осталось нормальное уравнение — прямые пересекаются в одной точке (x; y).
0 = 0
Бесконечно много
Ушли обе переменные, равенство верное — это одна и та же прямая (уравнения пропорциональны).
0 = 7
Решений нет
Ушли обе, а равенство неверное — прямые параллельны, общих точек нет.

Важно: 0·x = 0 — это не «x = 0», а «подходит любой x». А 0·x = 7 означает «нет такого x». Не дели на ноль.

Покрути сам · интерактив

Система — это две прямые

Каждое уравнение системы — прямая. Их точка пересечения и есть решение (x; y). Метод сложения находит ту же точку алгеброй. Нажми «Другая система» и посмотри, как меняются прямые и их общая точка.

А если прямые параллельны — точки пересечения нет, у системы нет решений. Если прямые совпадают — общих точек бесконечно много.

Тренажёр · бесконечная практика

Реши систему методом сложения

Нажми «Новая система» и реши её. Введи ответ в виде x; y (например 3; 2). Если решений нет — напиши «нет», если бесконечно много — «много». Потом проверь себя или посмотри пошаговое решение.

Иногда коэффициенты уже удобны, иногда нужно домножить одно или оба уравнения. Изредка попадаются краевые случаи — параллельные и совпадающие прямые.

Теперь ты · от простого к анализу

Практика по нарастанию

Коэффициенты при y равны +7 и −7. Сложить или вычесть?понимание
Сложить. Коэффициенты противоположны: 7y + (−7y) = 0 — переменная y уйдёт без всякого домножения.
В { x + y = 10; x − y = 4 } какую переменную выгодно исключить и как?понимание
Исключаем y: при нём +1 и −1 — противоположны, значит складываем без домножения. 2x = 14 → x = 7, тогда y = 3. Ответ (7; 3).
{ 7x + 2y = 19; 5x − 2y = 5 }применение
При y коэффициенты +2 и −2 → складываем: 12x = 24 → x = 2. Подставим в первое: 14 + 2y = 19 → 2y = 5 → y = 2,5. Ответ (2; 2,5).
{ 5x + 4y = 22; 3x − 2y = 0 }применение
Домножим второе на 2, чтобы при y были +4 и −4: 6x − 4y = 0. Складываем с первым: 11x = 22 → x = 2. Тогда 3·2 − 2y = 0 → y = 3. Ответ (2; 3).
{ 3x + 4y = 10; 2x + 5y = 9 } — оба коэффициента разныеприменение
Убираем x: домножим 1-е на 2, 2-е на 3 → 6x + 8y = 20 и 6x + 15y = 27. Коэффициенты при x одинаковы → вычитаем: −7y = −7 → y = 1. Тогда 3x + 4 = 10 → x = 2. Ответ (2; 1).
Какой множитель? В { 2x + 5y = 1; 3x + 4y = 10 } как исключить x?анализ
Наименьшее общее для 2 и 3 — это 6. Домножь 1-е на 3, 2-е на 2 → при x станет 6 и 6. Они одинаковы, поэтому уравнения нужно вычесть (или домножить одно на −1 и сложить). Так x исчезнет — вот и вся суть подбора множителя: гонишь коэффициенты к общему кратному.
Найди ошибку: из { 2x + 3y = 13; 2x − y = 5 } вычли и получили 2y = 8анализ
Ошибка в знаке. При вычитании знак меняется у каждого слагаемого второго уравнения: 3y − (−y) = 3y + y = 4y, а не 2y. Верно: 4y = 8 → y = 2, затем 2x − 2 = 5 → x = 3,5. Ответ (3,5; 2).
Что изменится? При сложении вышло 0 = 0. Сколько решений и как расположены прямые?анализ
Ушли обе переменные, и осталось верное равенство 0 = 0 — значит, второе уравнение было пропорционально первому, это одна и та же прямая. Решений бесконечно много: любая пара с первой прямой подходит.
Что изменится? А если после сложения получилось 0 = 7?анализ
Равенство неверное — ни один (x; y) не сделает 0 = 7. Прямые параллельны, общих точек нет: у системы нет решений. Это честный ответ, а не ошибка счёта.

Где чаще всего ошибаются

Лови эти ловушки

  • Домножают только одну часть уравнения. Множитель применяется к обеим частям и ко всем слагаемым сразу. Умножил левую на 3 — и число справа тоже на 3. Пиши «·3» над всем уравнением и проверяй каждый член, включая свободный.
  • Ошибаются в знаке при вычитании. Знак меняется у каждого слагаемого вычитаемого уравнения, включая число справа: 13 − 5, а не 13 + 5. Приём: замени вычитание на сложение — домножь второе уравнение на −1 и складывай.
  • Складывают, не уравняв коэффициенты. Если при переменной не одинаковые и не противоположные числа, ни одна переменная не исчезнет. Сначала посмотри на коэффициенты и домножь до общего кратного.
  • Пишут столбиком неровно. Складывают 3x с 2y. Выравнивай x под x, y под y — тогда каждый столбец складывается сам собой.
  • Останавливаются на одной переменной. Нашёл x — это ещё не ответ. Обязательно подставь и найди y, запиши парой (x; y).

Проверь себя · объясни своими словами

Три вопроса

  1. Что значит «исключить переменную» и какие коэффициенты для этого нужны?
  2. Когда уравнения складывают, а когда вычитают? Что делают, если коэффициенты разные?
  3. После исключения осталось 0 = 0 — сколько решений? А если 0 = 5?
Сверить ответыпроверка
1) Сделать так, чтобы при переменной оказались противоположные (или одинаковые) коэффициенты, и она пропала при сложении/вычитании.   2) Складывают при противоположных коэффициентах, вычитают при одинаковых; если разные — сперва домножают уравнения до общего кратного.   3) 0 = 0 → решений бесконечно много (прямые совпали); 0 = 5 → решений нет (прямые параллельны).

Что дальше

Текстовые задачи на системы. Теперь ты умеешь решать готовую систему — следующий шаг научиться самому составлять её по условию («сумма 50, разность 8» → { x + y = 50; x − y = 8 }) и добивать методом сложения.

Графический метод. Начертить обе прямые и посмотреть на точку пересечения — быстрый способ прикинуть, сколько решений, ещё до вычислений.

Системы второй степени. Когда одно из уравнений уже с x², сложение и подстановка комбинируют — сводя систему к квадратному уравнению.

Итог одной фразой: способ сложения подбирает множители так, чтобы при почленном сложении (или вычитании) уравнений одна переменная исчезла, оставив простое уравнение с одной неизвестной.

Проверка на выходе: назови алгоритм по памяти · когда складываем, а когда вычитаем · что значит 0 = 0 и 0 = 5 после исключения.
