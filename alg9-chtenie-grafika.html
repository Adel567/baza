Чтение графика функции

У функции может даже не быть формулы — а график всё равно всё расскажет. Научись «считывать» с картинки значения, нули и знак функции.

Главное правило

точка графика = ( x ; y ),  где y = f(x)

x — по горизонтали (аргумент, «вход»), y — по вертикали (значение функции, «выход»). Порядок записи всегда: сначала x, потом y.

Зачем это нужно

График — самый «говорящий» способ задать функцию

Одним взглядом видно, как одна величина зависит от другой. По графику движения видно, где машина стояла, а где ехала; по графику температуры — когда было теплее всего; по графику тарифа — сколько заплатишь за разговор. Чтение графика — это базовый навык всей темы «функции»: без него не поговорить ни про возрастание, ни про наибольшее значение.

Главное заблуждение: «график показывает дорогу, траекторию движения». Это не так. График показывает не путь в пространстве, а зависимость одной величины от другой. Например, график зависимости высоты мяча от времени — это парабола, хотя сам мяч летит вверх-вниз по одной прямой.

Что вспомнить с прошлых шагов

Координатная плоскость. У каждой точки две координаты: (x; y) — сначала абсцисса x (по горизонтали), потом ордината y (по вертикали).

Функция. Каждому x соответствует ровно один y. Именно поэтому любая вертикальная прямая пересекает график функции не больше чем в одной точке.

Ядро темы

Что можно «снять» с графика

Прочитать график — значит по картинке ответить на вопросы о функции, не имея формулы. Каждая точка графика — это пара «аргумент и значение», то есть (x; f(x)). Вот что с графика читают чаще всего:

Значение функции f(x)

Вошёл по оси Ox в нужный x, поднялся вертикально до графика, ушёл влево до оси Oy — читаешь высоту.

это и есть f(x) — ордината точки

Аргумент по значению

Обратный ход: от числа на оси Oy идёшь вправо до графика, потом вниз до оси Ox — читаешь x.

таких x может быть несколько

Нули функции

Точки, где график пересекает ось Ox. Там значение равно нулю. Абсциссы этих точек и есть нули.

f(x) = 0 ⇢ x — нуль функции

Знак функции

Где график идёт выше оси Ox — там f(x) > 0. Где ниже оси Ox — там f(x) < 0.

выше оси — плюс, ниже — минус

Возрастание и убывание

Слева направо график идёт вверх — функция возрастает; идёт вниз — убывает. (Подробно — в следующей теме.)

вверх ⇢ возрастает, вниз ⇢ убывает

Наибольшее и наименьшее

Самая высокая точка графика — наибольшее значение функции; самая низкая — наименьшее.

пик графика и его «дно»

Снимаем значения с готового графика

График проходит через точки (−2; 3), (0; −1), (1; 0), (4; 0).
Найди: f(−2), нули функции, f(0).

  1. f(−2). «Мне дан x = −2. Ставлю палец на −2 по оси Ox, поднимаюсь вертикально до графика — попадаю в точку (−2; 3). Высота 3.» Значит f(−2) = 3. Почему: значение функции — это ордината точки графика с данной абсциссой.
  2. Нули. «Нуль — там, где график пересекает ось Ox, то есть где y = 0. Это точки (1; 0) и (4; 0), их абсциссы 1 и 4.» Значит нули: x = 1 и x = 4. Почему: на оси Ox ордината равна 0.
  3. f(0). «Теперь x = 0. Не хватаю число 0 с оси Oy — я вхожу по x = 0 и поднимаюсь до графика: точка (0; −1), высота −1.» Значит f(0) = −1. Почему: f(0) — значение в точке пересечения с осью Oy.
f(−2) = 3 · нули x = 1 и x = 4 · f(0) = −1

Покрути сам · интерактив

Двигай ползунок — смотри, как считывается f(x)

Тяни ползунок по оси x. Пунктирная «лесенка» показывает путь снятия значения: от x вверх до графика и влево до оси Oy. Зелёным подсвечены участки, где функция возрастает, гранатом — где убывает, а жёлтые точки на оси Ox — это нули.

x = −3 → f(x) = 2

x
возрастает убывает нуль функции

Останови ползунок над нулём — точка ляжет ровно на ось Ox, там f(x) = 0. Загони его на самый верх графика — это наибольшее значение.

Мини-практика

Точка графика — (5; −2). Назови абсциссу и ординатупонимание
Абсцисса x = 5 — это аргумент. Ордината y = −2 — это значение функции. То есть f(5) = −2.
График проходит через (3; 5). Чему равно f(3)? Пересекает ось Ox в (−4; 0) — назови нульприменение
f(3) = 5 (ордината точки с абсциссой 3). Нуль функции: x = −4 (там график лёг на ось Ox).
График проходит через (−1; 4), (0; 0), (2; 0), (3; −2). Найди f(−1), нули, f(0)применение
f(−1) = 4; нули x = 0 и x = 2 (там y = 0); f(0) = 0 — здесь точка пересечения с осью Oy сама лежит на оси Ox.
Найди ошибку: ученик говорит, что точка (0; 4) — это нуль функциианализ
Он спутал две вещи. Точка (0; 4) — это пересечение с осью Oy (там x = 0), а нуль функции — пересечение с осью Ox (там y = 0). У (0; 4) ордината 4 ≠ 0, значит это не нуль. Нуль — там, где график ложится на ось Ox.
Что изменится, если весь график подняли вверх на 2 единицы?анализ
Каждое значение станет на 2 больше: было f(x), стало f(x) + 2. Нули сместятся: там, где раньше было f(x) = 0, теперь значение равно 2 (уже не нуль). Новые нули появятся там, где раньше было f(x) = −2 — поднявшись на 2, график коснётся оси Ox именно там.
Обратная задача: известно, что f(x) = 3. Как найти все такие x?анализ
Провести горизонтальную прямую y = 3. Все её пересечения с графиком дают нужные x (их может быть несколько). Это чтение «в обратную сторону»: от значения на оси Oy к аргументам на оси Ox.

Где чаще всего ошибаются

Лови эти ловушки

  • Путают абсциссу и ординату. Ищут f(2), но берут число 2 с оси Oy вместо того, чтобы войти по оси Ox. Проговаривай: «сначала x по горизонтали → поднимаюсь до графика → потом y по вертикали». Запись всегда (x; y).
  • Считают (0; 4) нулём функции. Это пересечение с осью Oy, а не нуль. Нуль — там, где график ложится на ось Ox и ордината равна 0.
  • Читают ближайшую отмеченную точку. Берут точку рядом, а не ту, что строго над нужным x. Проводи вертикальную линию точно через свой x и смотри высоту графика над осью.
  • «График — это траектория движения.» Вверх на графике не значит «вверх в пространстве». По вертикали отложена величина (например, расстояние), а не направление движения.

Три вопроса на понимание

Точка графика — (−5; 2). Чему равен аргумент и чему — значение функции?проверка
Аргумент — абсцисса x = −5. Значение функции — ордината y = 2, то есть f(−5) = 2.
Где «живут» нули функции — на какой оси их искать?проверка
На оси Ox: нули — это абсциссы точек, где график пересекает ось Ox (там y = 0).
Чем f(0) отличается от нуля функции?проверка
f(0) — это значение при x = 0 (высота точки пересечения с осью Oy). А нуль функции — это x, при котором значение равно нулю (точка на оси Ox). Разные вещи: одно — про x = 0, другое — про y = 0.
