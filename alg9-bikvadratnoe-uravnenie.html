Биквадратные уравнения

Уравнение с четвёртой степенью выглядит страшно — но одной заменой t = x² оно превращается в обычное квадратное, которое ты уже умеешь решать.

Биквадратное уравнение

ax4 + bx2 + c = 0

только чётные степени x (нет x³ и x¹) · замена t = x², где t ≥ 0, сводит его к квадратному a·t² + b·t + c = 0

🎯 В ОГЭ · Задание 9
Биквадратные уравнения дают в №9 как задание с кратким ответом. А сама замена t = x² может встретиться и в задании 20 второй части, где нужно записать полное решение.

Зачем это нужно

Увидеть в сложном знакомое простое

Уравнение x⁴ − 13x² + 36 = 0 пугает четвёртой степенью. Но присмотрись: в нём есть только x⁴, x² и число — а нечётных степеней (x³, x) нет. Тогда работает фокус: одна замена сводит задачу к обычному квадратному уравнению.

Главное заблуждение: «четвёртая степень — значит, нужны какие-то новые формулы для корней». Нет. Никаких формул для корней 4-й степени в школе не вводят. Весь секрет — в замене переменной. Это тот же приём, что дальше встретится в дробно-рациональных и тригонометрических уравнениях: он главный, ради чего тема и существует.

Что вспомнить с прошлого шага

Раз биквадратное сводится к квадратному — надо уверенно решать a·t² + b·t + c = 0: через дискриминант D = b² − 4ac или теорему Виета.

И помнить: x² = a при a > 0 даёт два корня x = ±√a, при a = 0 — один (x = 0), при a < 0 — ни одного. Вся тема стоит на этом.

Ядро темы · метод замены

Пять шагов от x⁴ к ответу

«Би-квадратное» буквально значит «дважды квадратное»: x⁴ = (x²)². Обозначаем t = x² — и весь алгоритм такой:

  1. Ввести замену t = x². Обязательное условие: t ≥ 0 (квадрат неотрицателен). Тогда x⁴ = t².
  2. Получить квадратное уравнение a·t² + b·t + c = 0 и решить его относительно t.
  3. Отобрать только корни t ≥ 0. Отрицательные t отбрасываем — для них x² = t решений не имеет.
  4. Вернуться к x: для каждого подходящего t решить x² = t, то есть x = ±√t (если t = 0 — один корень x = 0).
  5. Записать все полученные x. Ответ — только в переменной x, не в t!

Сколько будет корней

Всё решают знаки t

Число корней зависит от того, сколько неотрицательных t получилось. Три главные ситуации:

оба t > 0
4 корня
Каждый положительный t даёт пару ±√t.
один t > 0
2 корня
Второй t отрицательный — его отбрасываем.
все t < 0
нет корней
Ни один t не годится для x² = t.

Особый случай: если t = 0, то x² = 0 даёт ровно один корень x = 0 — не дублируй его.

Разбираем вместе · думаю вслух

Эталонный пример

x⁴ − 13x² + 36 = 0  →  найти все корни

  1. Замена t = x² (t ≥ 0). Тогда x⁴ = (x²)² = t². Уравнение становится квадратным: t² − 13t + 36 = 0.
  2. Дискриминант: D = (−13)² − 4·1·36 = 169 − 144 = 25, значит √D = 5.
  3. Корни по t: t₁ = (13 − 5)/2 = 4,  t₂ = (13 + 5)/2 = 9.
  4. Проверяем условие t ≥ 0: оба (4 и 9) положительны — оба годятся.
  5. Возвращаемся к x. Из t = 4: x² = 4 → x = ±2. Из t = 9: x² = 9 → x = ±3.
Ответ: x = −3, −2, 2, 3 — четыре корня.

Тренажёр · бесконечная практика

Реши биквадратное сам

Нажми «Новое уравнение», сделай замену t = x² и найди все корни. Введи их через пробел или «;» (дробные — с точкой или запятой), или напиши «нет», если корней нет. Порядок не важен. Потом проверь себя или посмотри пошаговое решение.

Практика по нарастанию

Какая замена превращает x⁴ − 10x² + 9 = 0 в квадратное? Чему равно t²?понимание
Замена t = x² (t ≥ 0). Тогда t² = x⁴, и уравнение становится t² − 10t + 9 = 0.
Почему значение t = −5 нельзя использовать для возврата к x?понимание
Потому что t = x², а квадрат не бывает отрицательным. Уравнение x² = −5 решений не имеет, поэтому отрицательный t сразу отбрасываем.
Реши: x⁴ − 8x² − 9 = 0применение
t² − 8t − 9 = 0; D = 64 + 36 = 100, √D = 10; t₁ = 9, t₂ = −1. t = −1 отбрасываем. Из t = 9 → x = ±3. Ответ: x = −3 и 3.
Реши: 4x⁴ − 5x² + 1 = 0  (a ≠ 1)применение
4t² − 5t + 1 = 0; D = 25 − 16 = 9, √D = 3; t = (5 ± 3)/8 → t₁ = 1, t₂ = 0.25. Оба ≥ 0. Из t = 1 → x = ±1; из t = 0.25 → x = ±0.5. Ответ: x = −1; −0.5; 0.5; 1.
Найди ошибку: «t² − 7t + 12 = 0, t₁ = 3, t₂ = 4, значит x = 3 и x = 4».анализ
Забыли вернуться к x! t — вспомогательная буква, а спрашивали x. Надо решить x² = 3 → x = ±√3 и x² = 4 → x = ±2. Правильный ответ: x = −2; −√3; √3; 2 (четыре корня).
Что с числом корней у x⁴ − 13x² + 36 = 0, если заменить +36 на −36?анализ
В t² − 13t − 36 = 0 произведение корней t₁·t₂ = −36 < 0 → корни разных знаков → один t отрицательный, его отбрасываем. Останется 2 корня вместо четырёх.
Придумай биквадратное уравнение ровно с двумя корнями: x = −1 и x = 1.анализ
Нужен один положительный t = 1 (даёт ±1) и один отрицательный (отбросится). Например, (t − 1)(t + 4) = 0 → t² + 3t − 4 = 0, то есть x⁴ + 3x² − 4 = 0. Проверка: t = 1 → x = ±1; t = −4 отбрасываем.

Где чаще всего ошибаются

Лови эти четыре ловушки

  • Не вернулись к x. Нашли t₁ = 9, t₂ = 4 и написали «ответ: 9 и 4». Но спрашивали x! Обязательно реши x² = t. Ответ записывается только в переменной x.
  • Взяли отрицательное t. Пишут x = ±√(−1). Так нельзя: t = x² ≥ 0, отрицательные t отбрасываются ещё до возврата к x. Проверяй знак сразу после нахождения t.
  • Потеряли минус при извлечении корня. Из x² = 4 пишут только x = 2, забыв x = −2. Из каждого положительного t рождается два значения x.
  • Забыли случай t = 0. Если t = 0, то x² = 0 даёт ровно один корень x = 0 (не два). Не дублируй.

Проверь, что понял

Объясни своими словами

Какую замену делают в биквадратном уравнении и при каком условии на t?проверка
Замена t = x² при условии t ≥ 0 — потому что квадрат любого числа неотрицателен.
Сколько значений x даёт один положительный корень t? А корень t = 0?проверка
Положительный t даёт два значения: x = ±√t. Корень t = 0 — одно: x = 0.
Почему отрицательные корни t отбрасывают?проверка
Потому что t = x², а квадрат не бывает отрицательным. Для t < 0 уравнение x² = t не имеет решений — возвращаться некуда.

Что дальше

Тот же приём «увидеть в сложном знакомое простое» ведёт к дробно-рациональным уравнениям:

1/(x−2) + 1/(x+2) = 1

Там уравнение сводят к квадратному, избавляясь от дробей, — и снова важно не потерять и не добавить лишние корни (проверять ОДЗ). Замена переменной будет твоим постоянным инструментом.
