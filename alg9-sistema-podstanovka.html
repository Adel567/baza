Метод подстановки

Системы, где одно уравнение уже второй степени — с x², y² или x·y. Тот же приём «вырази и подставь», но в конце получается квадратное уравнение — и решений, как правило, два.

Зачем это нужно

Два условия сразу — и одно из них «кривое»

Система — это когда про два неизвестных (x и y) известно несколько фактов сразу, и надо найти такие x и y, что подходят ко всем условиям одновременно. В 9 классе одно из уравнений часто уже не прямая, а «кривое» — с x², y² или произведением x·y.

«Периметр прямоугольника 14, а площадь 12. Найди стороны.»

Это система: x + y = 7 (полупериметр) и x·y = 12 (площадь). Второе уравнение — второй степени. Метод подстановки выдаёт стороны за пять шагов.

Ещё это точки пересечения графиков: где парабола y = x² встречает прямую y = x + 2? Решить систему этих уравнений — значит найти координаты точек пересечения.

Главное заблуждение: «нашёл x — задача решена». Нет. Ответ системы — это пара (x; y), и таких пар обычно две. Потеря второй пары — ошибка №1 по теме.

Что вспомнить перед стартом

Метод подстановки в линейных системах (7 класс). Из одного уравнения выражаешь переменную и подставляешь в другое. Здесь — то же самое, просто второе уравнение сложнее.

Квадратное уравнение через дискриминант (8 класс). ax² + bx + c = 0, считаем D = b² − 4ac: при D > 0 два корня, при D = 0 один, при D < 0 корней нет. Именно к такому уравнению сведётся система.

Квадрат суммы: (a + b)² = a² + 2ab + b² — понадобится при подстановке в x² + y².

Ядро — весь метод в пяти шагах

Алгоритм подстановки

Система второй степени в общем виде — два уравнения под фигурной скобкой, и хотя бы одно из них не линейное:

{x − y = 1  (линейное)x² + y² = 25  (второй степени)

Как решаем

  1. Вырази одну переменную через другую из линейного уравнения. Оно проще — дробей не будет.
  2. Подставь это выражение во второе уравнение — не в то, откуда выражал. Останется одна переменная.
  3. Реши получившееся уравнение — как правило, квадратное (через дискриминант). Найди все корни.
  4. Для каждого найденного корня вернись к выражению из шага 1 и посчитай вторую переменную.
  5. Запиши ответ — все пары (x; y).

Смысл: мы сводим «трудную» систему с двумя неизвестными к одному квадратному уравнению с одним неизвестным — а его ты уже умеешь решать.

Эталонный пример

Цвет-код действий — держи его в голове на каждом шаге:

выразить подставить решить квадратное найти пары

{x − y = 1x² + y² = 25

  1. Выражаю. Беру линейное уравнение x − y = 1 и выражаю x: x = y + 1. Линейное — выразить проще всего.
  2. Подставляю. Заменяю x в втором уравнении: (y + 1)² + y² = 25. Выражение — в скобки, чтобы не потерять квадрат.
  3. Решаю. Раскрываю по формуле: (y + 1)² = y² + 2y + 1. Тогда y² + 2y + 1 + y² = 25 → 2y² + 2y − 24 = 0 → y² + y − 12 = 0.
    Дискриминант: D = 1 + 48 = 49, √D = 7, y = (−1 ± 7)/2 → y₁ = 3, y₂ = −4.
  4. Нахожу пары. Возвращаюсь к x = y + 1 для каждого y:
    при y = 3 → x = 4;   при y = −4 → x = −3.
  5. Ответ: (4; 3) и (−3; −4). Две пары — не теряем вторую!
Проверка (4; 3): 4 − 3 = 1 ✓  и  16 + 9 = 25 ✓

Сколько решений — и почему

Всё решает дискриминант

После подстановки получается квадратное уравнение. Сколько у него корней — столько (обычно) и пар-решений у системы. Это тот же дискриминант из 8 класса, только теперь он считает точки пересечения графиков:

D > 0
Две пары
Прямая пересекает параболу (или окружность) в двух точках.
D = 0
Одна пара
Прямая касается кривой — одна общая точка.
D < 0
Решений нет
Графики не пересекаются — общих точек нет.

Наглядность · интерактив

«Решить систему» = найти общие точки

Прямая и парабола на одной координатной плоскости. Их точки пересечения — это и есть пары-решения системы. Подстановка находит их координаты буквами, а график — глазами.

Вот система y = x² и y = x + 2 из начала урока. Сколько точек пересечения предскажешь — 0, 1 или 2? Нажми кнопку и проверь.

y = x² y = x + 2

Графики начерчены. Точки пока не показываю — сначала прикинь сам.

Практика по нарастанию

Что является ответом системы — число x или пара (x; y)?понимание
Ответ — это пара (x; y), где x и y привязаны друг к другу. И таких пар у системы «прямая и парабола» может быть две (по числу точек пересечения). Одно число x — это ещё не ответ.
{ y = x²;   y = 2x − 1 } — после подстановки вышло x² − 2x + 1 = 0. Сколько пар?понимание
D = (−2)² − 4·1·1 = 4 − 4 = 0 → один корень x = 1, значит одна пара (1; 1). Прямая касается параболы.
{ x + y = 5;   x·y = 6 } — реши подстановкойприменение
Из первого y = 5 − x. Подставляем: x(5 − x) = 6 → x² − 5x + 6 = 0. D = 25 − 24 = 1, x₁ = 2, x₂ = 3. Тогда y = 5 − x: пары (2; 3) и (3; 2).
{ x − y = 2;   x·y = 15 } — реши подстановкойприменение
Из первого x = y + 2. Подставляем: (y + 2)y = 15 → y² + 2y − 15 = 0. D = 4 + 60 = 64, √D = 8, y = (−2 ± 8)/2 → y₁ = 3, y₂ = −5. Тогда x = y + 2: пары (5; 3) и (−3; −5).
Что если? В { y = x²; y = x + c } менять c — при каком c будет ровно одно решение?анализ
Приравниваем: x² = x + c → x² − x − c = 0. Одно решение — когда D = 0: D = 1 + 4c = 0 → c = −1/4. При этом c прямая касается параболы в одной точке. Если c > −1/4 — две точки, если c < −1/4 — ни одной.
Что если D < 0? { y = x²; y = x − 1 } — сколько решений?анализ
x² = x − 1 → x² − x + 1 = 0. D = 1 − 4 = −3 < 0 → корней нет, значит система решений не имеет. Геометрически: прямая y = x − 1 проходит ниже параболы и не пересекает её. Отрицательный D — это честный ответ «нет решений», а не ошибка.
Найди ошибку: из { x − y = 1; x² + y² = 25 } получили «Ответ: (4; 3)»анализ
Квадратное уравнение дало два корня: y₁ = 3 и y₂ = −4. Ученик обработал только первый и потерял вторую пару. Для y = −4: x = −4 + 1 = −3. Полный ответ — (4; 3) и (−3; −4). Правило: сколько корней — столько и пар.
Обратная задача: придумай систему с решениями ровно (1; 2) и (2; 1)анализ
Подбери условия, которым подходят обе пары. Сумма у обеих одна: 1 + 2 = 3 → берём x + y = 3. Произведение тоже одно: 1·2 = 2 → берём x·y = 2. Система { x + y = 3; x·y = 2 } даёт именно (1; 2) и (2; 1). Проверь подстановкой.

Тренажёр · бесконечная практика

Реши систему сам

Нажми «Новая система» и реши её методом подстановки. Впиши все пары решений: числа пары через ;, пары — через запятую. Например: 4;3, −3;−4. Если решений нет — впиши нет.

Система может быть линейной (одна пара) или второй степени (обычно две пары, иногда одна или ни одной).

{ x + y = 5x·y = 6

Где чаще всего ошибаются

Лови эти ловушки

  • Теряют второе решение. Нашли два x (или два y), а вторую переменную считают только для одного корня. Правило: сколько корней в квадратном уравнении — столько и пар. Обработай каждый корень отдельно.
  • Ошибаются при возведении в квадрат. Пишут (y + 1)² = y² + 1, забыв средний член. Верно: (y + 1)² = y² + 2y + 1. Всегда раскрывай по формуле (a + b)² = a² + 2ab + b², проговаривай «плюс 2ab».
  • Подставляют не в то уравнение. Выразили из первого и подставили обратно в первое — получили 0 = 0. Подставлять надо во второе, ещё не использованное уравнение.
  • Не записывают пары / путают порядок. Пишут «x = 4, y = −4, x = −3, y = 3», перемешивая числа. Записывай сразу парой (x; y), привязывая y к своему x на шаге 4.
  • Теряют минус при раскрытии скобок. В выражениях вида −(…) знак меняется у каждого слагаемого. Раскрывай скобки отдельной строкой, не в уме.

Проверь себя · объясни своими словами

Три вопроса

  1. Назови по шагам алгоритм подстановки: что выражаем и куда подставляем?
  2. В системе y = x² и y = 2x − 1 после подстановки вышло x² − 2x + 1 = 0. Сколько пар решений и почему?
  3. Почему нельзя остановиться, найдя только x?
Сверить ответыпроверка
1) Выражаем переменную из линейного уравнения → подставляем во второе → решаем квадратное → для каждого корня находим вторую переменную → пишем пары.   2) D = 4 − 4 = 0 → один корень x = 1 → одна пара (1; 1).   3) Ответ системы — это пара (x; y); найдя только x, ты не назвал y, а их бывает несколько — легко потерять решение.

Что дальше

Метод сложения. Иногда переменную выразить неудобно (везде степени). Тогда уравнения складывают или вычитают так, чтобы одна переменная ушла сама — это следующий приём для систем.

Графический метод. Начертить оба графика и посмотреть на точки пересечения — быстрый способ понять, сколько решений, и прикинуть их ещё до вычислений.

Итог одним предложением: способ подстановки сводит систему к одному квадратному уравнению, а ответом служат все пары (x; y), полученные обратной подстановкой каждого корня.

Проверка на выходе: назови 5 шагов метода · сколько пар при D = 0 · почему нельзя остановиться на одном x.
