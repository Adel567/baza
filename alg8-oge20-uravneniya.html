Уравнения: методы решения

Первое задание второй части. Нужно записать полное решение — метод, преобразования и все корни. Максимум — 2 балла. Ниже — семь рабочих методов (уравнения и системы), эталонные разборы и практика, включая «солянки», где метод нужно выбрать самому.

Как оценивают. 2 балла — верное решение доведено до конца, все корни найдены. 1 балл — метод верный, но допущена вычислительная ошибка. 0 — метод не тот или потерян корень. Поэтому два правила: не теряй корни (чаще всего теряют x = 0 при делении на x) и проверяй ОДЗ в дробных уравнениях.
ax2 + bx = 0 (нет свободного числа)→ вынести общий множитель
x3 + … (четыре слагаемых)→ группировка
x4 + bx2 + c = 0 (биквадратное)→ замена t = x2
дробь = число / дробь + дробь→ ОДЗ, общий знаменатель
скобки, квадраты, перенос→ раскрыть → квадратное (D или Виета)
система из двух уравнений→ подстановка или сложение

1 Вынесение общего множителя

Когда: в уравнении нет свободного члена — у каждого слагаемого есть общий множитель (чаще всего x). Главное: не делить на x — потеряешь корень x = 0. Переноси всё в одну часть и раскладывай.

Эталон · думаю вслух

3x² − 12x = 0

3x(x − 4) = 0  — вынесли 3x за скобку

3x = 0 или x − 4 = 0  — произведение равно нулю

Ответ: x = 0;   x = 4

  1. 5x² = 20x
  2. 7x² + 4x = 0
  3. 2x³ − 8x = 0
  4. (x + 2)² = (x + 2)(3x − 1)

2 Группировка (уравнения с x³)

Когда: кубическое уравнение из четырёх слагаемых. Группируешь попарно, выносишь множитель из каждой пары — должна получиться одинаковая скобка. Дальше x² − a раскладываешь по разности квадратов.

Эталон · думаю вслух

x³ + 2x² − x − 2 = 0

x²(x + 2) − (x + 2) = 0  — сгруппировали и вынесли

(x + 2)(x² − 1) = 0  — общая скобка (x + 2)

(x + 2)(x − 1)(x + 1) = 0  — разность квадратов

Ответ: x = −2;   x = 1;   x = −1

  1. x³ + 3x² − 4x − 12 = 0
  2. x³ − 2x² − 9x + 18 = 0
  3. x³ − 5x² − 4x + 20 = 0
  4. x³ + x² − 16x − 16 = 0

3 Замена переменной (биквадратные)

Когда: есть x⁴ и x², но нет x³ и x. Замена t = x² (обязательно t ≥ 0) превращает его в квадратное. Нашёл t — возвращаешься к x: x² = t. Отрицательные t отбрасываешь.

Эталон · думаю вслух

x⁴ − 13x² + 36 = 0

t² − 13t + 36 = 0, где t = x²  — замена

D = 169 − 144 = 25;  t = 9 или t = 4

x² = 9 → x = ±3;  x² = 4 → x = ±2  — обратно к x

Ответ: x = ±2;   x = ±3

  1. x⁴ − 5x² + 4 = 0
  2. x⁴ − 10x² + 9 = 0
  3. x⁴ − 5x² − 36 = 0  (ловушка: t < 0)
  4. x⁴ + 3x² − 4 = 0

4 Дробно-рациональные (ОДЗ!)

Когда: переменная в знаменателе. Сначала ОДЗ: знаменатель ≠ 0. Умножаешь обе части на общий знаменатель, решаешь. В конце выбрасываешь корни, которые не входят в ОДЗ (посторонние).

Эталон · думаю вслух

(x² − 7x + 6) / (x − 6) = 0

ОДЗ: x ≠ 6  — знаменатель не ноль

x² − 7x + 6 = 0 → (x − 1)(x − 6) = 0  — дробь = 0, когда числитель = 0

x = 1 или x = 6;  x = 6 — посторонний (не в ОДЗ)

Ответ: x = 1

  1. (x² − 9) / (x − 3) = 0
  2. (x + 4) / (x − 2) = x
  3. x / (x + 3) + 18 / (x² + 3x) = 1
  4. 12 / (x + 1) = x + 2

5 Раскрыть скобки → квадратное

Когда: в уравнении скобки, квадраты, произведения. Раскрываешь, переносишь всё влево, приводишь подобные — получается квадратное. Дальше дискриминант или теорема Виета. Иногда x сокращаются и остаётся неполное x² = a.

Эталон · думаю вслух

(x + 1)(x − 2) = 4

x² − x − 2 = 4  — раскрыли скобки

x² − x − 6 = 0  — перенесли, привели

(x − 3)(x + 2) = 0  — Виета: 3 · (−2) = −6, 3 + (−2) = 1

Ответ: x = 3;   x = −2

  1. x(x − 1) = 12
  2. (x − 4)² = 2x² − 17
  3. (x + 3)² = 6x + 34
  4. (x − 1)² + (x + 1)² = 34

6 Системы: подстановка

Когда: в одном уравнении легко выразить переменную (особенно если система нелинейная — есть xy или x²). Выражаешь одну переменную из простого уравнения, подставляешь в другое — получается одно уравнение с одной переменной. Найдя её, возвращаешься за второй. Ответ — пары (x; y).

Эталон · думаю вслух

{x − y = 2xy = 8

x = y + 2  — выразили x из первого

(y + 2)·y = 8 → y² + 2y − 8 = 0  — подставили во второе

(y + 4)(y − 2) = 0 → y = −4; y = 2

y = 2 → x = 4;  y = −4 → x = −2  — вернулись за x

Ответ: (4; 2), (−2; −4)

  1. {x + y = 6xy = 8
  2. {y − x = 1y = x² − 5
  3. {x + y = 7x² − y = 5
  4. {x − y = 3xy = 10

Когда: оба уравнения линейные и у одной переменной противоположные (или легко уравниваемые) коэффициенты. Складываешь уравнения почленно — одна переменная исчезает. Если сразу не сокращается, домножь уравнение на число, чтобы коэффициенты стали противоположными.
