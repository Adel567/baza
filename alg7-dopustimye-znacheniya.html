Алгебра · 7 класс

Допустимые значения переменных

Вместо буквы можно подставить число. Но не любое: иногда подстановка ломает выражение — вылезает деление на ноль. Учимся видеть такие числа заранее.

Главное условие осмысленности

числительзнаменатель — имеет смысл, когда знаменатель ≠ 0

На ноль делить нельзя. Значения, от которых знаменатель становится нулём, вычёркиваем.

Зачем это нужно и где встречается

Буква — не значит «любое число»

Есть в выражении буква (переменная) — значит, вместо неё можно подставлять разные числа. Но не каждое: иногда подстановка выводит на запрещённое действие, чаще всего на деление на ноль. Поэтому и разбираемся заранее, какие значения переменной разрешены, а какие нет.

Скажешь: стоит буква — подставляй что хочешь. Вот это и есть главное заблуждение темы: «раз стоит буква, в неё можно подставить любое число». Не любое. Есть значения, при которых выражение теряет смысл — его просто нечем вычислить.

Проверь прямо сейчас. Возьми выражение 8 : (x − 3) и подставь x = 3. В знаменателе получится 3 − 3 = 0, а значит, нужно поделить 8 на 0. Такого действия в математике нет. Всё, число 3 сюда подставлять запрещено.

Этот навык — фундамент. Дальше он всплывёт:

  • при решении уравнений с дробями — там нельзя брать корень, который обнуляет знаменатель;
  • при работе с функциями — это будет называться «область определения»;
  • при упрощении дробных выражений.

Не умеешь находить «запрещённые» значения — запишешь в ответ число, которого не существует.

🎯 Зачем это на экзамене
Отдельного задания «найди допустимые значения» в школьной программе 7 класса почти не встретишь. Зато это обязательный шаг внутри задач с дробями: нашёл корень уравнения — проверь, не обнуляет ли он знаменатель. Не проверил — записал в ответ несуществующее число.

Что вспомнить перед стартом

Тебе понадобятся две вещи:

1. Что такое выражение с переменной и как в него подставляют число. Буква (чаще x, a, t) — это пустое место, куда мы ставим число, а потом считаем. В x − 3 при x = 10 получается 10 − 3 = 7.

2. Как решить простейшее уравнение вида x + 3 = 0. Число переносим в другую часть с противоположным знаком: x = −3. Именно на этом шаге в теме теряют больше всего баллов, так что проверь себя: чему равен x, если x + 4 = 0? (Должно получиться −4.)

Ядро темы · определение и правило

Допустимое значение — то, при котором всё считается

Определение. Допустимым значением переменной называется такое значение, при подстановке которого выражение имеет смысл — то есть все входящие в него действия выполнимы.

Если коротко: подставил число вместо буквы, выражение получилось посчитать — значение допустимое. Наткнулся на запрещённое действие — недопустимое.

Главное правило для 7 класса. Деление на ноль не определено. Значит, если переменная входит в знаменатель дроби, нужно потребовать:

  • знаменатель ≠ 0,
  • то есть найти значения переменной, обращающие знаменатель в ноль, и исключить их.

знаменатель ≠ 0

Как это записывают и читают:

  • Буква — это переменная. Чаще всего x, a, t, но подойдёт любая.
  • Запись x ≠ 5 читается «икс не равен пяти» и означает: число 5 — недопустимое значение, а все остальные числа допустимы.
  • Мы не решаем уравнение — мы проверяем, имеет ли выражение право существовать. Уравнение знаменатель = 0 решается только как вспомогательный шаг: чтобы узнать, какое число запретить.
  • Если знаменателя с переменной нет — допустимы все числа. В 7 классе запрет берётся практически только из деления на выражение с буквой.

Разбираем вместе · думаю вслух

Эталонный пример

Найти допустимые значения для выражения 8x − 3

  1. Замечаю дробь, в знаменателе стоит переменная. Почему это важно: знаменатель не должен быть нулём, иначе делить не на что. Не было бы буквы в знаменателе — не было бы и запретов.
  2. Записываю условие: x − 3 ≠ 0. Почему именно так: запрещён ровно один случай — нуль в знаменателе. Остальное разрешено.
  3. Решаю «обратно»: смотрю, когда знаменатель всё-таки станет нулём, то есть решаю x − 3 = 0. Получаю x = 3. Почему беру знак «равно», хотя нужно «не равно»: проще найти одно запрещённое число, чем перебирать все разрешённые. Нашёл — вычеркнул.
  4. Записываю вывод: x ≠ 3. Допустимы все числа, кроме 3.
x ≠ 3

Как себя проверить: подставь запрещённое число и посмотри, как выражение ломается. При x = 3 знаменатель равен 3 − 3 = 0, и получается 8 : 0 — так нельзя. А при соседнем x = 4 всё нормально: 8 : (4 − 3) = 8 : 1 = 8.

Второй пример — допиши сам

Алгоритм тот же, последний шаг за тобой. Найди допустимые значения для x + 1x + 4. Первые два шага я уже сделал:

Знаменатель с переменной: x + 4

  1. Условие: x + 4 ≠ 0.
  2. ____ — допиши сам: какое значение обращает знаменатель в ноль и какой получится ответ? Подсказка: реши x + 4 = 0.
Проверить себяэталон
Решаем x + 4 = 0: переносим 4 вправо с противоположным знаком, x = −4. Значит, ответ: x ≠ −4 — допустимы все числа, кроме −4.
Следи за знаком: в знаменателе стоит плюс 4, а запрещённое число выходит отрицательным. Это самая частая ловушка темы.

Третий пример — теперь полностью сам

Найди допустимые значения для 52x − 10. Решай, а потом раскрывай.

Показать решениеэталон
Условие: 2x − 10 ≠ 0. Ищем запрещённое: 2x − 10 = 0 → 2x = 10 → x = 5. Ответ: x ≠ 5.
Тут перед иксом появился коэффициент, поэтому шага два: сначала перенесли число, потом поделили на 2.

Наглядность · выколотая точка

Числовая прямая с дыркой

Самый понятный образ темы вот такой. Числовая прямая — это все числа подряд, и почти все они разрешены, так что прямую закрашиваем целиком. А запрещённое значение выкалываем: ставим на его месте пустой кружок, дырку. Получается «допустимо всё, кроме одной точки».

Таблица подстановок

Тот же самый факт можно просто увидеть в таблице: подставим несколько чисел подряд в знаменатель x − 3 и посмотреть, что получается:

Красная колонка одна на всю таблицу — только там выражение ломается. Остальные значения переменной проходят спокойно.

Предскажи → проверь → объясни

Прежде чем раскрывать ответ, предскажи вслух или про себя: что будет, если в 8 : (x − 3) подставить x = 3? Не подглядывай, сначала сформулируй свою версию.

Проверяем предсказаниеPOE
Подставляем: знаменатель 3 − 3 = 0, значит, надо посчитать 8 : 0. Такого действия не существует: деление на ноль не определено. Выражение не имеет смысла.
Теперь объясни своими словами, почему такое значение исключают: потому что при нём выражение вообще нельзя вычислить, а не потому что «ответ большой» или «ответ ноль».

Теперь ты · реши, потом раскрой ответ

Мини-практика

Прочитай запись «a ≠ 0» словами. Что она значит для 7/a?понимание
Читается: «а не равно нулю». Для выражения 7/a это значит: число 0 подставлять вместо a нельзя (получилось бы деление на ноль), а любое другое число — можно.
В выражении 3x + 6 есть запрещённые значения? Почему?понимание
Нет. Дроби с переменной в знаменателе тут нет, а значит, ломаться нечему. Умножать и складывать можно с любыми числами. Допустимы все значения x.
Найди допустимые значения: 12 / (x − 7)применение
Условие: x − 7 ≠ 0. Запрещённое: x − 7 = 0 → x = 7. Ответ: x ≠ 7.
Найди допустимые значения: 1 / (x + 2)применение
Условие: x + 2 ≠ 0. Запрещённое: x + 2 = 0 → x = −2. Ответ: x ≠ −2. Ещё раз, это важно: плюс в знаменателе — минус в ответе.
Найди допустимые значения: 9 / (3x)применение
Условие: 3x ≠ 0. Запрещённое: 3x = 0 → x = 0. Ответ: x ≠ 0. Тройка на ответ не влияет: произведение равно нулю только тогда, когда сам x равен нулю.
Что изменится, если в 4 / (x − 1) заменить знаменатель на (x − 1)(x + 2)?анализ
Было одно запрещённое значение: x ≠ 1. Стало два. Произведение равно нулю, когда хотя бы один множитель равен нулю, поэтому проверяем оба:
x − 1 = 0 → x = 1;
x + 2 = 0 → x = −2.
Ответ: x ≠ 1 и x ≠ −2. На числовой прямой теперь две выколотые точки вместо одной.
Найди ошибку: для 5 / (x + 3) ученик написал x ≠ 3анализ
Промах в знаке. Ученик увидел в знаменателе тройку и переписал её в ответ, не решая уравнение. А решить надо так: x + 3 = 0 → x = −3. Верный ответ: x ≠ −3.
Проверка: при x = 3 знаменатель равен 3 + 3 = 6 — никакого нуля, значение вполне допустимое. А при x = −3 знаменатель −3 + 3 = 0 — вот оно, запрещённое.
Обратная задача: придумай дробь, для которой недопустимо именно x = 6анализ
Нужен знаменатель, который обращается в ноль при x = 6. Самое простое — x − 6. Например, 1 / (x − 6): условие x − 6 ≠ 0 даёт как раз x ≠ 6.
Числитель можно взять любой, он на запрет не влияет. Годится и 2x − 12 в знаменателе: 2x − 12 = 0 → x = 6. Вариантов бесконечно много.

Тренажёр · бесконечная практика

Найди запрещённые значения сам

Жми «Новый пример» и определяй, при каких значениях переменной выражение не имеет смысла. Пиши сами числа через запятую, например 3 или -1, 2. Минус — обычный дефис. Если запрещённых значений нет и подходит любое число, так и напиши: любое.

Осторожно: среди примеров попадаются такие, где переменной в знаменателе нет вовсе. Запрещённых значений там не существует, не выдумывай их.

Где чаще всего ошибаются

Лови эти четыре ловушки

  • «Любое значение переменной допустимо». Нет: значения, от которых знаменатель обращается в ноль, запрещены. Как не попасться: первым делом ищи знаменатель с переменной и проверяй его на ноль. В задании с дробью это шаг номер один.
  • Не замечают деления на ноль. Дробь видят, а знаменатель не проверяют. Приём: увидел переменную в знаменателе — сразу, не думая, пиши «знаменатель ≠ 0». Это рефлекс, а не размышление.
  • Путают знак при решении «знаменатель = 0». Для x + 3 пишут x ≠ 3 вместо x ≠ −3. Что помогает: честно решить уравнение x + 3 = 0 → x = −3, перенеся число с противоположным знаком. Число из знаменателя «как есть» не переписывается.
  • Исключают значение из-за нуля в числителе. Ноль в числителе разрешён: ноль на число делить можно, получится ноль. Запрет касается только знаменателя.

Что дальше

Теперь ты умеешь определять, при каких значениях переменной выражение вообще существует. Следующий шаг — тождества: равенства, верные при всех допустимых значениях переменной.

верно при всех допустимых x — это тождество

Заметил формулировку? В ней прямо сидит наша тема. Прежде чем сказать «равенство верно всегда», надо понять, где это «всегда» действует — то есть какие значения переменной допустимы.

Если совсем коротко: допустимые значения — это все числа, при которых выражение можно посчитать. В 7 классе всё упирается в одно: знаменатель дроби не должен обращаться в ноль.
