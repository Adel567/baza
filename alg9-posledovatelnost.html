Числовая последовательность

Числа, выстроенные по номерам: у каждого своё место в строю. Разберёмся, что значит запись aₙ и как последовательность задают формулой.

Главное обозначение

a₁, a₂, a₃, …, aₙ, …

n — номер члена (место в строю), aₙ — значение n-го члена (само число)

Зачем это нужно

Всё, что идёт по шагам

Последовательности — это про любой процесс, который идёт по шагам, по очереди: проценты по вкладу за месяц 1, 2, 3, …; число дней до экзамена; рост числа подписчиков по дням; платежи по графику. Везде, где у каждого шага есть свой номер, удобно говорить о числовой последовательности.

В математике эта тема — фундамент для двух больших разделов дальше: арифметической и геометрической прогрессий. Без аккуратного понимания «номер члена ↔ значение члена» прогрессии превращаются в путаницу из букв и индексов.

И сразу разрушим главный миф. Кажется, что «последовательность — это просто список, который где-то заканчивается». Нет: числовая последовательность бесконечна. За любым членом всегда есть следующий, потому что натуральные номера 1, 2, 3, … не кончаются.

Что вспомнить с прошлого шага

Функция — это правило, которое каждому «входу» ставит в соответствие ровно один «выход».

Натуральные числа — числа для счёта: 1, 2, 3, 4, … Нуля и отрицательных среди них нет, и они не кончаются.

Держи эти две вещи в голове — из них и собирается вся тема.

Суть темы

Последовательность — это функция от номера

Словами: возьмём натуральные числа по порядку 1, 2, 3, 4, … и каждому из них поставим в соответствие одно число. Получится бесконечная вереница чисел, выстроенных по номерам. Это и есть числовая последовательность.

Ключевая мысль: последовательность — это функция, у которой аргумент n пробегает только натуральные числа. Номер n — это «вход», член последовательности — это «выход». Если у функции y = f(x) мы подставляли любые x, то здесь подставляем только n = 1, 2, 3, …

Символьная запись: члены обозначают одной буквой с индексом-номером — a₁, a₂, a₃, …, aₙ, … Здесь aₙ — это n-й член (значение), а маленькое n внизу — его номер (место в строю). Всю последовательность кратко пишут как (aₙ).

номер n12345
член aₙ13579

Верхняя строка — номера, нижняя — значения. Здесь a₄ = 7: четвёрка — это номер, а сам член равен 7.

Ядро темы

Определение и обозначения

Числовая последовательность — это функция, заданная на множестве натуральных чисел N. Каждому натуральному числу n соответствует ровно одно число aₙ — n-й член последовательности.

  • n — номер члена, n ∈ N (n = 1, 2, 3, …);
  • aₙ — значение n-го члена (само число);
  • (aₙ) — обозначение всей последовательности.
Номер всегда натуральный. Поэтому a₀ или a₋₂ не бывает — «нулевого» члена нет.

Два способа задания

Формулой n-го члена или рекуррентно

aₙ = 2n − 1
Формулой n-го члена (явный способ)
Даётся формула: подставляешь номер n — и сразу получаешь член. Здесь выходит 1, 3, 5, 7, … — нечётные числа.
a₁ = 4, aₙ₊₁ = aₙ + 3
Рекуррентно (через предыдущие)
Задан первый член и правило, как из предыдущего получить следующий. Слово «рекуррентный» значит «возвратный»: чтобы найти новый член, мы «возвращаемся» к предыдущему.

Важно различать запись: aₙ₊₁ — это следующий член (с номером n+1), а aₙ + 1 — это n-й член, увеличенный на 1. Это разные вещи, и путать их нельзя.

Покрути сам · интерактив

Конвейер членов

Выбери способ задания и выпускай члены по одному. По горизонтали — номер n, по вертикали — значение aₙ. Смотри, чем отличаются два способа: по формуле n-го члена можно сразу прыгнуть к a₁₀₀, а рекуррентно — только шаг за шагом.

Формула n-го члена

Обрати внимание: точки стоят только над натуральными n — между ними пусто. Это и значит «функция натурального аргумента»: между 3-м и 4-м членом никакого члена нет.

Разбираем вместе

Эталонный пример: считаем по формуле n-го члена

aₙ = n² − 1  →  найти a₁, a₃ и a₁₀

  1. Ищем a₁. Первый член — значит номер равен 1, подставляю n = 1: a₁ = 1² − 1 = 1 − 1 = 0.
  2. Ищем a₃. Третий член — значит номер 3: a₃ = 3² − 1 = 9 − 1 = 8.
  3. Ищем a₁₀. Подставляю n = 10: a₁₀ = 10² − 1 = 100 − 1 = 99.
Ответ: a₁ = 0, a₃ = 8, a₁₀ = 99. Номер n работает «входом», член aₙ — «выходом».

b₁ = 5, bₙ₊₁ = bₙ + 4  →  найти b₂, b₃, b₄ (допиши сам)

  1. b₂ = b₁ + 4 = 5 + 4 = 9.
  2. b₃ = b₂ + 4 = 9 + 4 = ___
  3. b₄ = b₃ + 4 = ___ + 4 = ___

Подсказка: каждый следующий член — это предыдущий плюс 4. Заметь, как обязательно нужен предыдущий: b₄ без b₃ не найти.

Проверить себярекуррентно
b₃ = 9 + 4 = 13, b₄ = 13 + 4 = 17

cₙ = 3n + 2  →  найди c₁, c₂ и c₅ сам

Мой ответ готовприменение
c₁ = 5, c₂ = 8, c₅ = 17

Три взгляда на одно и то же

Наглядность: таблица, прямая, плоскость

Одну и ту же последовательность полезно увидеть тремя способами — так связь «номер → значение» становится очевидной.

Таблица
В верхней строке номера n = 1, 2, 3, 4, в нижней — значения aₙ. Прямо показывает соответствие «номер → значение».
Числовая прямая
Отметь значения членов точками — видно, как они «шагают».
Координатная плоскость
По горизонтали номер n, по вертикали aₙ. Точки (1; a₁), (2; a₂), … показывают, что последовательность — функция натурального аргумента: точки стоят только над натуральными n, между ними «пусто». Именно это ты и видел в конвейере выше.

Попробуй приём «предскажи → проверь → объясни»: перед тобой 2, 5, 8, 11. Какой член будет пятым? Сначала предскажи, потом посчитай, а потом объясни словами, почему прибавляем 3.

a₁ = 2a₂ = 5a₃ = 8a₄ = 11a₅ = ?
Проверить предсказаниеPOE
a₅ = 11 + 3 = 14 — каждый следующий больше предыдущего на 3.

Где чаще всего ошибаются

Лови эти ловушки

  • Путают номер члена и его значение. Видят «a₅» и ищут число 5, хотя 5 — это номер, а значение надо ещё вычислить. Приём: всегда проговаривай «пятый член — значит подставляю n = 5».
  • Подставляют не то. В формуле aₙ = 5n − 3 для второго члена пишут 5 · (значение), а не 5 · (номер). Правило: в формулу n-го члена всегда подставляется НОМЕР.
  • Считают последовательность конечной. Думают, что «…» означает «скоро кончится». Помни: за каждым членом есть следующий, последовательность бесконечна.
  • Смешивают способы задания. Получив рекуррентную формулу aₙ₊₁ = aₙ + 3, пытаются сразу подставить номер, как в явную. Но рекуррентно член находят только через предыдущий, шаг за шагом.
  • Путают aₙ₊₁ и aₙ + 1. Первое — следующий член, второе — текущий член плюс единица. Читай индекс внимательно.

Проверка понимания

Объясни своими словами

Что в записи a₇ обозначает семёрка — номер или значение?вопрос 1
Номер. Значение седьмого члена ещё надо вычислить.
Чем формула n-го члена отличается от рекуррентной?вопрос 2
В первой подставляем номер и сразу получаем член; во второй находим член через предыдущий.
Может ли у числовой последовательности быть «последний» член?вопрос 3
Нет, она бесконечна: номера 1, 2, 3, … не кончаются.

Итог одной фразой: числовая последовательность — это функция натурального номера, которая каждому n ставит в соответствие член aₙ и задаётся либо формулой n-го члена, либо рекуррентно.

Что дальше

Дальше пойдут два самых важных частных случая последовательности — когда правило перехода к следующему члену особенно простое:

арифметическая прогрессия · геометрическая прогрессия

В одной к предыдущему члену каждый раз прибавляют одно и то же число, в другой — умножают на одно и то же. Обе задаются и рекуррентно, и формулой n-го члена — ровно тем языком, который ты только что разобрал.
