Координаты середины отрезка

Чтобы найти точку ровно посередине, не нужно ничего измерять. Достаточно взять среднее от координат концов — отдельно по x и отдельно по y.

Формула середины отрезка

xM = (x₁ + x₂)/2  ·  yM = (y₁ + y₂)/2

A(x₁; y₁) и B(x₂; y₂) — концы отрезка, M(xM; yM) — его середина

Зачем это нужно

Одна формула — куча задач

Метод координат превращает геометрическую задачу в вычисление по формуле, и середина отрезка — одна из самых рабочих формул в нём. Она нужна, чтобы найти центр окружности по концам диаметра, точку пересечения медиан треугольника, центр симметрии, а ещё чтобы проверить, что четырёхугольник — параллелограмм: у параллелограмма диагонали делятся точкой пересечения пополам, значит у диагоналей общая середина. Дальше эта же формула помогает выводить уравнение прямой и работать с векторами.

В жизни это просто «найти точку ровно посередине»: середина моста между двумя берегами с известными координатами, точка встречи двух людей на карте, центр участка.

Разрушаем главный миф. Многие думают: раз «середина» — это про длину, то её надо как-то измерять или делить расстояние пополам. Ничего подобного. Координаты середины считаются прямо из координат концов, и длину отрезка вычислять не нужно вообще — ни разностей, ни корней.

Что вспомнить с прошлых шагов

Точка на плоскости задаётся парой координат: сначала x (вправо-влево), потом y (вверх-вниз). Пишем через точку с запятой: A(2; 6).

Координаты бывают отрицательными и нулём — знак берём вместе с числом.

Среднее двух чисел — это их полусумма: (число₁ + число₂) ÷ 2.

Если нужна ещё и длина — это формула расстояния между точками, отдельная тема. Для середины она не нужна.

Суть темы

Середина — это среднее по каждой оси

Возьмём отрезок с концами A и B. Середина M — точка, которая делит отрезок ровно пополам: AM = MB. Её координаты — «средние» от координат концов: координата x середины лежит ровно между x концов, и то же самое по y.

Ключевая мысль: каждая координата считается отдельно и независимо. Ось x ничего не знает про ось y.

xM = (x₁ + x₂)/2
Работаем по оси x
Складываем только x-координаты концов и делим на 2.
yM = (y₁ + y₂)/2
Работаем по оси y
Складываем только y-координаты концов и делим на 2.

Полезная привычка — раскладывать вычисление по столбикам, чтобы не перепутать оси. Всегда спрашивай себя: «в каком столбце я сейчас работаю?»

Что берёмСтолбец xСтолбец y

Порядок концов не важен: (x₁ + x₂)/2 = (x₂ + x₁)/2, ответ получится один и тот же. Координаты могут быть любыми — положительными, отрицательными, нулём, дробными; минусы складываем по правилам знаков, а на 2 делим обязательно после сложения.

Разбираем вместе · думаю вслух

Эталонный пример

Найти середину отрезка AB, где A(2; 6), B(8; 4)

  1. Выписываю координаты концов: x₁ = 2, y₁ = 6, x₂ = 8, y₂ = 4. Почему: формула работает только с конкретными числами, их надо чётко разделить по осям.
  2. Считаю x середины: xM = (2 + 8)/2 = 10/2 = 5. Почему: сначала складываю обе x-координаты, потом делю на 2.
  3. Считаю y середины: yM = (6 + 4)/2 = 10/2 = 5. Почему: y считаю отдельно от x, по той же формуле.
  4. Записываю ответ парой: M(5; 5).
Проверка смыслом: 5 лежит между 2 и 8, и 5 лежит между 6 и 4 — точка действительно посередине.

А теперь пример с минусами — допиши сам пропущенный шаг. Найти середину отрезка CD, где C(−3; 1), D(5; −7):

xM = (−3 + 5)/2 = 2/2 = 1;  yM = (1 + (−7))/2 = ___/2 = ___допиши
Подсказка: 1 + (−7) = −6, значит yM = −6/2 = −3. Ответ: M(1; −3).
Сам: середина PQ, где P(−4; −2), Q(6; −2)применение
Ответ: M(1; −2). Обрати внимание: у концов одинаковый y, поэтому и у середины тот же y — отрезок горизонтальный.

Покрути сам · интерактив

Видно, что середина — это среднее

Двигай ползунки и следи за пунктирными проекциями на оси: точка xM на оси x всегда стоит ровно посередине между x₁ и x₂, и то же самое по y. Кнопка справа переключает на обратную задачу: даны конец и середина — второй конец достраивается симметрично.

Двигай концы A и B — середина M считается сама.

Поймай момент, когда обе координаты концов разной чётности — середина «приземляется» на половинку (например, 2,5). Это нормально: середина вовсе не обязана попадать в узел клетки.

Проверь себя · по нарастанию

Мини-практика

Прочитай формулу словами: как получить xM?понимание
Сложить x-координаты обоих концов и разделить сумму на 2. То же отдельно для y.
A(0; 0), B(10; 0) — назови середину устнопонимание
M(5; 0): (0 + 10)/2 = 5, (0 + 0)/2 = 0.
Середина отрезка с концами A(1; 9) и B(7; 3)применение
xM = (1 + 7)/2 = 4,  yM = (9 + 3)/2 = 6 → M(4; 6).
Середина отрезка с концами K(−5; 2) и L(−1; 8)применение
xM = (−5 + (−1))/2 = −6/2 = −3,  yM = (2 + 8)/2 = 5 → M(−3; 5).
Обратная задача: M(4; 5), конец A(1; 2). Найди Bанализ
Из xM = (x₁ + x₂)/2 выражаем x₂ = 2·xM − x₁ = 2·4 − 1 = 7; так же y₂ = 2·5 − 2 = 8 → B(7; 8).
Найди ошибку: для A(2; 4), B(6; 10) ученик написал M(8; 14)анализ
Он сложил координаты, но забыл разделить на 2. Верно: xM = (2 + 6)/2 = 4,  yM = (4 + 10)/2 = 7 → M(4; 7). Проверка смыслом: 8 вообще не лежит между 2 и 6 — значит точка не могла быть серединой.
Что изменится с серединой, если обе координаты каждого конца увеличить на 3?анализ
Середина сдвинется на те же 3 по каждой оси. Проверка на примере: было A(2; 6), B(8; 4), M(5; 5). Стало A(5; 9), B(11; 7): xM = (5 + 11)/2 = 8,  yM = (9 + 7)/2 = 8 → M(8; 8). Обе координаты выросли ровно на 3. Объяснение: к сумме добавилось 3 + 3 = 6, а после деления на 2 это и есть +3.

Где чаще всего ошибаются

Четыре ловушки

  • Сложили координаты, но не разделили на 2. Получается точка вдвое «дальше» (как M(8; 14) выше). Помни: середина — это среднее, а среднее всегда делится на 2. Написал сумму — сразу пиши «/2».
  • Путают середину с расстоянием. Начинают считать длину отрезка, разности, корни. Для середины разности и корни не нужны вообще — только сумма и деление на 2.
  • Берут полусумму только по одной координате. Усреднили x, а y просто переписали от одного конца. Формула применяется к каждой координате отдельно: две полусуммы, по одной на ось.
  • Теряют минус при сложении отрицательных координат. Например, 1 + (−7) считают «наоборот» или забывают знак. Записывай отрицательное число в скобках и складывай по правилам знаков: 1 + (−7) = −6.

Что дальше

Середина — вторая рабочая формула метода координат после расстояния. Дальше по этой же дороге идёт уравнение прямой в координатах: там середина понадобится, например, чтобы описать серединный перпендикуляр.

M( (x₁ + x₂)/2 ; (y₁ + y₂)/2 )

Уже пройденное рядом: расстояние между точками — оно даёт длину медианы, если сначала найти середину. И уравнение окружности — там центр как раз находят как середину диаметра.

Итог одной фразой: координаты середины отрезка — это полусуммы соответствующих координат его концов, посчитанные по каждой оси отдельно.
