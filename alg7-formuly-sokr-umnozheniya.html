Формулы сокращённого умножения

Готовые «заготовки» для самых частых произведений — чтобы раскрывать скобки сразу, без пошагового умножения.

Зачем. Когда перемножаешь скобки вроде (a + b)(a + b), приходится раскрывать и приводить подобные — долго и легко ошибиться. Некоторые произведения встречаются так часто, что для них вывели готовые формулы: подставил — и ответ сразу.

И это не зубрёжка: каждая формула — просто результат обычного умножения многочленов. Понимать вывод важнее, чем заучивать.

Три формулы, которые нужны

Квадрат суммы

(a + b)2 = a2 + 2ab + b2

Квадрат разности

(a − b)2 = a2 − 2ab + b2

Разность квадратов

(a − b)(a + b) = a2 − b2

В первых двух знак между a² и b² всегда +, меняется только знак среднего 2ab (совпадает со знаком в скобке). В третьей — среднего слагаемого нет, оно сокращается, и справа стоит минус. Здесь a и b — любые выражения (число, буква, одночлен).

Главная ошибка всех времён

(a + b)2 ≠ a2 + b2

Среднее слагаемое 2ab теряют чаще всего. Проверь на числах:

(2 + 3)² = 5² = 25   ✗   2² + 3² = 4 + 9 = 13

25 ≠ 13 — значит без 2ab формула неверна. А откуда оно берётся — сейчас увидишь глазами.

Откуда берётся 2ab — покрути сам

Возьмём квадрат со стороной a + b. Его площадь — это (a + b)². Но тот же квадрат распадается на 4 части. Двигай ползунки:

a² — большой квадрат 2ab — два прямоугольника b² — малый квадрат

Видишь: прямоугольников a×b ровно два — вот почему в формуле 2ab, а не просто ab.

Как раскрывать — разбор

Раскрыть (3x + 2)²

  1. Это квадрат суммы → формула a² + 2ab + b², где a = 3x, b = 2.
  2. a² = (3x)² = 9x² — в квадрат возводим весь множитель (и 3, и x).
  3. 2ab = 2 · 3x · 2 = 12x — не забываем двойку из формулы.
  4. b² = 2² = 4.
Ответ: 9x² + 12x + 4

Как выбрать нужную формулу

Видишь квадрат скобки ( )² → это квадрат суммы или разности. В ответе будет три слагаемых.
Видишь две одинаковые скобки с разными знаками (a−b)(a+b) → разность квадратов. В ответе два слагаемых.

Проверь себя

1) Раскрой (a + 7)²
a² + 14a + 49 (2ab = 2·a·7 = 14a).
2) Раскрой (2x − 1)²
4x² − 4x + 1 (a=2x → a²=4x²; 2ab=2·2x·1=4x, со знаком минус).
3) Раскрой (p − 3)(p + 3)
Разность квадратов: p² − 9.
4) Найди ошибку: ученик написал (a + b)² = a² + b².
Потеряно среднее слагаемое. Верно a² + 2ab + b². Проверка: (2+3)²=25, а 4+9=13 — не сходится.
5) Обратная задача: 9x² + 12x + 4 — это квадрат какой суммы?
Это (3x + 2)²: √(9x²)=3x, √4=2, а 2·3x·2=12x совпадает со средним.

Ловушки

  • (a + b)² = a² + b². Нет! Теряется 2ab. Всегда три слагаемых.
  • Не возводят коэффициент в квадрат. (3x)² = 9x², а не 3x². В квадрат идёт весь множитель.
  • Путают формулы. Квадрат скобки → 3 слагаемых; две скобки разных знаков → 2 слагаемых.
  • Теряют минус в квадрате разности — знак относится ко всему второму выражению.

Запомни главное

(a ± b)² = a² ± 2ab + b² · (a − b)(a + b) = a² − b²

Квадрат скобки даёт три слагаемых (не забудь 2ab!), разность квадратов — два. Любую формулу можно проверить, просто перемножив скобки.
