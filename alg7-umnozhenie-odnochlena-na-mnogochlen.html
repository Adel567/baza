Умножение одночлена на многочлен

Главный рабочий инструмент алгебры: множитель перед скобкой обязан «дойти» до каждого слагаемого внутри неё.

Главная идея

m(a + b) = m·a + m·b

Это распределительный закон, знакомый тебе ещё по числам.

Зачем это нужно и где встречается

Скобки не «убирают» — их раскрывают

Умножение одночлена на многочлен нужно везде, где приходится раскрывать скобки: при упрощении выражений, при решении уравнений, при выводе формул сокращённого умножения, при работе с площадями фигур и при разложении на множители (обратная операция — вынесение общего множителя за скобку).

Простой пример из жизни. Пусть прямоугольная грядка имеет ширину a метров, а длину разбили на две части: b метров под морковь и c метров под лук. Тогда общая площадь — это a·(b + c). Но её же можно посчитать как сумму двух кусков: a·b + a·c. Эти два выражения равны — и это и есть наше правило.

Типичное заблуждение: будто «скобки можно просто убрать». Нет. Множитель перед скобкой обязан дойти до каждого слагаемого внутри скобки, а не только до первого.

🎯 В ОГЭ
Раскрытие скобок — базовый шаг в заданиях на упрощение выражений и в уравнениях: почти любое преобразование начинается с того, что одночлен умножают на многочлен.

Что вспомнить перед стартом

Тебе понадобятся три вещи:

1. Умножение одночленов. Коэффициенты перемножаем, а степени с одинаковым основанием складываем: xk · xn = xk+n. Например, 3x · 2x² = 6x³.

2. Правило знаков. «Плюс на минус даёт минус», «минус на минус даёт плюс».

3. Многочлен — это сумма одночленов, и складывать их ты уже умеешь: подобные слагаемые приводятся, результат записывается в стандартном виде.

Ядро темы · правило

Умножь на каждый — и сложи

Словами: чтобы умножить одночлен на многочлен, надо умножить этот одночлен на каждый член многочлена и полученные произведения сложить (с учётом их знаков).

  1. Посмотри, сколько членов в скобке — столько произведений у тебя и получится.
  2. Умножай одночлен по очереди на каждый член, вместе с его знаком.
  3. В каждом произведении: коэффициенты перемножь, а степени одной буквы сложи.
  4. Сложи все произведения и приведи результат к стандартному виду.

m·(t₁ + t₂ + … + tn) = m·t₁ + m·t₂ + … + m·tn

Частные случаи, которые встречаются чаще всего: m(a + b) = ma + mb и m(a − b) = ma − mb. Ограничений на значения букв нет — правило работает для любых чисел. Зелёным всюду в уроке отмечен одночлен-множитель, который «разносится» по скобке.

Разбираем вместе · думаю вслух

Эталонный пример

Упростить: 3x·(2x² − 4x + 5)

В скобке три члена — значит, будет ровно три произведения. Иду по порядку.

  1. 3x · 2x² = (3·2)·(x·x²) = 6x³
    коэффициенты перемножил (3·2 = 6), степени x сложил: 1 + 2 = 3.
  2. 3x · (−4x) = −12x²
    беру член вместе с его знаком: плюс на минус даёт минус; x¹·x¹ = x².
  3. 3x · 5 = 15x
    здесь буква одна, степень не меняется.
  4. Складываю всё, что получилось: 6x³ − 12x² + 15x.
    подобных слагаемых нет — приводить нечего, это и есть ответ.
3x·(2x² − 4x + 5) = 6x³ − 12x² + 15x

Самопроверка: членов в скобке было 3 — и в ответе 3 слагаемых. Ни один не потерян ✓

Допиши шаг сам

Упростить: −2a·(a² + 3a − 6)

−2a · a² = −2a³

−2a · 3a = ______ умножь коэффициенты (−2·3) и сложи степени a

−2a · (−6) = +12a

Проверить себяразбор
Пропущенный шаг: −2a · 3a = −6a². Полный ответ: −2a³ − 6a² + 12a. Обрати внимание на последний член: минус на минус дал плюс.

Теперь целиком сам

Упростить: 4y²·(3y − 2y² + 1)

Показать ответрешай сам
4y² · 3y = 12y³;  4y² · (−2y²) = −8y⁴;  4y² · 1 = 4y². Итого: 12y³ − 8y⁴ + 4y².

Наглядность · почему множитель достаётся каждому

Площадная модель

Представь прямоугольник высотой m, у которого ширина разбита на части a, b и c. Всю площадь можно посчитать двумя способами — и это ровно наше правило:

m
m·aширина a
m·bширина b
m·cширина c

Целиком площадь равна m(a + b + c). По полоскам — m·a + m·b + m·c. Это один и тот же прямоугольник, поэтому выражения равны. Видно, почему высота m достаётся каждой полоске: полоска без своей высоты просто не существует.

Предскажи → проверь → объясни

Возьмём 2x·(x + 3). Сначала предскажи ответ, потом подставь число и проверь, а затем объясни, почему совпадение не случайно. Двигай ползунок — слева считается исходное выражение, справа раскрытое.

Сколько бы ты ни двигал ползунок, два числа совпадают. Причина простая: это площадь одного и того же прямоугольника, посчитанная целиком и по кусочкам.

Теперь ты · реши, потом раскрой ответ

Мини-практика

На сколько произведений распадётся 5·(a − b + c − d)?понимание
На 4 — по числу членов в скобке. Число произведений всегда равно числу членов многочлена.
Сколько произведений получится при раскрытии a·(x + y − z)?понимание
Три — в скобке три члена.
Раскрой скобки: 7m·(m + 2)применение
7m · m = 7m²,  7m · 2 = 14m. Ответ: 7m² + 14m.
Чему равно −3x·(2x − 1)?применение
−3x · 2x = −6x²,  −3x · (−1) = +3x. Ответ: −6x² + 3x.
Найди ошибку: 2x·(x − 3) = 2x² − 3анализ
Множитель 2x не умножили на −3 — до второго члена он просто не дошёл. Верно: 2x·(x − 3) = 2x² − 6x.
Что изменится: сравни 2x·(x + 4) и −2x·(x + 4)анализ
Все знаки в результате поменяются на противоположные: 2x² + 8x и −2x² − 8x. Знак множителя перед скобкой «расходится» по всем членам сразу.
Обратная задача: 6x³ + 9x² = 3x²·(…) — что в скобке?анализ
3x²·(2x + 3). Проверь раскрытием: 3x²·2x + 3x²·3 = 6x³ + 9x² ✓ Это и есть обратная операция — вынесение общего множителя за скобку.

Тренажёр · бесконечная практика

Раскрой скобки сам

Нажми «Новый пример» и раскрой скобки. Ответ пиши многочленом, например 6x^3-12x^2+15x. Степени — через ^ или значок ² (можно «x^2» или «x2»). Знак минус — обычный дефис. Порядок слагаемых любой.

3x(2x² − 4x + 5)

Тренажёр сравнивает твой многочлен с правильным по-честному: приводит подобные и сверяет каждый член. Если ты умножил не на все члены скобки — он это заметит и скажет отдельно.

Где чаще всего ошибаются

Лови эти четыре ловушки

  • Умножают только на первый член скобки: 3x·(x + 2) = 3x² + 2. Множитель обязан «дотянуться» до каждого слагаемого. Проверяй так: число произведений должно быть равно числу членов в скобке. Верно: 3x² + 6x.
  • Теряют знак перед членом. В −2a·(a − 5) забывают, что минус на минус даёт плюс. Сначала определи знак каждого члена скобки вместе с ним самим, потом умножай: −2a·(a − 5) = −2a² + 10a.
  • Ошибаются в степенях: пишут x · x² = x² вместо x³. При одинаковом основании степени складываются — не остаются прежними и не перемножаются.
  • Путают коэффициент и степень: 3x · 2x = 6x вместо 6x². Коэффициенты перемножай (3·2 = 6), а степени складывай (x¹·x¹ = x²).

Проверка понимания · ответь себе

Три вопроса на понимание

Сколько произведений получится при раскрытии a·(x + y − z)?объясни
Три — по числу членов в скобке.
Чему равно −3x·(2x − 1)?объясни
−6x² + 3x. Второй член дал плюс, потому что минус на минус даёт плюс.
Почему нельзя написать 4·(a + b) = 4a + b?объясни
Множитель 4 не умножили на b. Верно: 4a + 4b.

Итог одним предложением: чтобы умножить одночлен на многочлен, умножай этот одночлен по очереди на каждый член многочлена, аккуратно следя за знаками и степенями, и складывай результаты.

Что дальше

Ты научился «разносить» один одночлен по скобке. Дальше скобок станет две:

(a + b)(c + d) = ac + ad + bc + bd

Умножение многочлена на многочлен — это то же самое правило, применённое несколько раз: каждый член первой скобки умножается на каждый член второй. А ещё есть обратный ход — вынесение общего множителя за скобку: там из суммы 6x³ + 9x² получают произведение 3x²(2x + 3).
