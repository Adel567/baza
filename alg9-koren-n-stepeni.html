Корень n-й степени

Квадратный корень ты уже знаешь. Теперь тот же вопрос, но для любой степени: какое число нужно возвести в n-ю степень, чтобы получить данное?

Определение одной строкой

x = ⁿ√a  ⟺  xn = a

n — показатель корня (натуральное, n ≥ 2), a — подкоренное число

Зачем это нужно

Степени бывают не только вторые

В 8 классе ты искал число, квадрат которого равен данному, — например, сторону квадрата по его площади. Но возводить в степень приходится не только во вторую: объём куба со стороной a равен a³, проценты по вкладу за n лет дают множитель в n-й степени, в физике встречается a⁴ и выше.

И тогда возникает обратный вопрос: какое число нужно возвести в 3-ю (4-ю, 5-ю…) степень, чтобы получилось данное? Ответ на него и есть корень n-й степени.

Сразу разрушим главное житейское заблуждение: «корень n-й степени — это то же самое, что разделить на n». Нет. ∛8 — это не 8 : 3, а число, куб которого равен 8, то есть 2 (ведь 2³ = 8). Корень — обратная операция к возведению в степень, а не к умножению.

Что вспомнить с прошлого шага

Квадратный корень: √a — неотрицательное число, квадрат которого равен a. Из отрицательного числа его извлечь нельзя.

Степени: 2³ = 2·2·2 = 8, (−2)³ = −8, (−2)⁴ = +16. Минус в чётной степени пропадает, в нечётной — сохраняется.

Именно из этого свойства знаков вырастет вся сегодняшняя тема.

Суть и обозначения

Корень «отменяет» степень

Словами: корень n-й степени из числа a — это такое число, n-я степень которого равна a.

Обозначим искомое число буквой x. Условие звучит так: xⁿ = a. Само это число x и записывают значком корня: x = ⁿ√a.

Здесь n — показатель корня (натуральное число, n ≥ 2), a — подкоренное число. При n = 2 двойку не пишут и говорят «квадратный корень» (√a), при n = 3 — «кубический» (∛a).

Главный смысл: корень отменяет возведение в степень так же, как вычитание отменяет сложение, а деление — умножение. Поэтому проверять ответ всегда легко: возведи его в нужную степень и сравни с подкоренным числом. Это твой универсальный самоконтроль на всю тему.

Ядро темы

Всё решает чётность показателя n

Определение арифметического корня. Арифметическим корнем n-й степени из неотрицательного числа a (a ≥ 0) называется такое неотрицательное число b, что bⁿ = a. Пишут ⁿ√a = b, где b ≥ 0 и bⁿ = a.

А дальше — самый важный момент темы. Существует корень или нет, зависит от того, чётный n или нечётный:

n нечётное
Корень есть всегда
При n = 3, 5, 7… корень определён для любого a — положительного, отрицательного и нуля, и он единственный. Знак корня совпадает со знаком подкоренного: ∛8 = 2, ∛(−8) = −2.
n чётное, a ≥ 0
Корень есть, он ≥ 0
При n = 2, 4, 6… и неотрицательном подкоренном корень существует и неотрицателен: ⁴√16 = 2 (а не −2).
n чётное, a < 0
Корня не существует
Любое число в чётной степени неотрицательно: и 2⁴, и (−2)⁴ равны 16. Значит получить −16 никакой четвёртой степенью невозможно.

Отдельно: ⁿ√0 = 0 при любом n. И полезное тождество, которое пригодится дальше: если a ≥ 0, то (ⁿ√a)ⁿ = a.

Эталонный пример

Вычислить ∛125

  1. Смотрю на показатель: n = 3 — нечётный, подкоренное 125 > 0. Значит корень существует и он единственный. Почему сначала это: для нечётного n корень есть всегда, и проверять ограничения не нужно, а для чётного — нужно.
  2. Ищу число, куб которого равен 125. Перебираю: 5³ = 5·5·5 = 125. Почему перебираю: по определению ∛125 — это число x с условием x³ = 125, другого способа «увидеть» его нет.
  3. Проверка: 5³ = 125 — совпало с подкоренным числом.
Ответ: ∛125 = 5

  1. n = 4 — чётный, подкоренное 81 > 0 → корень существует, и он неотрицателен.
  2. Ищу неотрицательное число, 4-я степень которого равна 81: 3⁴ = 3·3·3·3 = ____.
  3. Значит ⁴√81 = ____. Проверь себя: возведи свой ответ в 4-ю степень.

Наглядность · интерактив

Почему из −16 корень 4-й степени не достать

Ниже график функции y = xⁿ. Горизонтальная линия — это уровень y = a, то есть само подкоренное число. Сколько раз линия пересекает график — столько решений у уравнения xⁿ = a, а значит столько чисел годятся на роль корня.

Двигай ползунок a вниз, в отрицательную область, и переключай n с чётного на нечётный. Вся тема — вот в этой картинке.

два решения: x ≈ ±2

y = x²,  y = 4

Заметил закономерность? При чётном n обе ветви графика уходят вверх — ниже оси графика просто нет, поэтому при a < 0 линия ни с чем не пересекается: корня не существует. При нечётном n график проходит через всю плоскость снизу вверх, и любая горизонтальная линия пересекает его ровно один раз: корень есть всегда и он один.

То же самое числами. Посчитай x³ и x⁴ для нескольких x и посмотри на строку со знаками:

x−2−1012
x³−8−1018
x⁴1610116

Куб выдаёт и отрицательные значения, и положительные — поэтому ∛ работает на всей числовой прямой. Четвёртая степень «загибает» оба конца вверх, значения только ≥ 0 — поэтому ⁴√ определён лишь для a ≥ 0.

Что изменится: ∛(−8) = −2, а чему равно ⁴√(−8)?анализ

Где чаще всего ошибаются

Лови эти четыре ловушки

  • «Корень чётной степени можно извлечь из отрицательного». Пишут ⁴√(−16) = −2. Неверно: (−2)⁴ = +16, а не −16. Как не допустить: перед извлечением проверь чётность n — при чётном n подкоренное обязано быть ≥ 0.
  • «Корень n-й степени = деление на n». Считают ∛8 как 8 : 3. Как не допустить: помни, что корень обратен степени, а не умножению, и всегда проверяй ответ возведением в степень: 2³ = 8.
  • «Арифметический корень даёт два знака». Пишут ⁴√16 = ±2. Он один и неотрицателен: ⁴√16 = 2. Как не допустить: различай «вычислить корень» (один неотрицательный ответ) и «решить уравнение xⁿ = a» (там при чётном n корней два).
  • Теряют знак при нечётном корне. Забывают, что ∛(−8) существует и равен −2. Как не допустить: при нечётном n знак корня = знаку подкоренного числа.

Сверить ответысамопроверка

Что дальше

Дальше два шага. Первый — свойства корня n-й степени: как корень ведёт себя с произведением, частным и степенью (сегодня ты уже пользовался тождеством ниже).

(ⁿ√a)ⁿ = a   при a ≥ 0

Второй — степень с рациональным показателем: оказывается, корень можно записать степенью, ∛a = a^(1/3), и тогда все правила работы со степенями сразу начинают работать и с корнями.
