Теорема Виета

Короткий путь к корням: для многих уравнений их видно «в уме» — без дискриминанта и длинных вычислений.

Зачем это нужно. Формула корней через дискриминант работает всегда, но она длинная. Теорема Виета — быстрый путь: корни многих уравнений подбираются устно за пару секунд. На контрольной и на ОГЭ это экономит время.

И это не просто «ещё одна формула вместо дискриминанта». Это связь корней с коэффициентами: она нужна дальше, чтобы раскладывать квадратный трёхчлен на множители, сокращать дроби и исследовать квадратичную функцию.

Суть простыми словами

Возьмём приведённое квадратное уравнение — то, где перед x² стоит единица: x² + px + q = 0. Пусть у него есть два корня x1 и x2.

Оказывается, коэффициенты p и q «хранят» информацию о корнях:

x1 + x2 = −p

🟠 Сумма

Сумма корней равна второму коэффициенту, но с противоположным знаком.

x1 · x2 = q

🟢 Произведение

Произведение корней равно свободному члену — просто q, без изменений.

Поэтому решать можно наоборот: подобрать два числа, которые в сумме дают −p, а в произведении q. Эти два числа и есть корни.

Правило и формула

Теорема Виета (для приведённого уравнения). Если x² + px + q = 0 имеет корни x1 и x2, то:

x1 + x2 = −p
x1 · x2 = q
p — коэффициент при x (второй) · q — свободный член · x1, x2 — корни

Уравнение должно быть приведённым (перед x² стоит 1). Если коэффициент другой, например 2x² − 10x + 8 = 0 — сначала раздели всё уравнение на этот коэффициент: x² − 5x + 4 = 0. И ещё: подбирать корни есть смысл, только когда они существуют (дискриминант D ≥ 0).

Хитрость со знаками. Сначала посмотри на знак q: если q > 0 — корни одного знака, если q < 0 — разных. Потом по сумме поймёшь, какой знак «перевешивает». Это сильно сужает перебор.

Разбор по шагам

Решаем x² − 5x + 6 = 0 по Виету. Удобно выписать пары множителей числа 6 и проверить их сумму:

Пара множителейПроизведение (= q)Сумма (= −p)
1 и 667
2 и 365 ← подходит

x² − 5x + 6 = 0

  1. Уравнение приведённое (перед x² единица). Здесь p = −5, q = 6.
  2. Сумму берём с обратным знаком: x1 + x2 = −p = −(−5) = 5. Произведение равно q: x1 · x2 = 6.
  3. Ищем два числа: произведение 6, сумма 5. Из таблицы — это 2 и 3.
  4. Проверка: 2 + 3 = 5 ✓ и 2 · 3 = 6 ✓.
Ответ: x₁ = 2, x₂ = 3

x² + 4x − 5 = 0 (корни разных знаков)

  1. Здесь p = 4, q = −5. Значит x1 + x2 = −4, x1 · x2 = −5.
  2. Произведение отрицательное → корни разных знаков. Нужны числа: произведение −5, сумма −4.
  3. Подходит пара 1 и −5: 1 · (−5) = −5 ✓, 1 + (−5) = −4 ✓.
Ответ: x₁ = 1, x₂ = −5

Обратная задача: составь уравнение с корнями 2 и −7

  1. Сумма корней: 2 + (−7) = −5, значит −p = −5 → p = 5.
  2. Произведение: 2 · (−7) = −14, значит q = −14.
  3. Собираем: x² + px + q = 0 → x² + 5x − 14 = 0.
Ответ: x² + 5x − 14 = 0

Тренажёр · подбери корни

Дано приведённое уравнение — подбери его корни по сумме и произведению. Впиши оба корня через запятую или пробел (порядок неважен).

x² − 5x + 6 = 0

Проверь себя

1) Не решая, назови сумму и произведение корней x² − 9x + 20 = 0.
Сумма = −p = 9, произведение = q = 20. (Сами корни: 4 и 5.)
2) Реши подбором x² − 6x + 8 = 0.
Сумма 6, произведение 8. Пара 2 и 4: 2+4=6 ✓, 2·4=8 ✓. Ответ x₁ = 2, x₂ = 4.
3) Реши x² + x − 12 = 0.
q = −12 < 0 → корни разных знаков. Сумма = −1, произведение = −12. Пара 3 и −4. Ответ x₁ = 3, x₂ = −4.
4) Обратная задача: составь приведённое уравнение с корнями −2 и 6.
Сумма −2 + 6 = 4 → p = −4; произведение −2 · 6 = −12 → q = −12. Уравнение x² − 4x − 12 = 0.
5) Найди ошибку: для 2x² − 10x + 8 = 0 ученик написал «сумма = 10, произведение = 8».
Уравнение неприведённое — так брать нельзя. Сначала делим на 2: x² − 5x + 4 = 0. Тогда сумма = 5, произведение = 4 (корни 1 и 4).

Ловушки

  • Знак у суммы. Сумма корней — это −p, а не p. Произведение — просто q. Сразу делай проверку сложением корней.
  • Неприведённое уравнение. Если перед x² стоит не 1 — сначала раздели всё на этот коэффициент, иначе p и q будут неверными.
  • Проверяй оба условия. Пара должна давать нужное произведение и нужную сумму одновременно. Нашёл по произведению — обязательно проверь сумму.
  • Корней может не быть. Если D < 0, подбирать нечего — целых корней не существует.
  • Знаки подсказывают. q > 0 → корни одного знака; q < 0 → разных. Не пренебрегай этим — сэкономишь перебор.

Запомни главное

x₁ + x₂ = −p  ·  x₁ · x₂ = q

Для приведённого уравнения x² + px + q = 0 сумма корней равна −p, а произведение равно q. Это позволяет подбирать корни устно и решать обратные задачи.
