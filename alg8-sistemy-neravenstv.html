Системы линейных неравенств с одной переменной

Два условия про одно и то же число, соединённых словом «и». Решаешь каждое отдельно — а потом ищешь, где они выполняются одновременно.

Главная мысль темы

Система = «И» = ПЕРЕСЕЧЕНИЕ решений

Ответ — только те числа, что подходят в оба неравенства сразу. На оси это участок, закрашенный обоими.

Зачем это нужно

Когда одному числу нужно угодить сразу двум условиям

Часто одна величина обязана выполнять несколько требований одновременно. Рост для аттракциона: «не ниже 120 см и не выше 180 см». Температура хранения лекарства: «от 2 до 8 градусов». Каждое такое «и» — это система неравенств про одно и то же число.

Житейское заблуждение: «раз условий два, подойдёт число, которое годится хоть для одного из них». Нет. Слово «и» требует, чтобы выполнялись оба условия сразу. Рост 100 см годится «не выше 180», но проваливает «не ниже 120» — значит, на аттракцион не пускают.

Что вспомнить с прошлых шагов

Линейные неравенства. Умеешь решить одно неравенство: перенести слагаемые, разделить на число. Помни правило: делишь на отрицательное — разворачивай знак.

Числовые промежутки. (a; b) — концы не входят, [a; b] — входят; ±∞ всегда с круглой скобкой.

Точка на оси. Строгий знак (<, >) — кружок пустой ○; нестрогий (≤, ≥) — закрашенный ●.

Ядро — как решать

Реши каждое → наложи на одну ось → возьми общую часть

Система записывается фигурной скобкой слева — она и означает «и»:

{x > 1x ≤ 5

«икс больше 1 и икс меньше либо равно 5»  →  ответ (1; 5]

  1. Реши каждое неравенство системы по отдельности — как обычное линейное. Не забудь разворачивать знак при делении на отрицательное.
  2. Отметь решение каждого на одной числовой прямой — своим цветом (или своей штриховкой).
  3. Найди пересечение — участок, попавший в оба решения. Это и есть ответ. Только «двойная зона», где закрашено и тем, и другим.
  4. Запиши ответ числовым промежутком. Если общей части нет — ответ ∅ (система решений не имеет), и это законный ответ.

Считалочка: решил оба → наложил на ось → взял, где перекрылось.

Покрути сам · интерактив

Два неравенства на одной оси

Синий луч — первое неравенство, оранжевый — второе. Зелёным на самой оси подсвечено пересечение — где выполняются оба, это и есть ответ системы. Меняй знаки и границы и смотри, как ответ то сужается, то исчезает совсем.

Приём «предскажи → проверь»: перед тем как двигать, скажи вслух, пересекутся лучи или нет. Особенно ярко на пустом случае x > 5 и x < 2 — лучи смотрят в разные стороны, общей зоны нет.

Разбираем вместе · думаю вслух

Эталонный пример

{2x − 1 > 3x + 4 ≤ 10

  1. Решаю первое: 2x − 1 > 3 → 2x > 4 → x > 2. Перенёс −1 вправо, разделил на 2 (положительное) — знак неравенства не трогаю.
  2. Решаю второе: x + 4 ≤ 10 → x ≤ 6. Перенёс 4 вправо.
  3. Рисую оба на одной оси: x > 2 — луч вправо от 2 (кружок пустой), x ≤ 6 — луч влево от 6 (кружок закрашен). Общая часть — между 2 и 6.
  4. Беру пересечение: 2 < x ≤ 6. Слева граница строгая (○), справа входит (●).
Ответ: (2; 6]. Проверка: x = 5 → в первом 2·5−1=9>3 ✓, во втором 5+4=9≤10 ✓ — оба верны, 5 лежит в промежутке.

Теперь ты · нажми, чтобы проверить

Мини-практика

{ x ≥ −1 ; x < 3 } — прочитай и назови решения из −2, −1, 0, 3понимание
«икс не меньше −1 и икс меньше 3». Решения — те, что подходят в оба: −1 (входит, знак нестрогий) и 0. Число −2 проваливает первое, 3 — второе (строгий знак). Ответ системы: [−1; 3).
Для решения системы ищут объединение или пересечение?понимание
Пересечение. Система — это «и», нужны числа, подходящие сразу в оба неравенства.
{ 3x ≥ 6 ; x − 1 < 4 }применение
Первое: 3x ≥ 6 → x ≥ 2. Второе: x − 1 < 4 → x < 5. Пересечение: 2 ≤ x < 5, то есть [2; 5).
{ 4x − 2 ≥ 6 ; x + 1 < 7 }применение
Первое: 4x ≥ 8 → x ≥ 2. Второе: x < 6. Пересечение: 2 ≤ x < 6, то есть [2; 6).
{ x + 3 > 5 ; 2x ≤ 8 }применение
Первое: x > 2. Второе: 2x ≤ 8 → x ≤ 4. Пересечение: 2 < x ≤ 4, то есть (2; 4].
Что изменится: в { x > 1 ; x < 4 } второе заменили на x < 0. Сколько решений?анализ
Стало x > 1 и x < 0. Первое просит числа правее 1, второе — левее 0. Общих нет: лучи расходятся. Ответ ∅ — ни одного решения.
Найди ошибку: для { x > 2 ; x < 5 } написали «x > 2 или x < 5 — подходят все числа»анализ
Ученик взял объединение вместо пересечения (заменил «и» на «или»). В системе нужны числа, подходящие в оба. Правильно: 2 < x < 5, то есть (2; 5) — а вовсе не «все числа».
Обратная задача: придумай систему двух неравенств с ответом [0; 3)анализ
Левый конец входит (●, нестрогий), правый нет (○, строгий). Например: { x ≥ 0 ; x < 3 }. Проверь пересечение — получится ровно [0; 3).

Тренажёр · бесконечная практика

Реши систему сам

Нажми «Новое», реши каждое неравенство и собери ответ-промежуток: выбери левую скобку и число, правую скобку и число. Если решений нет — жми «∅». Для бесконечной стороны выбери −∞ или +∞. Потом проверь себя или посмотри решение с числовой осью.

{ 2x − 1 > 3x + 4 ≤ 10

Собери ответ. Пример: ( 2 ; 6 ]  или  ( −∞ ; 3 ). Если ответ — одна точка k, собери [ k ; k ] или просто впиши k (можно «x=k»).

Где чаще всего ошибаются

Лови эти ловушки

  • Берут объединение вместо пересечения. Закрашивают всё, что попало хоть в одно решение. Помни: система = «и» = только общее. Ответ — там, где закрашено дважды.
  • Неверно находят пересечение промежутков. Путают, где левая граница, где правая, какой кружок. Защита: рисуй обе границы на одной оси и бери участок, где лучи накладываются.
  • Теряют пустое решение. Когда промежутки не пересекаются (x > 5 и x < 2), пишут «ошибка» или выдумывают число. Нет общей части — это нормальный ответ ∅.
  • Забывают сменить знак. При делении неравенства на отрицательное не переворачивают знак — и получают неправильное решение уже на первом шаге. Проговаривай: «делю на минус — разворачиваю».
  • Путают тип кружка / скобки. Для ≤, ≥ ставят пустой кружок. Есть черта под знаком → точка закрашена ●, скобка квадратная.

Приём «найди, где выполняются оба условия» — фундамент старших классов. В 9 классе он превращается в метод интервалов для квадратичных неравенств: там ось тоже делят на участки и смотрят, где выражение подходит.
