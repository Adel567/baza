Квадратичная функция и парабола

Где появляется «x в квадрате» — там кривая-чаша. Научись узнавать её с одного взгляда и читать три коэффициента.

Где встречается. Высота брошенного мяча над землёй, струя воды в фонтане, форма спутниковой «тарелки» и подвесного троса моста, площадь квадрата от его стороны — всё это парабола. Везде, где одна величина зависит от квадрата другой.

С этой темы начинается большая глава 9 класса: дальше — вершина параболы, её свойства и квадратные неравенства по графику. Не научишься уверенно узнавать квадратичную функцию — вся глава посыплется.

Суть простыми словами

Квадратичная функция — это правило, где главная, самая «сильная» часть — это число, умноженное на x². К нему могут добавляться слагаемое с x и просто число, но слагаемое с x² быть обязано.

Именно x² «сгибает» прямую в кривую: график перестаёт быть прямой линией и становится параболой — плавной симметричной «чашей» или «куполом».

Осторожно с мифом: «раз есть x² — значит парабола» — не всегда правда. У y = x² + 1/x тоже есть x², но там ещё и деление на x — это не квадратичная функция. Парабола получается только у «чистого» вида y = ax² + bx + c.

Определение и три коэффициента

Определение. Функция вида y = ax² + bx + c, где a, b, c — заданные числа и a ≠ 0, называется квадратичной. Её график — парабола.

y = ax² + bx + c
обязательно a ≠ 0 — иначе слагаемое с x² исчезнет и останется прямая
a

Старший

Множитель при x². Главный: должен быть ≠ 0 и решает, куда смотрят ветви.

b

При x

Множитель при x (первая степень). Может быть 0.

c

Свободный

Число без x. Это y при x = 0 — точка пересечения с осью Oy. Может быть 0.

А знак старшего коэффициента a задаёт направление ветвей:

∪ a > 0 — ветви вверх

Парабола-«чаша». У функции есть наименьшее значение.

∩ a < 0 — ветви вниз

Парабола-«купол». У функции есть наибольшее значение.

Область определения: любой x — никаких ОДЗ. Но выражение должно быть целым многочленом степени 2: без деления на x, без x под корнем, без x в знаменателе. Иначе это уже не квадратичная функция.

Разбор — читаю коэффициенты вслух

Главное задание темы: узнать квадратичную функцию и назвать a, b, c вместе со знаками.

y = 3x² − 5x + 2 — квадратичная? Назвать a, b, c и ветви.

  1. Сравниваю с шаблоном y = ax² + bx + c. — сопоставляю слагаемые по степеням x.
  2. Слагаемое с x² — это 3x², значит a = 3.
  3. Слагаемое с x — это −5x, значит b = −5. — минус входит в коэффициент!
  4. Число без x: c = 2.
  5. a = 3 ≠ 0 — функция квадратичная. a = 3 > 0 → ветви вверх ∪.
Ответ: да, квадратичная; a = 3, b = −5, c = 2; ветви вверх.

y = −x² + 4 — определить a, b, c и ветви.

  1. При x² стоит −x², то есть множитель −1 → a = −1.
  2. Слагаемого с x в записи нет → коэффициент при x равен нулю: b = 0.
  3. Число без x: c = 4.
  4. a = −1 < 0 → ветви направлены вниз ∩.
Ответ: a = −1, b = 0, c = 4; ветви вниз.

Покрути параболу сам

Двигай ползунки a, b, c и смотри: знак a переворачивает ветви, c — это точка на оси Oy. Пунктиром показаны ось симметрии и вершина.

y = x²

Поставь a = 0 — и график честно перестаёт быть параболой: получается прямая. Это и есть смысл условия a ≠ 0.

Тренажёр · читай коэффициенты

Нажимай «Новое» — генерируются бесконечные задания трёх типов: назвать коэффициент, определить ветви, отличить квадратичную от других. Впиши ответ и проверь себя.

y = x²это квадратичная функция?

Для коэффициента впиши число со знаком (например −5 или 0). Для ветвей — слово вверх или вниз. Для «квадратичная ли» — да или нет.

Проверь себя

1) В функции y = 2x² − 3x + 6 назови a, b, c.
a = 2 (при x²), b = −3 (при x, со знаком минус), c = 6 (без x).
2) y = −0,5x² + 2x − 1: назови a, b, c и куда направлены ветви.
a = −0,5, b = 2, c = −1. Так как a = −0,5 < 0 — ветви направлены вниз ∩.
3) Найди ошибку: «У функции y = −2x² + 7 коэффициент a = 2».
Потерян знак минус. При x² стоит −2x², значит a = −2 (а не 2). И раз a < 0 — ветви вниз.
4) Почему y = 4x − 1 не квадратичная?
В записи нет слагаемого с x², то есть a = 0. Это линейная функция, её график — прямая, а не парабола.
5) Обратная задача: придумай квадратичную функцию с ветвями вниз, график которой пересекает ось Oy в точке (0; 5).
Ветви вниз → нужно a < 0. Пересечение с Oy в 5 → c = 5. Подойдёт, например, y = −x² + 5 (можно взять любое отрицательное a и b по вкусу, но c = 5).

Ловушки

  • «Любая функция с x² — парабола». Нет: y = x² + 1/x или y = √(x²+1) содержат x², но не квадратичные. Нужен целый многочлен ровно 2-й степени — без деления на x и без x под корнем.
  • Теряют знак коэффициента. В y = 3x² − 5x + 2 пишут b = 5 вместо b = −5. Минус приклеен к числу справа — бери коэффициент вместе со знаком.
  • Путают роли a, b, c. Запомни: a — при x², b — при x, c — без x (и это пересечение с Oy).
  • Забывают про a ≠ 0. Считают y = 5x + 3 квадратичной. Нет слагаемого с x² — это уже линейная функция.
  • Путают параболу с гиперболой. Гипербола y = k/x — две отдельные ветви и x в знаменателе. Парабола — единая симметричная «чаша», x во второй степени.

Запомни главное

y = ax² + bx + c, a ≠ 0

Это квадратичная функция, её график — парабола. a — при x² (главный, ≠ 0), b — при x, c — свободный член (пересечение с Oy). Знак a решает: a > 0 ветви вверх ∪, a < 0 ветви вниз ∩.
