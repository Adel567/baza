Системы второй степени: решаем по графику

Два уравнения — две линии на одной плоскости. Решение системы — там, где линии пересеклись. Видно глазами, сколько решений, ещё до всякой алгебры.

Что значит «решить систему»

{ F(x, y) = 0G(x, y) = 0

Решение — точка (x₀; y₀), которая лежит на обоих графиках сразу

Зачем это нужно

График отвечает на вопрос «сколько решений?»

Система двух уравнений — это вопрос: при каких x и y выполняются оба условия сразу? Каждое уравнение рисует на координатной плоскости свою линию: прямую, параболу, окружность, гиперболу. А решить систему графически — значит найти точки, где эти линии пересекаются: именно там оба уравнения верны одновременно.

Этот способ ценен не точностью, а наглядностью. Он мгновенно показывает, сколько у системы решений — 0, 1, 2 и больше, — ещё до всякой алгебры. Видно, касаются линии или честно пересекаются, и в каких четвертях лежат решения. Дальше ты будешь решать те же системы алгебраически (подстановкой, сложением) — и график станет проверкой: «а правдоподобен ли мой ответ?»

Сразу разрушим главный миф: «графический способ даёт точный ответ». Не даёт. Координаты пересечения почти всегда снимаются с чертежа приближённо. Точные значения даёт только алгебра.

Что вспомнить с прошлых шагов

Уравнение с двумя переменными. График уравнения — это множество всех точек (x; y), которые ему удовлетворяют. Не одна точка, а целая линия.

Построение параболы. y = ax² + bx + c: ветви вверх при a > 0 и вниз при a < 0; вершина в точке xв = −b/(2a); нули — там, где ax² + bx + c = 0.

Прямая y = kx + b однозначно строится по любым двум своим точкам.

Ядро темы · алгоритм

Пять шагов графического способа

  1. Каждое уравнение привести к удобному для построения виду.Например, выразить y через x: y = x² − 1. Или узнать знакомую кривую: x² + y² = 25 — это окружность радиуса 5.
  2. Построить в одной системе координат график каждого уравнения.
  3. Найти все точки пересечения графиков.
  4. Снять (приближённо) координаты этих точек — это и есть решения.
  5. Записать ответ парами: (x₁; y₁), (x₂; y₂), …
Число решений системы = число точек пересечения графиков.

Какие графики чаще всего встречаются в 9 классе — узнавай их по виду уравнения:

Возьмём самую частую пару — прямая и парабола. Вариантов всего три:

2 точки
Два решения
Прямая «прошивает» параболу насквозь.
1 точка
Одно решение
Прямая касается параболы — задевает её ровно в одном месте.

Линии проходят мимо друг друга, общих точек нет.

Где метод «не тянет»: координаты получаются приближёнными. Если решение нецелое (например, x = √7), с чертежа его точно не снять. Поэтому график — для оценки числа решений и грубой проверки, а точный ответ ищут алгебраически.

Разбираем вместе · думаю вслух

Эталонный пример

Решить графически:   { y = x² − 2x − 3 ;   y = x − 3 }

  1. Первое уравнение — парабола: a = 1 > 0, значит ветви вверх. Ищу вершину: xв = −b/(2a) = −(−2)/2 = 1, yв = 1 − 2 − 3 = −4. Вершина (1; −4). Нули: x² − 2x − 3 = 0 → (x − 3)(x + 1) = 0 → x = 3 и x = −1, то есть точки (−1; 0) и (3; 0).Почему именно так: нули показывают, где парабола пересекает ось x, а вершина задаёт «дно». Этих трёх точек уже хватает на аккуратный эскиз.
  2. Второе уравнение — прямая y = x − 3. Беру две точки: при x = 0 получаю y = −3, точка (0; −3); при x = 3 получаю y = 0, точка (3; 0).Почему две точки: прямая однозначно строится по любым двум своим точкам, третью брать не обязательно.
  3. Строю обе линии в одной системе координат и смотрю, где они пересекаются. Вижу две точки пересечения.Смотрю внимательно на обе ветви параболы — вторую точку теряют чаще всего.
  4. Снимаю координаты с чертежа: пересечения в (0; −3) и (3; 0). Тут повезло — обе точки попали в узлы сетки, значит координаты точные.
  5. Проверяю алгеброй (хорошая привычка): приравниваю правые части, x² − 2x − 3 = x − 3 → x² − 3x = 0 → x(x − 3) = 0 → x = 0 или x = 3. При x = 0: y = −3; при x = 3: y = 0. Совпало с чертежом.
Ответ: (0; −3) и (3; 0) — два решения.

Парабола y = x² стоит на месте, а прямую двигаешь ты. Сначала предскажи, сколько будет решений, потом двигай ползунок и проверяй.

Практика по нарастанию

Что геометрически означает решение системы?понимание
Это точка пересечения графиков двух уравнений. Её координаты — та самая пара чисел, которая обращает в верное равенство и первое уравнение, и второе.
Прямая касается окружности. Сколько решений у системы?понимание
Одно. Касание — это ровно одна общая точка, значит и решение одно.
Решить графически: { y = x² − 4 ; y = 0 }применение
Парабола y = x² − 4 (ветви вверх, вершина (0; −4)) и ось x. Пересечение там, где x² − 4 = 0 → x = ±2. Ответ: (−2; 0) и (2; 0) — два решения.
Решить графически: { y = x² ; y = 4 }применение
Парабола y = x² с вершиной (0; 0) и горизонтальная прямая y = 4. Пересекаются там, где x² = 4, то есть x = −2 и x = 2. Точки: (−2; 4) и (2; 4).
Сколько решений и где: { y = −x² + 4 ; y = 1 }применение
Парабола ветвями вниз с вершиной (0; 4) и горизонталь y = 1. Приравниваем: −x² + 4 = 1 → x² = 3 → x = ±√3. Два решения: (−√3; 1) и (√3; 1), то есть примерно (−1,7; 1) и (1,7; 1). На чертеже видно ровно две точки пересечения.
Найди ошибку в ответе к системе { y = −x² + 4 ; y = 1 }анализ
Ученик снял координаты с чертежа и записал в ответ: (−1,7; 1) и (1,7; 1) — как точный ответ. Ошибка не в числах, а в статусе: 1,7 — это прикидка «на глаз». Точный ответ (−√3; 1) и (√3; 1). С графика можно писать только «приближённо ≈ 1,7», а точное значение досчитывают алгеброй.
Что будет с числом решений { y = x² ; y = x + c }, если c увеличивать?анализ
Прямая y = x + c при росте c поднимается вверх, не меняя наклона. Пока она ниже параболы — общих точек нет. В какой-то момент она касается параболы (одно решение), а дальше режет её в двух точках, и точки пересечения расходятся всё дальше друг от друга.
Момент касания ловим алгеброй: x² = x + c, то есть x² − x − c = 0, и один корень бывает при D = 0: 1 + 4c = 0 → c = −1/4. Итого: при c < −1/4 — решений нет, при c = −1/4 — одно (касание), при c > −1/4 — два.

Где чаще всего ошибаются

Четыре ловушки графического способа

  • Считают число решений «на глаз», не разбираясь во взаимном расположении. Пишут «две точки», хотя линии на самом деле касаются (одна точка) или вовсе расходятся (ноль).Как не попасться: аккуратно строй вершину параболы и две точки прямой. Сомневаешься — проверь алгеброй: приравняй правые части и посмотри на дискриминант.
  • Снимают приближённые координаты и выдают их за точные. С чертежа «x ≈ 1,7» переезжает в ответ как точное число.Как не попасться: помни — график даёт оценку. Нецелый ответ либо помечай «приближённо», либо досчитывай точно (например, x = √3).
  • Пропускают одно из пересечений. Чаще всего теряют вторую точку у параболы: нарисовали одну ветвь или оборвали чертёж слишком рано.Как не попасться: строй параболу симметрично относительно её оси x = xв, продлевай обе ветви подальше и проверяй обе стороны от вершины.
  • Путают «решение системы» и «нуль функции». Точки, где парабола пересекает ось x, — это нули, а не решения системы (если только второе уравнение не y = 0).Как не попасться: решение системы — пересечение двух заданных графиков между собой, а не с осями.

Объясни своими словами

  1. Что геометрически означает решение системы двух уравнений?
  2. Почему графический способ обычно даёт лишь приближённый ответ?
  3. Сколько общих точек могут иметь прямая и парабола? Перечисли все случаи.

Скажи ответы вслух, как будто объясняешь однокласснику, и только потом сверься: точка пересечения графиков · координаты снимаются с чертежа на глаз · 0, 1 (касание) или 2.

Итог одним предложением: решить систему графически — значит построить графики обоих уравнений в одной системе координат и найти точки их пересечения, координаты которых и есть (приближённые) решения.

Что дальше

График показал, сколько решений и примерно где они. Теперь нужен точный ответ — за ним идём к алгебре:

Решение систем способом подстановки

Выражаешь одну переменную через другую, подставляешь во второе уравнение — и получаешь точные значения вместо «примерно 1,7». А чертёж из этого урока останется твоей проверкой: столько ли корней вышло, сколько было точек пересечения.

Проверка на выходе: что такое решение системы на чертеже · сколько общих точек у прямой и параболы бывает · почему ответ с графика — приближённый.
