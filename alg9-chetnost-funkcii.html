Чётность и нечётность функции

Это «тип симметрии» функции. Узнаёшь его — и половину графика можно не строить, а достроить отражением. Но только по формуле, не на глаз.

Чётная
f(−x) = f(x)
Симметрия относительно оси Oy
Меняем x на −x — значение не меняется.
Нечётная
f(−x) = −f(x)
Симметрия относительно начала координат O
Меняем x на −x — значение меняет знак.

Зачем это нужно

Симметрия экономит половину работы

Если знаешь, что функция чётная или нечётная, достаточно построить график для x ≥ 0, а левую часть достроить отражением. Этим постоянно пользуются при построении графиков — параболы y = x², гиперболы y = 1/x, — а позже в тригонометрии и старших классах.

Два частых заблуждения, которые надо сразу разрушить:

  • «Раз график вроде симметричный — значит чётная». На глаз симметрию определять нельзя. Нужна проверка по формуле.
  • «Любая функция обязана быть чётной или нечётной». Нет: большинство функций — ни те ни другие (функция общего вида).

Что вспомнить с прошлого шага

Область определения D(f) — множество всех допустимых значений x.

f(x) — значение функции в точке x; f(−x) — значение в противоположной точке. Чтобы найти f(−x), подставляем −x вместо каждого x и упрощаем.

Правило знаков у степеней: чётная степень «съедает» минус — (−x)² = x², (−x)⁴ = x⁴; нечётная степень минус сохраняет — (−x)³ = −x³.

Ядро темы

Два определения через f(−x)

Функция y = f(x) называется:

Чётная
f(−x) = f(x)
для любого x из D(f) (и −x тоже входит в D(f)).
Нечётная
f(−x) = −f(x)
для любого x из D(f) (и −x тоже входит в D(f)).
Если не выполнено ни одно из двух равенств — функция общего вида (ни чётная, ни нечётная). Это самый частый случай.

Обязательное условие

Область определения D(f) должна быть симметрична относительно нуля: вместе с каждым x в неё входит и −x.

Если это не так (например, D(f) = [−2; 5]) — функция не может быть ни чётной, ни нечётной, и проверять формулу уже не нужно.

Как исследовать — 3 шага

Порядок проверки

  1. Найди D(f) и проверь её симметричность относительно 0. Несимметрична → функция общего вида, конец.
  2. Вычисли f(−x): подставь −x вместо x и упрости.
  3. Сравни с f(x) и с −f(x):
    f(−x) = f(x) → чётная;   f(−x) = −f(x) → нечётная;   ни то ни другое → общего вида.

Разбираем вместе · думаю вслух

Эталонный пример

Исследовать на чётность  f(x) = x⁴ − 3x²

  1. D(f) = (−∞; +∞) — все числа, симметрично относительно 0. Степени целые, ограничений на x нет.
  2. f(−x) = (−x)⁴ − 3·(−x)² = x⁴ − 3x². Чётная степень «съедает» минус: (−x)⁴ = x⁴ и (−x)² = x².
  3. Сравниваем: f(−x) = x⁴ − 3x² = f(x). Получили в точности исходное выражение.
Ответ: функция чётная — график симметричен относительно оси Oy.

Исследовать на чётность  f(x) = x³ + x

  1. D(f) = (−∞; +∞), симметрично относительно 0.
  2. f(−x) = (−x)³ + (−x) = −x³ − x. Нечётная степень минус сохраняет: (−x)³ = −x³.
  3. Выносим минус: −x³ − x = −(x³ + x) = −f(x). Значит f(−x) = −f(x).
Ответ: функция нечётная — график симметричен относительно начала координат.

Как «работает» симметрия

Переключай тип и двигай точку x₀. Смотри, куда попадает «зеркальная» точка: у чётной высота сохраняется, у нечётной — точка проходит через центр O.

А вот «зеркальность» в числах — таблица значений f(x) = x³ (нечётная). Смотри: f(−x) всегда противоположно f(x).

x−3−2−10123
f(x) = x³−27−8−101827

Пары «зеркальных» столбцов: f(−2) = −8, а f(2) = 8 — противоположные. Это и есть f(−x) = −f(x).

Практика по нарастанию

Закончи: график чётной симметричен относительно ___, нечётной — относительно ___понимание
Чётной — относительно оси Oy; нечётной — относительно начала координат.
f(4) = 7. Чему равно f(−4), если функция чётная? а если нечётная?понимание
Чётная: f(−4) = f(4) = 7. Нечётная: f(−4) = −f(4) = −7.
Исследуй: f(x) = 5x² − 1применение
f(−x) = 5(−x)² − 1 = 5x² − 1 = f(x) → чётная.
Исследуй: f(x) = 2x³ − xприменение
f(−x) = 2(−x)³ − (−x) = −2x³ + x = −(2x³ − x) = −f(x) → нечётная.
Исследуй: f(x) = x² + 3xприменение
f(−x) = x² − 3x. Это не равно ни f(x) = x² + 3x, ни −f(x) = −x² − 3x → функция общего вида.
Что изменится: в f(x) = x⁴ + ax² + bx сделали b = 0. Будет ли чётной?анализ
При b ≠ 0 мешало слагаемое bx (нечётная степень) — функция была общего вида. Как только b = 0, остаётся x⁴ + ax² — только чётные степени, поэтому f(−x) = x⁴ + ax² = f(x) → да, станет чётной.
Найди ошибку: «f(x) = 1/x определена не везде (x ≠ 0), значит не может быть нечётной»анализ
Ученик неправ. Область определения (−∞; 0) ∪ (0; +∞) симметрична относительно нуля: вместе с каждым x в неё входит и −x (выброшен только сам 0). Значит чётность проверять можно. И проверка даёт: f(−x) = 1/(−x) = −1/x = −f(x) → функция нечётная.
По графику: показана правая половина (x ≥ 0) симметричного относительно O графика. Точка (2; 3) на нём. Найди точку слеваанализ
Симметрия относительно начала координат: точке (x; y) соответствует (−x; −y). Значит слева лежит точка (−2; −3).

Тренажёр · бесконечная практика

Определи тип функции сам

Нажми «Новая функция» и реши: чётная, нечётная или ни та ни другая? Выбери ответ — покажу пошаговую проверку с подстановкой числа.

f(x) = x⁴ − 3x²

Где чаще всего ошибаются

Лови эти ловушки

  • Не проверяют область определения. Сразу считают f(−x), забыв: для функции на отрезке [−1; 4] вопрос о чётности вообще не ставится. Первым шагом всегда пиши D(f).
  • Делают вывод по графику «на глаз». «Вроде симметрично» — не доказательство. Чётность доказывается равенством f(−x) = f(x); график только подсказка.
  • Путают чётную и нечётную. Получили f(−x) = −f(x) — а пишут «чётная», потому что в выражении есть чётные степени. Смотри не на степени, а на итог сравнения.
  • Теряют минус при возведении в степень. Пишут (−x)³ = x³ вместо −x³. Нечётная степень минус сохраняет, чётная — убирает.
  • Считают, что функция обязана быть чётной или нечётной. Помни про третий вариант — «функция общего вида».

Три вопроса на понимание

Какое равенство доказываем для чётной функции? а для нечётной?проверка
Чётная — f(−x) = f(x); нечётная — f(−x) = −f(x).
Почему перед проверкой формулы обязательно смотреть на область определения?проверка
Чётность/нечётность определены, только если D(f) симметрична относительно 0. Иначе для какого-то x точка −x в область не входит — и сравнивать f(−x) просто не с чем.
f(x) = x⁵ − x — какая она и относительно чего симметричен график?проверка
f(−x) = (−x)⁵ − (−x) = −x⁵ + x = −(x⁵ − x) = −f(x) → нечётная, график симметричен относительно начала координат.

Что дальше

Ты уже видел два «эталона»: y = x² — чётная, y = x³ — нечётная. Дальше — тема «Степенная функция»:

y = xⁿ

Там ты увидишь, как чётность y = xⁿ связана с показателем n. А инструмент проверки — равенство f(−x) с f(x) и −f(x) — у тебя уже есть.

Проверка на выходе: запиши равенство для чётной и для нечётной · относительно чего симметричен график каждой · почему сначала смотрим на D(f).
