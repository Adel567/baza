Выделение полного квадрата

Приём, который убирает из уравнения «лишний» x первой степени и превращает его в простое (x + m)² = n. Из него же выведена формула корней.

Ключевое равенство

(x + m)2 = x2 + 2mx + m2

чтобы из x² + 2mx получить полный квадрат, не хватает ровно m²

Зачем это нужно

Почему «в лоб» не решается

Полное квадратное уравнение ax² + bx + c = 0 нельзя решить простым переносом слагаемых: переменная стоит и в квадрате, и в первой степени, и они мешают друг другу. Нужен приём, который уберёт первую степень и сведёт всё к одному квадрату — тогда останется только извлечь корень.

Этот приём и называется выделение полного квадрата. Он важен по двум причинам:

· это универсальный способ решить любое квадратное уравнение — ещё до того, как ты выучил готовую формулу корней;
· именно из него выводится сама формула корней через дискриминант. Формула — не «магия с неба», а краткая запись того, что ты сейчас будешь делать руками.

Позже тот же приём нужен, чтобы найти вершину параболы и привести квадратичную функцию к удобному виду. Так что навык работает на всю старшую школу.

Типичное заблуждение: «раз есть готовая формула корней, выделение квадрата не нужно». На самом деле понимание именно этого вывода отличает того, кто знает математику, от того, кто зазубрил формулу.

Что вспомнить перед стартом

Формула сокращённого умножения: (x + m)² = x² + 2mx + m².

Перенос через знак равенства меняет знак слагаемого: из x² + 6x − 7 = 0 получается x² + 6x = 7.

Квадрат не бывает отрицательным: если справа после сворачивания стоит минус — корней нет.

Ядро темы

Суть в одном движении

Мы хотим переписать левую часть так, чтобы вместо «x² и x по отдельности» получился один точный квадрат (x + m)², плюс некоторое число.

Смотри: чтобы из x² + 2mx получить полный квадрат, не хватает ровно m². Мы его добавляем — но чтобы уравнение не изменилось, тут же его вычитаем (или прибавляем и справа тоже). Добавили и отняли одно и то же — значение не поменялось, а вид стал удобным.

Алгоритм для x² + px + q = 0  (при x² стоит 1)

  1. Перенеси свободный член вправо: x² + px = −q.
  2. Возьми половину коэффициента при x и возведи её в квадрат: (p/2)². Это и есть добавляемое число.
  3. Прибавь (p/2)² к обеим частям: x² + px + (p/2)² = −q + (p/2)².
  4. Сверни левую часть в квадрат: (x + p/2)² = −q + (p/2)².
  5. Извлеки корень с двумя знаками: x + p/2 = ±√(правая часть).
  6. Вырази x.
m = p/2 — половина коэффициента при x. Она же стоит внутри скобки.

Обозначения: p — коэффициент при x (со знаком), q — свободный член (со знаком), m = p/2 — число внутри скобки.

А если при x² стоит не 1?

Если уравнение ax² + bx + c = 0 и a ≠ 1 — первым делом раздели всё уравнение на a, и только потом применяй алгоритм. Например, 2x² + 12x − 14 = 0 делим на 2 и получаем x² + 6x − 7 = 0 — знакомый вид с единицей при x².

Три исхода на последнем шаге

Когда уравнение свёрнуто до (x + m)² = n, всё решает знак числа n справа:

n > 0
Два корня
x + m = ±√n — два разных варианта.
n = 0
Один корень
x + m = 0, то есть x = −m.
n < 0
Корней нет
Квадрат не бывает отрицательным.

Разбираем вместе · думаю вслух

Эталонный пример

x² + 6x − 7 = 0

  1. x² + 6x = 7 почему: хотим слева оставить только то, из чего лепим квадрат; при переносе −7 меняет знак на +7.
  2. 6 : 2 = 3,  3² = 9 почему: сначала пополам, потом в квадрат. В (x + 3)² не хватает именно 3² = 9.
  3. x² + 6x + 9 = 7 + 9,  то есть x² + 6x + 9 = 16 почему: прибавили одно и то же слева и справа — равенство сохранилось.
  4. (x + 3)² = 16 почему: x² + 6x + 9 — это точный квадрат (x + 3)².
  5. x + 3 = ±4 почему: квадрат равен 16, значит само выражение равно +4 или −4.
  6. x + 3 = 4 → x = 1;  x + 3 = −4 → x = −7 разбираем оба случая отдельно — отсюда и берутся два корня.
Ответ: x = 1; x = −7.
Допиши сам: x² − 8x + 12 = 0с пропуском
x² − 8x = −12
Половина от −8 равна −4, в квадрате: (−4)² = 16.
x² − 8x + 16 = −12 + 16 = 4
(x − 4)² = 4 → x − 4 = ±2
x = 6 и x = 2.
Реши сам: x² + 4x − 5 = 0применение
x² + 4x = 5;  (4/2)² = 4;  (x + 2)² = 9;  x + 2 = ±3 → x = 1; x = −5.

Покрути сам · интерактив

Откуда взялось слово «квадрат»

Выражение x² + bx можно выложить из фигур: большой квадрат со стороной x и два прямоугольника шириной b/2. Видно, что до целого квадрата со стороной x + b/2 не хватает одного уголка — и его площадь как раз (b/2)². Вот это число мы и добавляем.

Поставь b нечётным — уголок станет дробным (например, при b = 5 это 2,5 × 2,5 = 6,25). Приём работает точно так же, просто число получается не целым.

Для любознательных

Отсюда и берётся формула корней

Проделай тот же алгоритм не с числами, а с буквами — для ax² + bx + c = 0:

ax² + bx + c = 0  |  : a сначала делим всё на a, чтобы при x² осталась единица
x² + (b/a)·x = −c/a свободный член переносим вправо
половина от b/a это b/(2a), в квадрате — b²/(4a²) то самое «добавляемое число» (p/2)²
(x + b/(2a))² = b²/(4a²) − c/a = (b² − 4ac) / (4a²) справа приводим к общему знаменателю — и вот он, b² − 4ac, дискриминант
x + b/(2a) = ±√D / (2a) извлекаем корень с двумя знаками
x = (−b ± √D) / (2a) та самая формула корней

Видишь: дискриминант — это просто то, что оказалось справа после сворачивания. Его знак и решает, сколько корней, ровно как в трёх исходах выше.

Тренажёр · бесконечная практика

Три типа заданий на один приём

Нажимай «Новое задание»: попадётся либо выделить полный квадрат, либо решить уравнение, либо найти наименьшее значение. Дробные числа пиши через точку или запятую, несколько чисел — через точку с запятой. Если корней нет — так и напиши: нет.

Теперь ты · нажми, чтобы проверить

Мини-практика

Каким выражением свернётся x² + 10x + 25?понимание
(x + 5)², потому что 10 = 2·5, а 25 = 5².
Что прибавить к x² − 12x до полного квадрата?понимание
Половина от −12 равна −6, в квадрате 36. Получится (x − 6)².
Реши: x² + 2x − 8 = 0применение
x² + 2x = 8;  (2/2)² = 1;  (x + 1)² = 9;  x + 1 = ±3 → x = 2; x = −4.
Реши: x² − 6x + 5 = 0применение
x² − 6x = −5;  (−3)² = 9;  (x − 3)² = 4;  x − 3 = ±2 → x = 1; x = 5.
Что изменится: сколько корней у x² + 6x + 9 = 0?анализ
Сворачивается в (x + 3)² = 0 — справа ноль. Значит корень один: x = −3.
Найди ошибку: x² + 6x = 7 → x² + 6x + 9 = 7анализ
Ученик прибавил 9 только слева. Что прибавил слева — прибавь и справа: должно быть x² + 6x + 9 = 16, откуда (x + 3)² = 16.
Обратная задача: подбери c, чтобы у x² − 10x + c = 0 был ровно один кореньанализ
Половина от −10 это −5, в квадрате 25. При c = 25 выйдет (x − 5)² = 0 — один корень x = 5.
Предскажи и проверь: сколько корней у (x − 4)² = 4, у (x − 4)² = 0, у (x − 4)² = −1?анализ
Справа 4 → два корня (x = 6 и x = 2). Справа 0 → один (x = 4). Справа −1 → ни одного: квадрат не бывает отрицательным.

Где чаще всего ошибаются

Пять ловушек

  • Неверно подбирают добавляемое число. Берут сам коэффициент или его квадрат целиком. Делай два действия строго по порядку: сначала пополам, потом в квадрат. Для p = 6 это (6/2)² = 9, а не 36.
  • Прибавляют только к одной части. Добавили (p/2)² слева и забыли справа — равенство сломалось. Правило: что прибавил слева — прибавь и справа, проговаривай это на каждом шаге.
  • Ошибаются со знаком при переносе. Из x² + 6x − 7 = 0 пишут x² + 6x = −7 вместо = 7. Через знак равенства слагаемое меняет знак на противоположный.
  • Теряют второй корень. После (x + m)² = n пишут только +√n. Помни про ±: квадрат даёт ДВА варианта (кроме случая n = 0).
  • Забывают разделить на a при a ≠ 1. Сразу делят пополам коэффициент при x, хотя при x² стоит не единица. Первым делом смотри на коэффициент при x².

Проверка понимания

Объясни своими словами

Какое число прибавить к обеим частям x² + 8x = 5?вопрос
Половина от 8 это 4, в квадрате 16. Получится (x + 4)² = 21.
Почему при извлечении корня из (x + m)² = n появляется ±?вопрос
Потому что и +√n, и −√n при возведении в квадрат дают одно и то же число n.
Сколько корней, если справа после сворачивания стоит отрицательное число?вопрос
Ноль действительных корней: квадрат не бывает отрицательным.

Скажи вслух одной фразой: выделение полного квадрата превращает уравнение в вид (x + m)² = n, добавляя и вычитая (p/2)², — и тем самым решает любое квадратное уравнение.
