Построение графика квадратичной функции

Парабола строится не по случайным точкам, а по опорным: вершина, ось симметрии, нули, точка на Oy. Семь шагов — и график готов.

Алгоритм построения y = ax² + bx + c  (a ≠ 0)

  1. Смотрим знак a — куда ветви.
  2. Вершина по x: x₀ = −b / (2a).
  3. Вершина по y: y₀ = a·x₀² + b·x₀ + c.
  4. Ось симметрии: прямая x = x₀.
  5. Пересечение с Oy: x = 0 → y = c.
  6. Нули: решаем ax² + bx + c = 0 через D.
  7. Пара точек + отражение и плавная кривая.

Порядок важен: сначала вершина и ось, потом всё остальное.

Зачем это нужно

Парабола вокруг тебя

График квадратичной функции — это парабола. Её форму ты видишь каждый день: траектория брошенного мяча, струя воды из фонтана, форма подвесного троса, профиль спутниковой тарелки.

Умея строить параболу, ты сразу «видишь» поведение процесса: где наибольшее или наименьшее значение, при каких x функция положительна, а при каких отрицательна. В самой математике этот навык — фундамент для квадратных неравенств (по графику видно, где парабола выше или ниже оси Ox) и для исследования свойств функции.

Главное заблуждение: «чтобы построить параболу, надо взять побольше случайных точек и соединить их плавной линией». Так получаются кривые «на глаз». На самом деле параболу строят по опорным точкам — вершина, ось симметрии, нули, пересечение с Oy. Тогда график выходит точным и быстрым.

Что вспомнить с прошлых шагов

Что за функция. y = ax² + bx + c, обязательно a ≠ 0: при a = 0 она перестаёт быть квадратичной и становится линейной. Подробно — в уроке «Квадратичная функция и парабола».

Вершина. x₀ = −b / (2a), затем y₀ подстановкой. Если формула ещё не «в пальцах» — вернись в урок «Вершина параболы и ось симметрии».

Дискриминант. D = b² − 4ac — он скажет, сколько точек пересечения с Ox будет. Напоминание — в уроке «Дискриминант».

Коэффициенты берём вместе со знаком: если в формуле стоит − 4x, то b = −4.

Суть — зачем именно эти точки

Четыре опоры параболы

У параболы есть «центр» — вершина, и есть зеркало — ось симметрии. Значит, много точек считать не нужно: находим ключевые и отражаем их.

вершина (x₀; y₀)
Самая нижняя или самая верхняя точка
Нижняя — если ветви вверх, верхняя — если ветви вниз.
ось симметрии x = x₀
Зеркало графика
Левая и правая половины параболы одинаковы.
нули: y = 0
Точки пересечения с Ox
Их может быть две, одна или ни одной — решает знак D.
точка (0; c)
Пересечение с Oy
При x = 0 остаётся только c — считать нечего.

Правило-подсказка: с какой осью пересекаемся — там вторая координата ноль. С Oy — это x = 0, с Ox — это y = 0.

Шаг 1 и шаг 6 — два «решателя»

Знак a и знак D

Два числа задают весь вид графика ещё до построения.

a > 0
Ветви вверх («улыбка»)
У функции есть наименьшее значение — оно в вершине.
a < 0
Ветви вниз («грусть»)
У функции есть наибольшее значение — оно в вершине.
D > 0
Два нуля
Парабола пересекает Ox в двух точках.
D = 0
Один ноль
Вершина лежит прямо на оси Ox.
D < 0
Нулей нет
С Ox пересечений нет — но график есть всегда!

Разбираем вместе · думаю вслух

Эталонный пример

Построить график y = x² − 4x + 3

  1. Коэффициенты: a = 1, b = −4, c = 3. Так как a = 1 > 0 — ветви вверх. Почему: направление задаёт знак старшего коэффициента.
  2. Вершина по x: x₀ = −(−4) / (2·1) = 4/2 = 2. Почему: формула x₀ = −b/(2a); минус перед b «съел» минус у −4.
  3. Вершина по y: y₀ = 2² − 4·2 + 3 = 4 − 8 + 3 = −1. Вершина (2; −1). Почему: подставили найденный x₀ в саму функцию.
  4. Ось симметрии — вертикальная прямая x = 2. Она проходит через вершину, всё остальное будем от неё отражать.
  5. Пересечение с Oy: при x = 0 получаем y = 3. Точка (0; 3). Почему: два первых слагаемых обнулились, остался c.
  6. Нули: x² − 4x + 3 = 0, D = 16 − 12 = 4 > 0, корни x = (4 ± 2)/2 → x = 3 и x = 1. Точки (1; 0) и (3; 0).
  7. Симметрия: точка (0; 3) отражается относительно x = 2 в точку (4; 3). Почему: от 0 до оси ровно 2, откладываем такие же 2 вправо — высота y та же.
Отмечаем (2; −1), (1; 0), (3; 0), (0; 3), (4; 3) и проводим плавную кривую. Ответ: парабола ветвями вверх с вершиной (2; −1).

У y = x² − 4x − 5 вершина по x та же: x₀ = 2 (a и b не менялись), а y₀ = 4 − 8 − 5 = −9. Парабола просто опустилась на 8 вниз. Нули: D = 16 + 20 = 36, x = (4 ± 6)/2 → 5 и −1 — ось Ox она пересекает.

Проверь себя · от простого к анализу

Практика с ответами

y = 2x² − 8x + 5 — куда ветви?понимание
Смотрим только на a = 2. Так как a > 0 — ветви вверх, и у функции есть наименьшее значение.
y = x² − 6x + 8: вершина, ось, нулиприменение
x₀ = 6/2 = 3, y₀ = 9 − 18 + 8 = −1 → вершина (3; −1), ось x = 3. Нули: D = 36 − 32 = 4, x = (6 ± 2)/2 → 2 и 4. Ветви вверх.
Допиши шаг: y = −x² + 2x + 3применение
Начало сделано за тебя: a = −1 < 0 → ветви вниз; x₀ = −2 / (2·(−1)) = −2 / (−2) = 1. Дальше сам: y₀ = −1 + 2 + 3 = 4, вершина (1; 4). Нули: −x² + 2x + 3 = 0 ⟺ x² − 2x − 3 = 0, D = 4 + 12 = 16 → x = −1 и x = 3. Oy: (0; 3).
y = x² + 2x − 3 — весь набор опорприменение
Вершина (−1; −4); ось симметрии x = −1; нули x = −3 и x = 1; пересечение с Oy в точке (0; −3); ветви вверх.
Найди ошибку: вершина y = x² − 4x + 3анализ
Ученик написал x₀ = −b/(2a) = −4/2 = −2. Он потерял, что b = −4, а значит −b = +4. Правильно: x₀ = 4/2 = 2, вершина (2; −1).
Что изменится: к y = x² + 1 добавили −4xанализ
Было y = x² + 1 с вершиной (0; 1). Стало y = x² − 4x + 1: x₀ = 4/2 = 2, y₀ = 4 − 8 + 1 = −3. Вершина уехала в (2; −3) — вправо и вниз, а ось симметрии сдвинулась с x = 0 на x = 2.
Обратная задача: вершина (1; −4), нули −1 и 3анализ
Ветви вверх, значит подойдёт y = x² − 2x − 3. Проверяем: x₀ = 2/2 = 1, y₀ = 1 − 2 − 3 = −4 ✓, D = 4 + 12 = 16 → корни −1 и 3 ✓.

Где чаще всего ошибаются

Лови эти ловушки

  • Строят по 3–4 случайным точкам без вершины. График выходит несимметричным и неточным. Всегда сначала вершина и ось симметрии, потом остальное.
  • Не используют симметрию. Считают отдельно кучу точек слева и справа. Посчитал точку слева — сразу отрази её относительно оси x = x₀: высота y у неё та же.
  • Теряют минус в формуле вершины. Пишут x₀ = b/(2a) вместо −b/(2a), особенно когда b отрицательное. Проговаривай «минус бэ делить на два а» и аккуратно подставляй знак.
  • Путают пересечение с Oy и Ox. С Oy — это x = 0 (значение y = c), с Ox — это y = 0 (решение уравнения).
  • Решают, что параболы нет, если D < 0. График есть всегда — просто он не пересекает ось Ox. D < 0 означает «нет нулей», а не «нет графика».

Проверка понимания

Объясни своими словами

  1. По какой формуле находят x-координату вершины параболы?
  2. Чему равна y-координата точки пересечения графика с осью Oy у функции y = ax² + bx + c?
  3. Если D < 0, сколько точек пересечения параболы с осью Ox?
сверить ответыитог
1) x₀ = −b/(2a).   2) y = c.   3) Ноль — пересечений нет.
Итог одним предложением: чтобы быстро и точно построить параболу, находим вершину и ось симметрии, добавляем нули и точку (0; c), а остальные точки получаем отражением относительно оси.
