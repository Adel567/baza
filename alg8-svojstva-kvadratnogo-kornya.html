Свойства квадратного корня

Знак корня свободно «проходит сквозь» умножение и деление — но никогда сквозь сложение и вычитание. На этом держится вся работа с корнями.

Два свойства корня

√a·b = √a · √b
√a/b = √a / √b

при a ≥ 0 и b ≥ 0 (для деления b > 0)

Зачем это нужно

Корень дружит с × и ÷, но не с + и −

Квадратные корни появляются всюду, где есть площади и теорема Пифагора: диагональ, сторона квадрата по площади, путь по гипотенузе. Часто под корнем стоит «неудобное» число, например √72, и его нужно упростить. Именно свойства корня это позволяют: √72 = √36·2 = 6√2.

Главное заблуждение: «корень можно распределить по любому действию», то есть √a+b = √a + √b. Это неверно. Корень дружит только с умножением и делением. Это главное, что нужно усвоить в теме.

Числовые выражения. Часто нужно вычислить √a·b, корень из дроби или упростить корень — свойства превращают √72 в 6√2 за один шаг.

Что вспомнить с прошлого шага

Арифметический квадратный корень √x — это неотрицательное число, квадрат которого равен x.

То есть √x ≥ 0 и (√x)² = x. Например √100 = 10 (а не ±10).

Под корнем может стоять только неотрицательное число.

Суть темы — с чем корень дружит

Разносим и собираем

Корень из произведения равен произведению корней; корень из частного равен частному корней. Знак корня можно разнести на множители или, наоборот, собрать обратно. Со сложением и вычитанием так нельзя.

✓ Дружит с × и ÷
√a·b = √a · √b
√a/b = √a / √b
Проверка: √9·4 = √9·√4 = 3·2 = 6, и √36 = 6. Совпало.
✗ НЕ дружит с + и −
√a+b ≠ √a + √b
 
Контрпример: √9+16 = √25 = 5, а √9 + √16 = 7. И 5 ≠ 7.

Почему так? Корень — обратное к возведению в квадрат, а (√a·√b)² = a·b. Значит √a·√b — это и есть √a·b. Со сложением не выходит: (√a+√b)² даёт лишнее слагаемое.

Предскажи: чему равно √9+16? Нажми, когда решишь
Многие говорят «7» (это √9 + √16). Но сначала считаем под корнем: 9 + 16 = 25, и √25 = 5. Корень нельзя разносить по сложению.

Наглядность · площадь

Почему √a·√b = √(a·b)

Возьмём прямоугольник со сторонами √a и √b. Его площадь — это произведение сторон, √a·√b. Но та же площадь равна √a·b. Один прямоугольник, два способа записать площадь — значит, они равны.

Разбираем по шагам · интерактив

Упрощаем √200 — шаг за шагом

Нажимай «Следующий шаг» и смотри, как свойства корня превращают неудобное √200 в аккуратный ответ.

√200 — упростить
  1. 200 = 100 · 2 выделяем наибольший множитель-квадрат: 100 = 10²
  2. √200 = √100·2 = √100 · √2 свойство корня из произведения (оба множителя ≥ 0)
  3. = 10 · √2 извлекаем √100 = 10
  4. Ответ: 10√2. Проверка: (10√2)² = 100·2 = 200 ✓

Ещё один эталон

Корень из частного

Вычислить √49/16

  1. Применяем свойство корня из частного (49 ≥ 0, 16 > 0): √49/16 = √49 / √16.
  2. Извлекаем корни отдельно: √49 = 7, √16 = 4.
  3. Собираем ответ: 7 / 4.
√49/16 = 7/4 = 1,75

Практика по нарастанию

Для каких a и b верно √a·b = √a·√b?понимание
Для a ≥ 0 и b ≥ 0. Под корнем должно стоять неотрицательное число, иначе отдельных корней √a, √b может не быть.
Какое равенство верно: √9·4=√9·√4 или √9+4=√9+√4?понимание
Верно первое: корень дружит с умножением. Второе неверно: √13 ≈ 3,6, а √9+√4 = 3+2 = 5.
Вычисли √25·36применение
√25·36 = √25·√36 = 5·6 = 30.
Упрости √50применение
50 = 25·2 → √50 = √25·√2 = 5√2.
Вычисли √81/100применение
√81/100 = √81/√100 = 9/10 = 0,9.
Что станет с √a·b, если оба множителя умножить на 4?анализ
√4a·4b = √16·ab = √16·√ab = 4√ab. Ответ увеличивается в 4 раза.
Найди ошибку: √9+16 = √9+√16 = 3+4 = 7анализ
Корень нельзя разносить по сложению. Считаем под корнем: 9+16 = 25, значит √9+16 = √25 = 5, а не 7.
Обратная задача: какое число под корнем даёт 6√2?анализ
Собираем обратно в один корень: 6√2 = √6²·2 = √36·2 = √72.

Где чаще всего ошибаются

Лови эти ловушки

  • «√(a+b) = √a + √b». Самая частая ошибка. Проверка: √(9+16) = √25 = 5, а √9+√16 = 7. Корень разносится только по × и ÷.
  • Теряют условие неотрицательности. Прежде чем писать √(ab) = √a·√b, проверь, что a ≥ 0 и b ≥ 0.
  • Путают знак при извлечении. √100 = 10, а не ±10. Знак ± появляется при решении x² = 100, но не при вычислении корня.
  • Не выделяют наибольший квадрат. Пишут √72 = √(4·18) = 2√18 и стоп, хотя √18 ещё упрощается. Бери сразу 72 = 36·2 → 6√2.
