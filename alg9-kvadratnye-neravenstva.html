Квадратные неравенства

Уравнение ищет отдельные точки. Неравенство ищет целый промежуток — и найти его проще всего по эскизу параболы.

Как выглядит квадратное неравенство

ax2 + bx + c ⋛ 0

знак ⋛ — это один из четырёх: >, <, ≥, ≤ (a ≠ 0)

Зачем это нужно

Ответ — не число, а участок

Квадратное неравенство отвечает на вопрос «при каких x величина больше (или меньше) нуля». Это нужно везде, где важен диапазон, а не одна точка: при каких размерах сторон площадь не меньше заданной, при каких ценах прибыль положительна, на каком участке полёта мяч выше определённой высоты, при каких значениях параметра у уравнения есть корни (через условие D ≥ 0).

Главное заблуждение: раз неравенство квадратное — жди, как у уравнения, «пару чисел-ответов». На деле ответ — это, как правило, целый промежуток (или объединение двух промежутков), а не отдельные точки.

Что вспомнить с прошлых шагов

Дискриминант. D = b² − 4ac говорит, сколько корней у ax² + bx + c = 0: два, один или ни одного.

Парабола. График y = ax² + bx + c — парабола. Ветви вверх при a > 0 и вниз при a < 0.

Корни — это нули. В точках-корнях парабола пересекает ось Ox; они делят ось на участки, где функция то выше нуля, то ниже.

Ядро темы · алгоритм

Пять шагов через эскиз параболы

Решить неравенство — значит найти все x, при которых функция y = ax² + bx + c имеет нужный знак. Знак удобно «считывать» прямо с рисунка:

  1. Перенеси всё влево, чтобы справа остался 0, а слева — трёхчлен ax² + bx + c.
  2. По знаку a определи направление ветвей: a > 0 — вверх, a < 0 — вниз.
  3. Найди корни уравнения ax² + bx + c = 0 через D = b² − 4ac.
  4. Нарисуй схематичную параболу с этими нулями.
  5. Выдели участки оси, где знак функции совпадает с требуемым — это и есть ответ.

Строгий знак (>, <) — корни в ответ не входят (круглая скобка). Нестрогий (≥, ≤) — корни входят (квадратная скобка).

Три случая по дискриминанту

Сколько раз парабола коснётся оси

D > 0
Два корня x₁ < x₂
Парабола пересекает ось в двух точках. Ось делится на три участка со сменой знака.
D = 0
Один корень x₀
Вершина только касается оси. Функция знак не меняет — везде, кроме x₀, один и тот же знак.
D < 0
Корней нет
Парабола целиком выше оси (при a > 0) или целиком ниже (при a < 0). Знак один и тот же при всех x.

В случаях D = 0 и D < 0 ответ — это либо все числа, либо пусто: смотри знак функции и знак неравенства.

Разбираем вместе · думаю вслух

Эталонный пример

x² − x − 6 > 0

  1. Смотрю на a = 1 > 0 → ветви вверх (знак при x² положительный).
  2. Ищу корни: D = (−1)² − 4·1·(−6) = 1 + 24 = 25, √D = 5. Тогда x = (1 ± 5)/2 → x₁ = −2, x₂ = 3.
  3. Рисую эскиз: парабола ветвями вверх, пересекает ось в −2 и 3. Между корнями она ниже оси (y < 0), вне корней — выше (y > 0).
  4. Мне нужно y > 0 → беру участки ВНЕ корней, там парабола над осью.
  5. Знак строгий → корни не входят, скобки круглые.
Ответ: x < −2 или x > 3, то есть (−∞; −2) ∪ (3; +∞)

На прямой:  ═════◦−2·······◦3═════  (штриховка — ответ, кружки пустые — концы не входят)

Покрути сам · интерактив

Парабола, знак и ответ — одно и то же

Двигай корни и переключай знак неравенства. Парабола красится по знаку функции: зелёная — выше нуля, красная — ниже. Синим подсвечен ответ на оси.

x² − x − 6 > 0

Ответ: (−∞; −2) ∪ (3; +∞)

Поставь оба корня в одну точку — получишь случай D = 0 (парабола касается оси). Тогда ответ становится «все числа» или «пусто».

Теперь ты · нажми, чтобы проверить

Мини-практика

Эскиз: ветви вверх, нули в 1 и 4. Где y < 0?понимание
Ниже оси парабола ветвями вверх находится между корнями. Ответ: (1; 4).
x² − 7x + 10 ≤ 0применение
D = 49 − 40 = 9, корни x = (7 ± 3)/2 → 2 и 5. a > 0, нужно y ≤ 0 → между корнями, знак нестрогий → концы входят. Ответ: [2; 5].
x² + 6x + 9 > 0применение · D = 0
D = 36 − 36 = 0, один корень x = −3. a > 0 → парабола везде y ≥ 0, а в −3 касается оси (там y = 0). Нужно строго y > 0 → подходят все точки, кроме −3. Ответ: (−∞; −3) ∪ (−3; +∞).
x² + 1 > 0применение · D < 0
D = 0 − 4 = −4 < 0, корней нет. a > 0 → парабола целиком выше оси, y > 0 при любом x. Ответ: x — любое число, (−∞; +∞).
Что изменится в x² − x − 6 > 0, если > заменить на ≥?анализ
Сами промежутки те же (корни −2 и 3, берём участки вне них), но теперь знак нестрогий — корни включаются. Ответ становится (−∞; −2] ∪ [3; +∞): круглые скобки у концов сменились на квадратные.
Найди ошибку: «x² − 4 < 0 → x < −2 или x > 2»анализ
Корни ±2, a > 0 (ветви вверх). Ниже нуля (y < 0) парабола находится между корнями, а «x < −2 или x > 2» — это где она выше нуля. Перепутаны «между» и «вне». Правильно: −2 < x < 2, то есть (−2; 2).
При каких m у x² + 4x + m = 0 два разных корня?анализ · обратная задача
Два разных корня — это D > 0. Считаю: D = 16 − 4m > 0 → 16 > 4m → m < 4. Ответ: (−∞; 4). Так квадратное неравенство решает задачу про параметр.

Тренажёр · бесконечная практика

Реши квадратное неравенство сам

Нажми «Новое неравенство», реши через эскиз параболы и запиши ответ-промежуток. Форматы, которые тренажёр понимает:

(−∞; −2) ∪ (3; +∞)  ·  [2; 5]  ·  -2<x<3  ·  x<-2 или x>3  ·  нет (решений нет)  ·  все (любое x). Минус, скобки и ∪ можно с клавиатуры или из подсказки.

x² − x − 6 > 0

Где чаще всего ошибаются

Пять типичных ловушек

  • Выбирают промежутки наугад, без эскиза. Нашли корни — и пишут ответ, не понимая, где функция нужного знака. Всегда рисуй схематичную параболу и смотри, выше или ниже оси нужный участок.
  • Игнорируют знак a. При a < 0 ветви вниз, и «между корнями» парабола уже положительна, а не отрицательна. Первым делом определяй направление ветвей.
  • Путаются при D < 0. «Корней нет → решений нет» — неверно. Решений может быть либо все числа, либо ни одного. Проверь знак функции в любой точке (например x = 0) и распространи на всю ось.
  • Теряют включение концов. Строгий знак — корни не входят (круглая скобка), нестрогий — входят (квадратная). Смотри на знак неравенства в самом конце записи ответа.
  • Случай D = 0 при нестрогом знаке. x² − 2x + 1 ≥ 0 верно при всех x, а ≤ 0 — только в одной точке x = 1. При D = 0 функция лишь касается оси и знак нигде не меняет.

Проверка понимания

Объясни своими словами

Как по знаку a узнать, куда направлены ветви?проверка
a > 0 → ветви вверх (парабола «улыбается»), a < 0 → ветви вниз. Это первое, что определяем, потому что от направления зависит, где функция положительна.
Сколько решений у x² + 5 < 0 и почему?проверка
Ни одного. D = 0 − 20 = −20 < 0, корней нет, а a > 0 → парабола целиком выше оси, y всегда положителен. Быть меньше нуля он не может. Ответ: решений нет.
При каком знаке корни включаются в ответ?проверка
При нестрогом (≥, ≤): в корнях функция равна нулю, а ноль подходит под «≥ 0» или «≤ 0». Значит концы входят — квадратная скобка. При строгом (>, <) — не входят.

Что дальше

Ты научился читать знак по одной параболе. Следующий шаг — метод интервалов: тот же приём, но для произведения нескольких скобок сразу.

(x − 1)(x + 2)(x − 5) > 0

Отмечаешь все нули на прямой и расставляешь знаки по участкам — парабола была частным случаем этого метода.
