Дискриминант и число точек пересечения с осью Ox

Один знак — плюс, ноль или минус — и ты уже знаешь, как парабола ведёт себя рядом с осью: протыкает её, касается или пролетает мимо.

Ключ ко всей теме

D = b2 − 4ac

знак D → число корней → столько же точек пересечения параболы y = ax² + bx + c с осью Ox

Зачем это нужно

Парабола вовсе не обязана пересекать ось

Парабола — это график квадратичной функции y = ax² + bx + c. Очень часто нужно быстро понять: пересекает ли она ось Ox, и если да — в скольких точках.

Точки пересечения с осью Ox — это те x, при которых y = 0. То есть это корни уравнения ax² + bx + c = 0. Значит, вопрос «сколько точек пересечения» и вопрос «сколько корней» — это один и тот же вопрос.

Где это пригодится:

  • при решении квадратных неравенств (ax² + bx + c > 0 и подобных) сначала смотрят, где парабола пересекает ось Ox — без этого не нарисовать эскиз;
  • в физике: высота брошенного тела h(t) = h₀ + v₀t − 5t² — момент падения (h = 0) существует только если парабола вообще достаёт до оси;
  • чтобы не считать корни «вслепую»: знак дискриминанта сразу говорит, есть они или нет.

И вот главное заблуждение, которое надо снести прямо сейчас: «парабола — это же кривая, она обязательно где-то пересечёт ось». Нет. Парабола может целиком лежать выше оси Ox или целиком ниже — и не касаться её вовсе.

Что вспомнить с прошлого шага

Три вещи, без которых дальше никак

1. Квадратичная функция — это y = ax² + bx + c, где a ≠ 0. Её график — парабола. Если a = 0, квадрат пропадает и остаётся прямая — тема уже не про нас.

2. Коэффициенты берём вместе со знаком: в y = x² − 6x + 5 это a = 1, b = −6, c = 5.

3. Из 8 класса: число корней уравнения ax² + bx + c = 0 определяется знаком дискриминанта D = b² − 4ac. Здесь мы этот же факт переводим на язык графика.

Ядро темы

Знак D → число точек на оси Ox

Дискриминант квадратного трёхчлена ax² + bx + c (при a ≠ 0) — это число D = b² − 4ac, где a — старший коэффициент, b — коэффициент при x, c — свободный член.

А теперь само правило — три случая, три цвета:

D > 0
2 точки
Два разных корня. Парабола пересекает ось Ox в двух точках.
D = 0
1 точка
Один корень (два совпавших). Парабола касается оси Ox вершиной.
D < 0
0 точек
Корней нет. Парабола не достаёт до оси: целиком выше её (при a > 0) или целиком ниже (при a < 0).
Знак DЧисло корнейТочки пересечения с осью Ox
D > 02 разных2 точки — парабола пересекает ось
D = 01 (двойной)1 точка — парабола касается оси
D < 0нет0 точек — парабола не достаёт до оси

Условия применимости простые: a ≠ 0, а коэффициенты a, b, c — обычные (действительные) числа.

Отдельно про случай D = 0: единственный корень равен x = −b/(2a) — а это ровно абсцисса вершины параболы. Поэтому «одна точка» означает, что вершина лежит прямо на оси Ox.

Главная идея темы: чтобы ответить на вопрос «сколько точек пересечения», сами корни считать не нужно. Хватает одного знака.

Разбираем вместе · думаю вслух

Эталонный пример

Сколько точек пересечения с осью Ox у параболы y = x² − 6x + 5?

  1. Выписываю коэффициенты: a = 1, b = −6, c = 5. Почему: сравниваю запись с общим видом ax² + bx + c и беру числа со знаками.
  2. Считаю дискриминант: D = b² − 4ac = (−6)² − 4·1·5 = 36 − 20 = 16. Почему: именно D отвечает за число корней. Обрати внимание: (−6)² = +36, минус в скобках исчезает при возведении в квадрат.
  3. Смотрю на знак: D = 16 > 0. Почему: мне важен только знак, а не само число 16. Даже если бы вышло 1000 или 0,3 — вывод был бы тем же.
  4. Делаю вывод: два разных корня → две точки пересечения с осью Ox. Почему: каждый корень — это одна точка на оси, где y обращается в ноль.
Ответ: 2 точки.

Для проверки: корни здесь x = 1 и x = 5 (подставь: 1 − 6 + 5 = 0 и 25 − 30 + 5 = 0). Но для ответа искать их было не обязательно — в этом и весь фокус.

Теперь допиши сам: y = x² − 4x + 4

  1. a = 1, b = −4, c = 4.
  2. D = (−4)² − 4·1·4 = 16 − 16 = ?
  3. D ? 0, значит число точек пересечения = ?

Подсказка: тут будет касание в вершине.

Сверить пропускиразбор
D = 0; D = 0 (равен нулю) → 1 точка: парабола касается оси Ox в вершине x = −(−4)/(2·1) = 2.

И один для самостоятельного решения: y = 2x² + 3x + 5

Сколько точек пересечения с осью Ox?применение
a = 2, b = 3, c = 5; D = 3² − 4·2·5 = 9 − 40 = −31 < 0 → 0 точек, парабола не пересекает ось Ox.

Наглядность · три картинки рядом

Поднимаем параболу — и точки исчезают

Возьмём одно семейство: a = 1 и b = −6 держим неизменными, меняем только свободный член c. Это значит, что мы просто поднимаем параболу вверх. Смотри, что происходит с точками на оси:

y = x² − 6x + 5 D = 36 − 20 = 16 2 точки
y = x² − 6x + 9 D = 36 − 36 = 0 1 точка
y = x² − 6x + 13 D = 36 − 52 = −16 0 точек

Парабола ползёт вверх, и в какой-то момент вершина ровно ложится на ось — это и есть D = 0, граница между «две точки» и «ни одной». Ещё чуть выше — и общих точек с осью уже нет.

Предскажи → проверь → объясни. Возьми функцию y = x² − 2x + 5. Сначала предскажи на глаз: как думаешь, сколько будет точек пересечения? Потом посчитай.

y = x² − 2x + 5 — проверка и объяснениепонимание
D = (−2)² − 4·1·5 = 4 − 20 = −16 < 0 → 0 точек. Почему график не достаёт до оси: ветви направлены вверх (a = 1 > 0), а вершина лежит выше оси Ox — значит, вся парабола висит над осью.

Покрути сам · интерактив

Считаем точки живьём

Двигай ползунки a, b, c. Счётчик слева сверху показывает, сколько точек пересечения с осью Ox сейчас у параболы, а рядом — знак дискриминанта. Лови момент перехода 2 → 1 → 0.

2 точки пересечения с осью Ox D = 16 > 0

y = x² − 6x + 5

Подними параболу ползунком c и следи за счётчиком: 2 → 1 → 0. Момент «1» очень узкий — это ровно D = 0. А при a = 0 квадрат исчезает и это уже не парабола, а прямая — потому в правиле и стоит a ≠ 0.

Практика по нарастанию

От понимания до анализа

У параболы D = 0. Сколько раз она встречается с осью Ox и как называется эта точка?понимание
Один раз — и это не пересечение, а касание. Точка касания — вершина параболы, её абсцисса x = −b/(2a).
y = x² + x − 12 — число точек пересечения с осью Ox (корни не искать)применение
a = 1, b = 1, c = −12; D = 1² − 4·1·(−12) = 1 + 48 = 49 > 0 → 2 точки. Осторожно со знаком: −4·1·(−12) = +48.
y = x² − 2x + 7 — число точек пересечения с осью Oxприменение
D = (−2)² − 4·1·7 = 4 − 28 = −24 < 0 → 0 точек.
y = 9x² − 6x + 1 — число точек пересечения с осью Oxприменение
D = (−6)² − 4·9·1 = 36 − 36 = 0 → 1 точка (касание в вершине).
Что изменится, если… У параболы y = x² + bx + 9 ровно одна общая точка с осью Ox. Найди все b.анализ
«Ровно одна общая точка» = касание = D = 0. Считаем: D = b² − 4·1·9 = b² − 36. Приравниваем к нулю: b² − 36 = 0 → b² = 36 → b = 6 или b = −6.
Проверка: при b = 6 получаем y = x² + 6x + 9, D = 36 − 36 = 0 ✓; при b = −6 — y = x² − 6x + 9, D = 36 − 36 = 0 ✓.
Ответ: b = 6 и b = −6.
Найди ошибку. Ученик пишет: «D = b² − 4ac = 3² − 4·2·5 = 9 − 40 = −31 > 0, значит две точки».анализ
Арифметика верна: 9 − 40 = −31. Ошибка в сравнении со знаком: число −31 меньше нуля, а не больше. Правильно: D = −31 < 0 → 0 точек, парабола не пересекает ось Ox.
Мораль: отрицательное число всегда меньше нуля, каким бы большим ни казался его модуль.
Обратная задача. Парабола не пересекает ось Ox. Что можно сказать о знаке её дискриминанта?анализ
Раз общих точек с осью нет, то и корней нет — а корней нет только при D < 0. Значит, дискриминант отрицателен. Дополнительно: если при этом ветви вверх (a > 0), парабола лежит целиком выше оси; если вниз (a < 0) — целиком ниже.

Где чаще всего ошибаются

Пять ловушек этой темы

  • Посчитали D — и остановились. Дискриминант сам по себе не ответ. Держи в голове цепочку: знак D → число корней → столько же точек на оси Ox. Вопрос был про точки — про них и отвечай.
  • «Парабола всегда пересекает ось Ox». Неверно. При D < 0 она целиком над осью (если a > 0) или целиком под осью (если a < 0), и общих точек с Ox нет вообще.
  • Путаются при D = 0. Говорят «точек нет» или «две точки». На самом деле ровно одна — касание в вершине. Это отдельный, третий случай, а не вариант первых двух.
  • Теряют знак при подсчёте D. Особенно при отрицательном b: (−6)² = +36, а не −36. И −4ac при c < 0 даёт плюс. Подставляй коэффициенты в скобках — тогда знак не потеряется.
  • Путают «число корней» и «значения корней». Для этого вопроса сами корни считать не надо: достаточно знака D. Лишние вычисления — лишние шансы ошибиться.

Проверка понимания

Ответь себе вслух, не подглядывая

  1. Чему равен дискриминант трёхчлена ax² + bx + c?
  2. Парабола касается оси Ox в одной точке. Какой знак у её дискриминанта?
  3. У квадратичной функции D = −5. Сколько точек пересечения её графика с осью Ox?
  4. Объясни своими словами, почему парабола может вообще не встретиться с осью Ox.
Сверить ответысамопроверка
1) D = b² − 4ac.   2) D = 0.   3) Ноль точек.   4) Потому что она может целиком лежать выше оси (ветви вверх, вершина над осью) или целиком ниже (ветви вниз, вершина под осью) — и тогда значение y = 0 не достигается ни при каком x.

Итог одним предложением: знак дискриминанта D = b² − 4ac сразу даёт число точек пересечения параболы с осью Ox — две при D > 0, одну при D = 0 и ни одной при D < 0.
