Уравнение x² = a

Самое простое квадратное уравнение — и главная ловушка восьмого класса: корень почти всегда не один.

Если a > 0

x = ±√a

читается «икс равно плюс-минус корень из a» — это сразу два числа

Зачем это нужно

Где ты это встретишь

Уравнение вида x² = a появляется везде, где есть площадь и сторона. Знаешь площадь квадратного участка S, ищешь его сторону x — это ровно x² = S. Знаешь площадь круга, ищешь радиус — снова уравнение такого вида. В физике из формулы свободного падения h = gt²/2 ищут время t — и опять приходят к «t² = число».

А теперь про главное заблуждение. Многие думают: «корень — это просто другое название для √, и ответ всегда один». Это не так. У уравнения x² = a при положительном a всегда два корня: один положительный и один отрицательный. Их очень легко потерять, если решать на автомате.

Что вспомнить с прошлого шага

√a — арифметический квадратный корень: это одно неотрицательное число, квадрат которого равен a.

Он существует только при a ≥ 0 и сам всегда ≥ 0. Например √9 = 3 — только 3, никакого −3.

Квадрат любого числа неотрицателен: 5² = 25 и (−5)² = 25.

Суть темы

Не путай две разные вещи

Решить уравнение x² = a — значит найти ВСЕ числа, квадрат которых равен a. И вот здесь надо чётко различать два объекта:

√a

Арифметический корень. Одно неотрицательное число.

√25 = 5

корни x² = a

Решения уравнения. Их может быть два, один или ни одного.

x = 5 и x = −5

Почему так? Потому что возведение в квадрат «склеивает» противоположные числа: и 3, и −3 дают 9. Поэтому, «разворачивая» квадрат обратно, мы обязаны вернуть оба числа: x = √a и x = −√a. Коротко это пишут так: x = ±√a.

Правило · вся тема в трёх строчках

Смотрим на знак a

Что означают буквы

x — неизвестное, то, что ищем. a — заданное число в правой части. Знак ± означает «два значения сразу»: и с плюсом, и с минусом.

Условие применимости. Правило работает именно для вида x² = a. Если перед x² стоит коэффициент или есть лишние слагаемые (например 3x² = 12 или x² − 5 = 0), сначала приведи уравнение к виду x² = a, то есть вырази x².

Покрути сам · интерактив

Парабола и прямая: откуда берутся два корня

Нарисуем параболу y = x² и горизонтальную прямую y = a. Точки их пересечения — это и есть корни уравнения x² = a. Двигай ползунок и следи за числом точек.

a = 4 > 0 · два корня: x = −2 и x = 2

Предскажи → проверь → объясни. Сначала скажи вслух, сколько будет точек, и только потом двигай ползунок. Поймай момент, когда прямая только касается вершины — это a = 0, граница между «два корня» и «ни одного». И заметь: две точки всегда стоят симметрично относительно оси Oy — вот почему корни идут парой +√a и −√a.

Разбираем вместе · думаю вслух

Эталонный пример

Решить x² = 25

  1. Смотрю на a = 25. Оно больше нуля — значит, корней два. Проверка знака a — это всегда первый шаг, до всяких вычислений.
  2. Считаю √25 = 5. Почему именно 5? Потому что 5 ≥ 0 и 5² = 25. Арифметический корень — неотрицательный, беру только его.
  3. Ставлю знак ±: x = √25 или x = −√25, то есть x = 5 или x = −5. Минус не теряю: (−5)² тоже равно 25.
  4. Проверяю оба: 5² = 25 ✓ и (−5)² = 25 ✓.
Ответ: x = 5; x = −5.

Теперь с пропущенным шагом — допиши сам

Решить 2x² = 18разбор
Сначала выражаем x²: делим обе части на 2, получаем x² = 9.
a = 9 > 0 — корней два. √9 = 3, поэтому x = 3 или x = −3.
Ответ: x = 3; x = −3.
Решить x² = 0,49сам
a = 0,49 > 0 — корней два, потому что 0,7² = 0,49.
Ответ: x = 0,7; x = −0,7.

Практика по нарастанию

Сколько корней у x² = 36? у x² = 0? у x² = −4?понимание
Два (потому что 36 > 0); один (a = 0); ни одного (−4 < 0).
Прочитай вслух запись x = ±√7понимание
«Икс равно плюс-минус корень из семи». Означает, что у уравнения x² = 7 два корня: x = √7 и x = −√7.
Реши: а) x² = 64   б) x² = 1   в) x² = 0   г) x² = −9применение
а) x = 8; x = −8
б) x = 1; x = −1
в) x = 0 — один корень
г) корней нет: −9 < 0
Реши, предварительно выразив x²: 5x² = 45применение
Делим обе части на 5: x² = 9. Дальше как обычно: a = 9 > 0, √9 = 3. Ответ: x = 3; x = −3.
Что изменится, если в x² = a заменить 16 на −16?анализ
Было x² = 16 — два корня (x = 4 и x = −4). Стало x² = −16 — корней не стало вообще. Причина: квадрат любого числа неотрицателен, он просто не может равняться отрицательному числу. Число корней «упало» с двух до нуля, потому что знак a перескочил через ноль.
Найди ошибку: «x² = 49, значит x = 7»анализ
Ученик нашёл только √49 = 7 и остановился — потерял второй корень. Но (−7)² = 49 тоже верно. Верный ответ: x = 7; x = −7.
Подбери такое a, чтобы у x² = a был ровно один кореньанализ
a = 0. Тогда единственный корень x = 0. При любом положительном a корней сразу два, при отрицательном — ни одного, так что ровно один корень бывает только в этом единственном случае.

Тренажёр · бесконечная практика

Реши уравнение сам

Нажми «Новое уравнение». Если корней два — введи оба через точку с запятой (5; −5). Если корень один — просто 0. Если корней нет — напиши нет. Дробные ответы можно писать и через запятую, и через точку.

x² = 25

Где чаще всего ошибаются

Четыре ловушки

  • Теряют второй, отрицательный корень. Пишут «x² = 25, значит x = 5» — и всё. Как не допустить: как только нашёл √a, сразу ставь знак ± и проговаривай «и плюс, и минус».
  • При a < 0 придумывают корни. Для x² = −4 пишут x = ±2 или x = √(−4). Как не допустить: помни — квадрат любого числа НЕ бывает отрицательным. При a < 0 ответ один: «корней нет».
  • Забывают случай a = 0. Думают, что ноль даёт два корня: 0 и −0. Как не допустить: −0 и 0 — это одно и то же число. Значит, корень ровно один: x = 0.
  • Путают √a и корни уравнения. Считают, что √25 = ±5. Как не допустить: √ всегда даёт ОДНО неотрицательное число (√25 = 5). Знак ± появляется только при решении уравнения x² = a.

Проверь себя · объясни своими словами

Три вопроса на понимание

  1. Сколько корней у уравнения x² = a в каждом из трёх случаев: a > 0, a = 0, a < 0?
  2. Чему равно √36 и чему равны корни уравнения x² = 36? В чём разница между этими двумя ответами?
  3. Почему уравнение x² = −5 не имеет корней?

Если можешь ответить на все три вслух, не подглядывая, — тема взята. Если запнулся на втором, вернись к блоку «Не путай две разные вещи».

Что дальше

Ты научился решать x² = a — это фундамент. Следующий шаг: неполные квадратные уравнения, где не хватает одного из слагаемых:

a·x² + c = 0   и   a·x² + b·x = 0

Первый вид решается ровно тем, что ты уже умеешь: выражаешь x², получаешь x² = число — и дальше три случая по знаку. А оттуда уже вырастает общий метод решения любых квадратных уравнений.
