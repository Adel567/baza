Теорема косинусов

Как найти сторону любого треугольника, когда Пифагора уже не хватает, — по двум сторонам и углу между ними.

Где встречается. Крыша дома, треугольный участок земли, маршрут корабля, который сначала шёл в одну сторону, а потом повернул на какой-то угол. Известны две стороны и угол между ними — а третью надо найти. В жизни углы редко бывают ровно 90°, и «через Пифагора» тут не посчитать: он просто не работает.

Теорема косинусов снимает это ограничение. Это рабочий инструмент в геодезии, навигации, строительстве и дальше в математике — тригонометрии и векторах.

Сначала вспомни две вещи

Новая формула вырастает прямо из того, что ты уже знаешь:

1. Теорема Пифагора. В прямоугольном треугольнике c2 = a2 + b2. Работает только при угле 90°.

2. Косинус угла. Число, зависящее от величины угла. Табличные значения, которые сегодня нужны: cos 60° = 0,5, cos 90° = 0, cos 120° = −0,5. Для тупого угла косинус отрицательный — это нормально.

Типичное заблуждение: «раз есть стороны — посчитаю по Пифагору». Пифагор — это частный случай, верный только при прямом угле. Теорема косинусов — общий закон для всех треугольников.

Ядро — сама формула

Для треугольника со сторонами a, b, c, где угол C лежит между сторонами a и b:

c2 = a2 + b2 − 2ab·cosC
a, b — две стороны, между ними угол C · c — сторона напротив угла C (её и ищем)

Словами: квадрат стороны равен сумме квадратов двух других сторон минус удвоенное произведение этих сторон на косинус угла между ними.

Смысл «лишнего» слагаемого −2ab·cosC — это поправка на угол, она показывает, насколько треугольник «отклонился» от прямоугольного. Теорема косинусов — это теорема Пифагора с поправкой на угол.

Если известны все три стороны, из этой же формулы можно выразить косинус угла:

cosC = (a2 + b2 − c2) / 2ab

Поправка на угол: три случая

Всё держится на знаке косинуса. Сравни поправочный член −2ab·cosC в трёх ситуациях:

Угол острый

cosC > 0

Вычитаем положительное → сторона c короче, чем при прямом угле.

Угол прямой

cos90° = 0

Поправка исчезает → остаётся ровно Пифагор c2=a2+b2.

Угол тупой

cosC < 0

Двойной минус даёт плюс → сторона c длиннее.

Разбор «думаю вслух»

Классика: даны две стороны и угол между ними — найди третью. Идём по шагам.

a = 7, b = 5, угол C между ними = 60°. Найти c.

  1. Пишем формулу для стороны напротив известного угла: c2 = a2 + b2 − 2ab·cosC.
  2. Подставляем: c2 = 72 + 52 − 2·7·5·cos60°.
  3. Табличное значение: cos60° = 0,5.
  4. Считаем: c2 = 49 + 25 − 70·0,5 = 49 + 25 − 35 = 39.
  5. Корень: c = √39 ≈ 6,24.
  6. Проверка смысла: угол острый, поэтому c ≈ 6,24 меньше, чем было бы при прямом угле (√74 ≈ 8,6). ✓
Ответ: c = √39 ≈ 6,24

a = 8, b = 3, угол C = 120° (тупой). Найти c.

  1. c2 = 82 + 32 − 2·8·3·cos120°.
  2. cos120° = −0,5 — угол тупой, косинус отрицательный.
  3. Аккуратно с двумя минусами: −2·8·3·(−0,5) = +24, значит удвоенное произведение прибавляется:
    c2 = 64 + 9 + 24 = 97.
  4. c = √97 ≈ 9,85.
  5. Проверка: угол тупой → c длиннее, чем при прямом угле (√73 ≈ 8,5). ✓
Ответ: c = √97 ≈ 9,85

Стороны a = 6, b = 10, c = 14. Найти угол C (напротив стороны 14).

  1. Известны все три стороны → берём вторую формулу: cosC = (a2 + b2 − c2) / (2ab).
  2. cosC = (36 + 100 − 196) / (2·6·10) = (−60) / 120 = −0,5.
  3. Косинус отрицательный → угол тупой. По таблице cosC = −0,5 даёт C = 120°.
Ответ: C = 120°

Увидь глазами — раскрываем угол C

Стороны a и b закреплены и выходят из вершины C. Двигай угол C ползунком и смотри, как меняется сторона c напротив него: острый угол — c короткая, тупой — c длинная.

Оранжевая — сторона a, бирюзовая — сторона b, синяя — искомая сторона c напротив угла C. Проходя через 90°, c ведёт себя ровно как Пифагор.

Таблица «угол → косинус → длина c»

Возьмём равные стороны a = b = 5 и меняем только угол между ними. Смотри, как растёт c:

Угол Ccos Cc2 = 25 + 25 − 50·cosCсторона c
60°0,550 − 25 = 25c = 5
90°050 − 0 = 50c ≈ 7,07
120°−0,550 + 25 = 75c ≈ 8,66

Стороны те же, а c растёт вместе с углом — потому что косинус уменьшается (от 0,5 к −0,5), и поправка из «вычитаем» превращается в «прибавляем».

Тренажёр · найди сторону c

Даны две стороны и угол между ними — найди третью. Углы подобраны так, что ответ выходит целым. Заданий — бесконечно.

Стороны a = 5 и b = 8, угол между ними C = 60°. Найди сторону c (напротив угла C).

Подставь стороны и cos угла в формулу, посчитай c2, потом извлеки корень.

Проверь себя

Понимание

1) Напиши теорему косинусов для стороны b. Какой угол в ней стоит и где он?
b2 = a2 + c2 − 2ac·cosB. В формуле стоит угол B — он лежит напротив стороны b и между сторонами a и c.

Применение

2) Две стороны 4 и 9, угол между ними 45°. Найди третью сторону. (cos45° = √2/2 ≈ 0,707.)
c2 = 42 + 92 − 2·4·9·cos45° = 16 + 81 − 72·0,707 ≈ 97 − 50,9 = 46,1. Значит c ≈ √46,1 ≈ 6,8. Ответ ≈ 6,8.

Анализ

3) «Что изменится, если…»: стороны 4 и 9 те же, а угол увеличили с 45° до 135°. Станет c длиннее или короче? Без вычислений.
Длиннее. При 45° косинус положительный — поправку вычитаем. При 135° угол тупой, cos135° < 0 — двойной минус даёт плюс, поправку прибавляем. Значит c2 больше, и сторона c длиннее.
4) Найди ошибку: для a = 5, b = 6, C = 60° ученик написал c2 = 52 + 62 + 2·5·6·cos60°.
Перед удвоенным произведением должен быть минус, а не плюс: c2 = 52 + 62 − 2·5·6·cos60°. Верно: c2 = 25 + 36 − 60·0,5 = 25 + 36 − 30 = 31, значит c = √31 ≈ 5,57. У ученика вышло бы 91 — слишком много.
5) Обратная задача: стороны 5, 7, 8. Остроугольный ли треугольник? Найди косинус наибольшего угла (напротив стороны 8).
Наибольший угол — напротив наибольшей стороны 8: cosC = (52 + 72 − 82) / (2·5·7) = (25 + 49 − 64) / 70 = 10/70 ≈ 0,143. Косинус положительный → наибольший угол острый → треугольник остроугольный.

Ловушки

  • Теряют минус. Пишут c2 = a2 + b2 + 2ab·cosC. Запомни «минус два аб косинус» как единое выражение: для острого угла сторона должна стать короче, а значит мы вычитаем.
  • Берут не тот угол. В формулу идёт угол напротив искомой стороны и между двумя данными. Сначала отметь на чертеже сторону c, потом угол напротив неё — только его косинус.
  • Путают с Пифагором. Считают c2 = a2 + b2, когда угол не 90°. Пифагор — это теорема косинусов при C = 90°; при другом угле обязателен член −2ab·cosC.
  • Забывают про тупой угол. Там cosC < 0, и «двойной минус» даёт плюс. Сначала определи знак косинуса, потом аккуратно раскрой два минуса — иначе c выйдет слишком маленькой.

Объясни своими словами

1) Запиши теорему косинусов для стороны c и назови угол, который в неё входит.
c2 = a2 + b2 − 2ab·cosC. Входит угол C — между сторонами a и b, напротив искомой стороны c.
2) Во что превращается теорема косинусов, если угол между сторонами 90°?
cos90° = 0, поправка −2ab·0 = 0 исчезает, и остаётся теорема Пифагора c2 = a2 + b2.
3) Косинус угла получился отрицательным. Что это говорит про угол?
Угол тупой (больше 90°). Это не ошибка — теорема косинусов честно работает и для тупоугольных треугольников.

Запомни главное

c2 = a2 + b2 − 2ab·cosC

Теорема косинусов — это обобщение Пифагора на любой треугольник. По двум сторонам и углу между ними находим третью сторону; по трём сторонам находим угол. Угол C — между сторонами a и b, напротив искомой c. Минус перед 2ab·cosC терять нельзя.
