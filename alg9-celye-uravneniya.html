Целые уравнения и их корни

Уравнения с кубами и четвёртыми степенями пугают только на вид. У всех один план: привести к виду «многочлен = 0», разложить на множители — и корни находятся сами.

Стандартный вид целого уравнения

anxn + an−1xn−1 + … + a1x + a0 = 0

n — степень уравнения (старший показатель при x), причём an ≠ 0

Зачем это нужно

Не только линейные и квадратные

В 7 классе ты решал линейные уравнения, в 8 — квадратные. Но в задачах встречаются уравнения посложнее: с кубами, четвёртыми степенями, скобками и произведениями. Например, объём коробки — это произведение трёх измерений, и поиск нужного размера приводит к уравнению третьей степени.

Всех их объединяет одно: в них нет деления на выражение с переменной и нет переменной под корнем. Это и есть целые уравнения. План работы всегда один: привести к виду «многочлен = 0», определить степень, прикинуть, сколько может быть корней.

Главный миф, который тут надо разрушить: «если степень уравнения 4 — значит и корней ровно 4». Это неверно. Степень — только потолок для числа корней; корней может быть и меньше.

Что вспомнить с прошлых шагов

Линейное (7 класс): степень 1, не больше одного корня, вида kx + b = 0.

Квадратное (8 класс): степень 2, не больше двух корней, вида ax² + bx + c = 0.

Любое уравнение сначала переносим всё в одну часть и приводим подобные — получаем «многочлен = 0».

Суть темы

Что такое целое уравнение

Уравнение называют целым, если его левая и правая части — целые выражения (многочлены): переменная встречается только в сложении, вычитании, умножении и возведении в натуральную степень. Переменной нет в знаменателе и нет под знаком корня.

Смысл работы такой: любое целое уравнение можно перенести всё в одну часть и привести к виду «многочлен = 0». Тогда степень этого многочлена и есть степень уравнения — наибольший показатель при x после приведения подобных.

Целое уравнение определено при любых значениях x (нет деления на ноль, нет корней), поэтому ОДЗ — все действительные числа. Отдельно искать ОДЗ не нужно.

Главное правило

Число корней не больше степени

Целое уравнение степени n имеет не более n корней. Степень — это «потолок», а не точное число:

степень 1
не более 1 корня
линейное уравнение
степень 2
не более 2 корней
квадратное уравнение
степень 3
не более 3 корней
кубическое и дальше

Ключевое слово — «не более». Корней может быть и меньше — вплоть до полного отсутствия действительных корней. Но больше степени — никогда.

Разбираем вместе · думаю вслух

Степень определяют после приведения

(x − 2)(x + 3) = x² − 5  →  какая степень?

  1. Раскрываем скобки слева, чтобы сравнить без скобок: x² + 3x − 2x − 6 = x² − 5, то есть x² + x − 6 = x² − 5.
  2. Переносим всё в левую часть — получаем «многочлен = 0»: x² + x − 6 − x² + 5 = 0.
  3. Приводим подобные — здесь x² сокращается: x − 1 = 0.
  4. Старший показатель при x равен 1, значит уравнение первой степени (линейное), хотя на вид были квадраты. Отсюда x = 1.
Степень определяют ПОСЛЕ приведения: старшие члены сократились, и уравнение оказалось линейным.

Как находят корни · интерактив

Разложил на множители — прочитал корни

Главный приём: перенести всё влево и разложить многочлен на множители. Тогда работает золотое правило — произведение равно нулю только если один из множителей равен нулю. Каждый множитель даёт свой корень, а ответ — их объединение. Разберём по шагам:

x³ − 9x = 0

Заметь: степень 3 — и корней получилось ровно 3. Каждый множитель «отвечает» за свой корень.

Тренажёр · бесконечная практика

Реши целое уравнение разложением

Нажми «Новое уравнение». Перенеси всё в одну часть (у нас уже так), разложи левую часть на множители — вынеси общий множитель или сгруппируй — и приравняй каждый множитель к нулю. Введи все корни через точку с запятой (например 0; 3; −3). Кратный корень пиши один раз. Порядок не важен.

x³ − 9x = 0

Практика по нарастанию

Какие уравнения целые?понимание
а) x³ − x = 0; б) 1/x + 2 = x; в) √x = 3; г) (x − 1)(x + 5) = 7.
Целые — а и г. В «б» переменная в знаменателе, в «в» — под корнем, поэтому они не целые.
5x² − (x − 2)(x + 2) = 1 — вид и степень?применение
(x − 2)(x + 2) = x² − 4, поэтому 5x² − (x² − 4) = 1 → 4x² + 4 = 1 → 4x² + 3 = 0. Степень 2 (квадратное).
(x + 1)² = 4x — вид и степень?применение
x² + 2x + 1 = 4x → x² − 2x + 1 = 0. Степень 2.
Уравнение 5-й степени имеет 3 корня — нарушено ли правило?анализ
Нет, не нарушено. Правило говорит «не более степени»: 3 ≤ 5. Степень — это максимум, а не точное число корней.
Найди ошибку: из x² = 5x получили один корень x = 5анализ
Ученик поделил обе части на x — и потерял корень x = 0. Делить на выражение с переменной нельзя. Правильно: x² − 5x = 0 → x(x − 5) = 0 → x = 0 и x = 5.

Где чаще всего ошибаются

Лови эти три ловушки

  • Путают степень уравнения с числом корней. «Степень 4 — значит 4 корня». Нет: степень — лишь верхняя граница. Сколько корней нашлось — столько и есть, лишь бы не больше степени.
  • Теряют корни при делении на выражение с переменной. Из x² = 5x нельзя делить на x (потеряешь x = 0). Переноси всё влево и выноси множитель: x(x − 5) = 0.
  • Не приводят к стандартному виду перед оценкой степени. Смотрят на скобки и квадраты в исходной записи и завышают степень. Сначала раскрой скобки и приведи подобные — старшие члены могут сократиться.

Проверь себя · объясни своими словами

Три вопроса на понимание

Что такое целое уравнение и почему у него ОДЗ — все числа?объясни
Обе части — многочлены: нет деления на переменную и нет переменной под корнем. Поэтому оно определено при любом x — ОДЗ все действительные числа, отдельно её искать не нужно.
Уравнение степени 3 — сколько корней максимум? А может меньше?объясни
Максимум — 3. Меньше тоже бывает: например, у x³ + 4x = 0 корень только один (x = 0) — множитель x² + 4 корней не даёт.
Почему опасно делить обе части на x?объясни
Потому что теряются корни. Деление на x отбрасывает решение x = 0. Вместо деления — выноси x за скобку.

Что дальше

Ты уже понял общий план. Дальше — два больших метода для конкретных уравнений:

разложение на множители → биквадратные

Решение разложением на множители — доведём приём «произведение = 0» до автоматизма. А в биквадратных уравнениях (ax⁴ + bx² + c = 0) познакомишься с приёмом «введение новой переменной»: замена t = x² сводит их к обычному квадратному.

Проверка на выходе: что такое целое уравнение? · сколько максимум корней у уравнения степени 3? · почему нельзя делить обе части на x?
