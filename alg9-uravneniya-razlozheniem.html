Решение уравнений разложением на множители

Одно сложное уравнение распадается на несколько простых — если справа ноль, а слева произведение.

Свойство нулевого произведения

A(x) · B(x) = 0
⇔  A(x) = 0  ИЛИ  B(x) = 0

Произведение равно нулю тогда и только тогда, когда хотя бы один множитель равен нулю.

Зачем это нужно

Формулы нет — а решать надо

Не всякое уравнение решается по готовой формуле. Для линейного есть свой приём, для квадратного — дискриминант. А что делать с x³ − 4x = 0? Никакой «формулы корней кубического уравнения» в школе нет.

Зато есть приём, который работает почти всегда: разложить левую часть на множители. Он же дальше пригодится в биквадратных уравнениях, в дробно-рациональных, при поиске нулей функции и точек пересечения графиков.

И сразу про главную ловушку. Ученик видит x² = 5x, делит обе части на x и радостно пишет x = 5. Один корень потерян: x = 0 тоже подходит (0² = 5·0). Деление на выражение с переменной — самая частая беда этой темы. Правильный путь: перенести всё в одну часть и раскладывать.

Что вспомнить перед стартом

Вынесение общего множителя: x³ − 4x = x(x² − 4).

Разность квадратов: a² − b² = (a − b)(a + b).

Квадрат суммы и разности: a² ± 2ab + b² = (a ± b)².

Разложение квадратного трёхчлена: ax² + bx + c = a(x − x₁)(x − x₂).

Всё это ты уже умеешь — здесь мы просто применяем это к уравнениям.

Ядро темы

Алгоритм в пять шагов

Правило звучит так: произведение нескольких множителей равно нулю тогда и только тогда, когда хотя бы один из множителей равен нулю. Для трёх множителей — так же: A · B · C = 0 равносильно A = 0 ИЛИ B = 0 ИЛИ C = 0.

Почему других вариантов нет? Потому что ненулевые числа при умножении ноль не дают. Если каждый множитель отличен от нуля — произведение точно не ноль. Значит, ноль в произведении обязан «прийти» хотя бы от одного множителя.

  1. Перенести все слагаемые в левую часть, чтобы справа остался 0.
  2. Разложить левую часть на множители.
  3. Приравнять каждый множитель к нулю.
  4. Решить полученные простые уравнения.
  5. Записать все корни в ответ (и при необходимости проверить ОДЗ).
Шаг 1 не пропускать. Свойство нулевого произведения работает только когда справа именно ноль.

Как выбрать способ разложения

Три инструмента — смотри на вид левой части

Разложение — это не одно действие, а выбор из нескольких знакомых приёмов. Посмотри, что перед тобой:

x³ + 5x² + 6x
Вынесение множителя
У каждого слагаемого есть общий множитель — выноси его за скобки первым делом.
x² − 9
x² + 6x + 9
Формулы сокращённого умножения
Разность квадратов, квадрат суммы или разности — узнавай их в лицо.
x³ − 3x² − 4x + 12
Группировка
Четыре слагаемых — разбей на две пары так, чтобы в скобках получилось одинаковое.
Что видишь слеваЧто делаешьЧто получается
x³ − 4xвыносишь xx(x² − 4) = x(x − 2)(x + 2)
2x² − 8xвыносишь 2x2x(x − 4)
x³ − 3x² − 4x + 12группируешь по парам(x − 3)(x − 2)(x + 2)
x² − 6x + 9узнаёшь квадрат разности(x − 3)²

Порядок действий обычно такой: сначала вынести общий множитель, а потом уже смотреть, раскладывается ли то, что осталось в скобках.

Разбираем вместе · думаю вслух

Эталонный пример

x³ − 4x = 0

  1. Смотрю на правую часть: там уже 0. Переносить нечего, можно раскладывать.
  2. Ищу общий множитель. У x³ и у 4x есть x — выношу: x(x² − 4) = 0.
  3. Смотрю в скобку: x² − 4 — это разность квадратов, a² − b² = (a − b)(a + b). Значит x² − 4 = (x − 2)(x + 2). Получаю x(x − 2)(x + 2) = 0.
  4. Слева произведение трёх множителей, справа ноль. Значит хоть один множитель равен нулю — приравниваю каждый: x = 0, или x − 2 = 0, или x + 2 = 0.
  5. Решаю три простых уравнения: x = 0, x = 2, x = −2.
Ответ: −2; 0; 2
Заметь: если бы я в самом начале «сократил на x», корень x = 0 пропал бы. Три множителя — три корня.

Одно уравнение x(x − 2)(x + 2) = 0 — это три простых уравнения. Каждый множитель отвечает за свой корень:

xx = 0корень 0
(x − 2)x − 2 = 0, x = 2корень 2
(x + 2)x + 2 = 0, x = −2корень −2

Сколько множителей — столько и корней (если какие-то множители не повторяются).

Покрути сам · интерактив

Каждый множитель — своя точка на оси

Ниже график левой части. Выключай и включай множители и смотри: как только множитель убран — его точка пересечения с осью x исчезает. Корень уравнения = точка, где график пересекает ось.

y = x(x − 2)(x + 2)

Пересечения с осью x: −2; 0; 2

Убери множитель x — и график перестанет проходить через ноль. Это ровно то, что происходит, когда уравнение «сокращают на x»: корень x = 0 просто пропадает из решения.

Теперь ты · нажми, чтобы проверить

Мини-практика

(x − 7)(x + 1) = 0понимание
Скобки раскрывать не надо. x − 7 = 0 → x = 7; x + 1 = 0 → x = −1. Ответ: −1; 7.
x² = 5xприменение
Переносим влево: x² − 5x = 0. Выносим: x(x − 5) = 0. Отсюда x = 0 или x = 5. Ответ: 0; 5 — два корня, а не один.
2x² − 8x = 0применение
Выносим общий множитель 2x: 2x(x − 4) = 0. Множитель 2 нулём быть не может, значит x = 0 или x − 4 = 0. Ответ: 0; 4.
x³ − 3x² − 4x + 12 = 0применение
Группировка: x²(x − 3) − 4(x − 3) = (x − 3)(x² − 4) = (x − 3)(x − 2)(x + 2). Ответ: −2; 2; 3.
Найди ошибку: x² = 9xанализ
Ученик разделил обе части на x и получил x = 9. Ошибка: делить на выражение с переменной нельзя — x может быть нулём, и этот случай просто выбрасывается. Потерян корень x = 0. Правильно: x² − 9x = 0, x(x − 9) = 0, ответ 0; 9.
А если бы было x² = −9x? Тогда x² + 9x = 0, x(x + 9) = 0, ответ −9; 0. Корень 0 остаётся на месте, меняется только второй — он становится отрицательным.
Что не так: (x − 2)(x + 1) = 3анализ
Ученик написал x − 2 = 3 или x + 1 = 3. Так нельзя: свойство работает только при нуле справа. Тройку можно получить как 1·3, 3·1, (−1)·(−3) и бесконечным числом других способов. Сначала переносим всё влево, чтобы справа стал 0.

Тренажёр · бесконечная практика

Реши уравнение разложением сам

Нажми «Новое уравнение», разложи левую часть на множители и выпиши все корни через точку с запятой (порядок любой). Если корень повторяется — пиши его один раз. Потом проверь себя или посмотри пошаговое решение.

x³ − 4x = 0

Где чаще всего ошибаются

Лови эти четыре ловушки

  • Делят обе части на множитель с переменной. Из x² = 5x делают x = 5 — и корень x = 0 исчезает. Никогда не делим на выражение, которое может быть нулём: переносим всё влево и раскладываем.
  • Приравнивают к нулю не каждый множитель. Получили x(x − 5) = 0 и написали только x = 5. Каждый множитель — отдельное уравнение; проверь, что выписал столько корней, сколько множителей (с учётом совпадений).
  • Раскладывают, когда справа не ноль. Из (x − 2)(x + 1) = 3 делают x − 2 = 3. Свойство нулевого произведения работает только при нуле справа — сначала перенеси всё в одну часть.
  • Забывают про область определения. Если в уравнении есть дроби, корень, обращающий знаменатель в ноль, — посторонний. Выпиши ОДЗ до ответа и сверь с найденными корнями.

Проверь себя

Объясни своими словами

При каком условии произведение A · B равно нулю?понимание
Когда хотя бы один из множителей равен нулю: A = 0 или B = 0 (возможно, оба сразу). Других вариантов нет.
Почему нельзя делить обе части уравнения на x?понимание
Потому что x может оказаться нулём, а на ноль делить нельзя. Деля, мы молча выбрасываем случай x = 0 — и теряем корень.
Сколько корней у x(x − 1)(x + 4) = 0 и какие?применение
Три корня: x = 0, x = 1, x = −4. Каждая скобка даёт свой.

Что дальше

Дальше — уравнения вида ax⁴ + bx² + c = 0:

биквадратные уравнения

Там сначала делают замену и решают квадратное, а потом возвращаются к x. Разложение на множители никуда не денется — оно останется рабочим инструментом и там.

Итог: переносим всё в одну часть · раскладываем на множители · приравниваем каждый множитель к нулю · выписываем все корни.
