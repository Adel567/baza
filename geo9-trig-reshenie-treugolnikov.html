Решение треугольников

У треугольника шесть элементов: три стороны и три угла. Тебе дают три из них — и надо найти остальные. Весь секрет в одном: правильно выбрать инструмент.

Два инструмента и одна проверка

a / sin A = b / sin B = c / sin C
c2 = a2 + b2 − 2ab·cos C
A + B + C = 180°

Стороны a, b, c лежат против углов A, B, C

Зачем это нужно

Когда до объекта не дотянуться рулеткой

«Решить треугольник» — значит найти все шесть элементов (3 стороны и 3 угла), зная только три из них. Так работают геодезия, навигация, строительство и астрономия: измеряют углы и одну-две доступные длины, а ширину реки, высоту горы или расстояние до корабля досчитывают.

Типичное заблуждение: «раз треугольник — хватит синуса и косинуса острого угла». Так можно только в прямоугольном. В произвольном треугольнике нет ни катетов, ни гипотенузы — там работают теорема синусов и теорема косинусов, и они годятся для любого треугольника.

Ещё важное: треугольник задаётся тремя элементами, среди которых есть хотя бы одна сторона. По трём углам размер не восстановишь — таких подобных треугольников бесконечно много.

Что уже должно быть в голове

Теорема синусов — связывает стороны с противолежащими углами: a / sin A = b / sin B = c / sin C = 2R. Повторить →

Теорема косинусов — связывает три стороны с одним углом: c² = a² + b² − 2ab·cos C. Повторить →

Сумма углов: A + B + C = 180° — и инструмент поиска, и проверка в конце.

Углы в треугольнике: 0° < угол < 180°. Синус на этом промежутке всегда положителен, а косинус меняет знак: у тупого угла cos < 0.

Ядро темы · вся суть на одном экране

Данные сами говорят, какую теорему брать

Не надо угадывать. Посмотри, что именно тебе дали, и опознай случай — дальше формула выбирается сама:

СУС · две стороны и угол между ними
→ теорема косинусов
Только в неё входят сразу обе известные стороны и известный угол. Первым шагом получаешь третью сторону.
ССС · три стороны
→ теорема косинусов «наизнанку»
cos C = (a² + b² − c²) / (2ab). Углов пока нет вообще, значит синусы применить не к чему.
УСУ / УУС · сторона и два угла
→ сумма 180°, потом теорема синусов
Третий угол считаешь мгновенно, и у тебя появляется полная пара «сторона — противолежащий угол». Дальше синусы дают остальные стороны.
ССУ · две стороны и угол против одной из них
→ теорема синусов
Есть готовая пара «сторона — её угол» — это и есть рабочее отношение теоремы синусов. Осторожно: синус даёт два возможных угла (см. ловушки).
Что даноПервый шагЧто получишь
2 стороны + угол между нимитеорема косинусовтретью сторону
3 сторонытеорема косинусовугол
сторона + 2 угласумма 180°, затем синусовостальные стороны
2 стороны + угол против однойтеорема синусоввторой угол

Короткая подсказка: есть полная пара «сторона — противолежащий угол» → синусы. Нет пары → косинусы. Это правило закрывает все четыре случая сразу.

Порядок действий

Три шага, всегда одинаковые

  1. Классифицируй данные. Подпиши на чертеже вершины A, B, C и стороны a, b, c напротив них. Определи случай: СУС, ССС, сторона с двумя углами или ССУ.
  2. Сделай первый шаг нужной теоремой и найди один новый элемент. После него данных станет больше — дальше пойдёт по цепочке.
  3. Добери остальное самым дешёвым способом. Последний угол считай через 180°, а не заново через синусы: короче и точнее. В конце сверь: сумма углов = 180°, против большей стороны — больший угол.

Эталонный пример: случай СУС

Дано: a = 5, b = 8, угол C = 60°. Найти сторону c и углы A, B.

  1. Классифицирую. Угол C лежит между сторонами a и b — это СУС. Значит, теорема косинусов: почему она — только в неё входят сразу обе известные стороны и известный угол.
    c² = a² + b² − 2ab·cos C = 25 + 64 − 2·5·8·cos 60°
    cos 60° = 1/2, поэтому 2·5·8·(1/2) = 40, и c² = 89 − 40 = 49 ⇒ c = 7.
  2. Ищу угол A. Теперь есть все три стороны и угол C — то есть полная пара «сторона c — угол C». Значит, теорема синусов:
    sin A = a·sin C / c = 5·sin 60° / 7 = 5·(√3/2) / 7 = 5√3/14 ≈ 0,6186 ⇒ A ≈ 38,2°.
    Второе значение (тупое) отбрасываю: A лежит против меньшей стороны a = 5, значит A острый.
  3. Третий угол — через сумму. Так дешевле и точнее, чем снова синусы:
    B = 180° − 60° − 38,2° = 81,8°.
Проверка: против большей стороны (b = 8) — больший угол (B ≈ 81,8°). Сходится. Ответ: c = 7, A ≈ 38,2°, B ≈ 81,8°.

Обрати внимание на главное: инструмент менялся по ходу решения. Начали косинусами (пары не было), а как только появилась пара «c — C», перешли на синусы — они считаются проще.

Ещё два случая · коротко

ССС и «сторона с двумя углами»

ССС. Дано: a = 7, b = 8, c = 9. Найти угол C.

Три стороны, углов нет ни одного — пары «сторона—угол» взять негде, значит только косинусы, записанные через косинус:

cos C = (a² + b² − c²) / (2ab) = (49 + 64 − 81) / (2·7·8) = 32 / 112 ≈ 0,2857 ⇒ C ≈ 73,4°.

УСУ. Дано: угол A = 45°, угол B = 60°, сторона c = 10. Найти стороны a и b.

Сторона и два угла: сначала третий угол через сумму — C = 180° − 45° − 60° = 75°. Теперь есть пара «c — C», работают синусы:

a = 10·sin 45° / sin 75° ≈ 7,32;   b = 10·sin 60° / sin 75° ≈ 8,97.

Проверка: самый большой угол C = 75° — против самой большой стороны c = 10. Сходится.

От понимания к анализу

Какие три элемента задают треугольник однозначно? Можно ли решить треугольник по трём углам?
Нужны три элемента, среди которых хотя бы одна сторона. По трём углам — нельзя: подобных треугольников с такими углами бесконечно много, размер ничем не закреплён.
a = 6, c = 10, угол B = 120°. Найди сторону b.
Угол B между сторонами a и c → СУС → косинусы: b² = 36 + 100 − 2·6·10·cos 120° = 136 − 120·(−1/2) = 136 + 60 = 196, значит b = 14. Минус на минус дал плюс — сторона получилась длиннее, как и положено при тупом угле.
Что изменится, если в эталонном примере угол C сделать 120° вместо 60°?
Сторона c станет больше. При C = 60° было cos C = +1/2 и мы вычитали 40. При C = 120° косинус отрицателен: cos 120° = −1/2, и −2ab·cos C добавляет +40: c² = 89 + 40 = 129, c ≈ 11,36. Чем больше угол между сторонами — тем дальше друг от друга их концы.
Найди ошибку: для a = 3, b = 4, c = 8 ученик считает cos C = (a² + b² − c²)/(2ab).
Формула-то верная, а вот треугольника не существует: 3 + 4 = 7 < 8 — нарушено неравенство треугольника. Косинус вышел бы (9 + 16 − 64)/24 = −39/24 ≈ −1,63, то есть меньше −1, чего у косинуса не бывает. Значит, ошибка не в вычислениях, а в самих данных.
Известны c = 7 и углы A = 38°, B = 82°. Восстанови сторону a.
Сторона и два угла: C = 180° − 38° − 82° = 60°. Появилась пара «c — C» → синусы: a = c·sin A / sin C = 7·sin 38° / sin 60° ≈ 7·0,6157/0,8660 ≈ 4,98. Проверка: A — самый маленький угол, и сторона a вышла самой маленькой.

Где чаще всего ошибаются

Лови эти ловушки

  • Берут неподходящую теорему. При «две стороны и угол между ними» лезут в синусы — а там нет готовой пары «сторона — противолежащий угол», подставлять нечего. Сначала классифицируй данные (СУС / ССС / сторона с двумя углами), потом бери формулу.
  • Не проверяют сумму 180°. Нашли два угла через синусы — и забыли, что третий обязан добить сумму до 180°. Погрешность так и остаётся незамеченной. Всегда считай третий угол через 180° и сверяй итог.
  • Теряют второе решение угла по синусу. sin A = 0,7 даёт и A ≈ 44°, и A ≈ 136°: синус одинаков у угла и его дополнения до 180°. Лишний корень отбрасывай по правилу «против большей стороны — больший угол» и по сумме углов.
  • Теряют минус для тупого угла. cos 120° = −1/2, а пишут +1/2 — и сторона выходит короче вместо длиннее. У тупого угла косинус отрицателен, третья сторона должна получиться больше, чем при прямом угле.
  • Берут угол не против той стороны. В c² = a² + b² − 2ab·cos C угол C обязан стоять против стороны c. Проверяй: буква угла совпадает с буквой стороны слева.

Проверь, что понял

Ответь себе вслух

Известны две стороны и угол между ними. С какой теоремы начинаешь и почему?
С теоремы косинусов: только в неё входят сразу обе известные стороны и угол между ними. Пары «сторона — противолежащий угол» здесь нет, поэтому синусы бесполезны — пока не найдена третья сторона.
Синус угла равен 0,5. Какие два значения угла возможны и как выбрать нужное?
30° и 150°. Выбираем по правилу «против большей стороны — больший угол» и по сумме углов: если 150° не влезает в 180° вместе с уже известными углами — остаётся 30°.
Зачем после нахождения всех углов проверять их сумму?
Это бесплатная проверка всей работы: если сумма не 180°, где-то ошибка — не тот угол, не та теорема или потерянный знак. А ещё она ловит накопленную погрешность округлений.
