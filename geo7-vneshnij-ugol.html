Внешний угол треугольника

Короткий путь к ответу: вместо двух шагов через 180° — просто сложи два «дальних» угла и всё.

Теорема о внешнем угле

внешний при C = ∠A + ∠B
и одновременно внешний при C = 180° − ∠C

внешний угол равен сумме двух внутренних углов, не смежных с ним

Зачем это нужно

Один шаг вместо двух

Часто в задаче известны два угла треугольника, а спрашивают про угол «снаружи», у продолжения стороны. Можно идти длинным путём: сначала найти третий внутренний угол через сумму 180°, потом вычесть его из 180° как смежный. А можно за один шаг — просто сложить два «дальних» угла.

Эта же идея работает в задачах на доказательство: теорема о внешнем угле — основа многих рассуждений. И она пригодится дальше, когда будешь изучать соотношение между сторонами и углами треугольника.

Типичное житейское заблуждение: «внешний угол — это весь угол снаружи треугольника». На самом деле внешний угол образуется только продолжением ОДНОЙ стороны и берётся как смежный к внутреннему, а не «всё, что снаружи».

Что вспомнить с прошлых шагов

Сумма углов треугольника равна 180°: ∠A + ∠B + ∠C = 180°. Значит третий угол — это остаток: ∠C = 180° − ∠A − ∠B.

Смежные углы вместе дают развёрнутый угол — 180°. Не «равны друг другу», а именно в сумме 180°.

Из этих двух фактов вся сегодняшняя теорема и получится — буквально в две строчки.

Ядро темы

Определение и теорема

Определение. Возьми треугольник и продли одну из его сторон за вершину — получится луч. Между этим лучом и второй стороной, выходящей из той же вершины, образуется угол. Это и есть внешний угол при данной вершине. Другими словами: внешний угол треугольника при вершине — это угол, смежный с внутренним углом этого треугольника при той же вершине.

Внешний угол и внутренний угол при одной и той же вершине — смежные: вместе они дают развёрнутый угол 180°.

Теорема о внешнем угле. Внешний угол треугольника равен сумме двух внутренних углов, не смежных с ним.

Обозначим углы треугольника при вершинах A, B, C через ∠A, ∠B, ∠C. Пусть внешний угол построен при вершине C. Тогда:

1) внешний при C = ∠A + ∠B — сумма двух не смежных внутренних;

2) внешний при C = 180° − ∠C — как смежный с ∠C.

Оба способа дают одно и то же число — это удобно для проверки.

Почему так (идея в две строчки). Третий внутренний угол равен 180° − (два других). А внешний равен 180° − третий. Подставь одно в другое — и «180°» сократятся: остаются как раз те самые два других угла. Внешний угол как бы «впитывает» в себя два внутренних, которые к нему не прилегают.

Условия и ограничения. Внутренние углы измеряются в градусах, каждый строго больше 0° и меньше 180°, сумма всех трёх — 180°. Внешний угол всегда больше каждого из двух не смежных с ним внутренних (ведь он равен их сумме). «Не смежные» — это два угла, у вершин которых внешний угол НЕ построен.

Разбираем вместе · думаю вслух

Эталонный пример

В треугольнике ∠A = 50°, ∠B = 70°. Найти внешний угол при вершине C.

  1. Смотрю, где строится внешний угол: при вершине C. Значит смежный с ним внутренний — это ∠C, его брать нельзя.
  2. Закрываю пальцем вершину C. Остались ∠A и ∠B — это и есть два не смежных внутренних угла. Почему они: их вершины A и B, а внешний угол построен не там.
  3. Применяю теорему: внешний при C = ∠A + ∠B. Теорема о внешнем угле: он равен сумме двух не смежных внутренних.
  4. Считаю: внешний при C = 50° + 70° = 120°. Просто складываю два данных числа — один шаг.
  5. Проверяю вторым способом: ∠C = 180° − 50° − 70° = 60°, тогда как смежный внешний = 180° − 60° = 120°. Совпало — значит верно.
Ответ: внешний угол при C = 120°

Теперь допиши пропущенный шаг сам: внешний угол при вершине B равен 145°, а ∠A = 60°. По теореме 145° = ∠A + ∠C, значит ∠C = 145° − 60° = ? Должно получиться 85°.

И ещё одна на закрепление: ∠A = 35°, ∠C = 45°, найди внешний угол при вершине B. Ответ: 80°.

Увидь глазами · интерактив

Чертёж: продли сторону — получишь внешний угол

Сторона BC продлена за вершину C до точки D — это тот самый луч. Синяя дуга — внешний угол при C (между лучом CD и стороной CA). Рядом гранатовая дуга — внутренний ∠C. Вместе они «разворачивают» прямую: 180°.

Тяни ползунки ∠A и ∠B и следи за нижней строкой: сколько ни меняй форму, синее число всегда равно сумме зелёного и янтарного.

Предскажи → проверь → объясни. Как думаешь: если ∠C станет большим, внешний угол вырастет или уменьшится? Сначала ответь про себя, потом нажми кнопку «Сделать ∠C большим» и посмотри. Внешний угол уменьшается при росте ∠C — ведь он равен 180° − ∠C: чем больше вычитаем, тем меньше остаток.

Проверь себя · от простого к анализу

Мини-практика

Внешний угол построен при вершине A. С каким внутренним углом он смежный и какие два угла дают его в сумме?понимание
Смежный он с внутренним ∠A (та же вершина). А в сумме его дают два не смежных: ∠B + ∠C. Приём: закрой пальцем вершину, где строишь внешний угол, — оставшиеся два угла и есть слагаемые.
В треугольнике два внутренних угла равны 48° и 52°. Найди внешний угол при третьей вершине.применение
Оба данных угла не смежны с искомым внешним, значит складываем: 48° + 52° = 100°. Ответ 100°.
В треугольнике ∠A = 50°, ∠B = 70°. Чему равен внутренний ∠C и чему внешний угол при C?применение
∠C = 180° − 50° − 70° = 60°, внешний при C = 180° − 60° = 120°. Тот же результат в один шаг: 50° + 70° = 120°. Ответ: ∠C = 60°, внешний 120°.
Внешний угол при вершине B равен 145°, ∠A = 60°. Найди ∠C.применение
По теореме 145° = ∠A + ∠C, значит ∠C = 145° − 60° = 85°. Ответ 85°.
Внешний угол при вершине C равен 110°. Что изменится в ответе, если один из не смежных внутренних углов увеличить на 10°, не меняя другого?анализ
Внешний угол — это сумма двух не смежных углов. Увеличили одно слагаемое на 10° — сумма выросла ровно на 10°: 110° + 10° = 120°. Заодно внутренний ∠C уменьшится на 10°, ведь ∠C = 180° − внешний.
Найди ошибку: ученик написал «внешний угол при C = ∠C + ∠A». Где он не прав?анализ
Внешний угол равен сумме двух НЕ смежных внутренних, а ∠C — как раз смежный с ним (та же вершина C), его брать нельзя. Верно: внешний при C = ∠A + ∠B.
Может ли внешний угол быть меньше каждого из двух не смежных внутренних?анализ
Нет. Он равен их сумме, а каждый угол больше 0°, значит сумма больше любого из слагаемых. Внешний угол всегда больше каждого из этих двух внутренних.

Где чаще всего ошибаются

Лови эти ловушки

  • Считают внешний угол равным смежному внутреннему. Внешний и внутренний при одной вершине — смежные: они в сумме дают 180°, а не равны друг другу (равны только если оба по 90°). Как не допустить: всегда помни «смежные = 180° в сумме».
  • Складывают не те внутренние углы. Берут угол, который смежен с внешним, вместо двух дальних. Как не допустить: сначала закрой пальцем вершину, где строишь внешний угол, — оставшиеся два угла и есть нужные слагаемые.
  • Путают внешний угол с «продолжением стороны без угла». Думают, что внешний угол — это просто луч-продолжение. Как не допустить: внешний угол — это именно угол между продолжением и второй стороной, у него есть градусная мера.
  • Думают, что внешний угол — «всё, что снаружи». Нет: он образован продолжением только одной стороны и второй стороной из той же вершины.

Что дальше

Следующий шаг — соотношение между сторонами и углами треугольника: против большей стороны лежит больший угол. Теорема о внешнем угле — один из инструментов, на которые там опираются рассуждения.

Запомни одним предложением: внешний угол треугольника равен сумме двух не смежных с ним внутренних углов (и одновременно дополняет смежный внутренний до 180°).
