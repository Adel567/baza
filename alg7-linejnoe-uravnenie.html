Линейное уравнение ax = b

Не угадать число, а надёжно его найти. Один алгоритм, который потом откроет и текстовые задачи, и системы, и квадратные уравнения.

Где встречается. «Билет стоит x рублей, 4 билета — 480. Сколько стоит один?» Это уравнение 4x = 480. Задачи «на сколько», «во сколько раз», про деньги, скорость, проценты — почти все сводятся к нему.

Уравнение — это вопрос «какое число подходит?», записанный на языке математики. И «решить» его — не угадать, а провести цепочку честных преобразований, которая гарантированно приводит к ответу.

Суть простыми словами

Линейное уравнение — это то, что можно привести к виду a·x = b: «какое-то число, умноженное на x, равно другому числу». Переменная x стоит только в первой степени — нет x², нет x под корнем, нет x в знаменателе.

Представь весы в равновесии: левая часть = правой части. Что бы ты ни делал — делай с обеими чашами одинаково, тогда равновесие (а значит, и корень) не изменится. Мы шаг за шагом «освобождаем» x: собираем всё с иксом слева, числа справа, а потом делим на число перед иксом.

Определение и формула

ax = b  ⟶  x = b/a
a — коэффициент при x · b — свободный член · делить можно только при a ≠ 0

Правило. При a ≠ 0 уравнение ax = b имеет ровно один корень: x = b/a. Коэффициент перед x — это множитель, поэтому убираем его делением, а не вычитанием.

Алгоритм решения — по шагам:

  1. Раскрой скобки, если они есть.
  2. Перенеси всё с x влево, числа — вправо. При переносе через знак «=» слагаемое меняет знак.
  3. Приведи подобные — получи чистый вид ax = b.
  4. Раздели обе части на коэффициент a: x = b/a.
  5. Проверь: подставь найденный x в исходное уравнение.

Разбор «думаю вслух»

Решаем 5x − 7 = 2x + 8. Смотри, как каждый шаг сохраняет равновесие весов:

5x − 7 = 2x + 8

  1. Переносим 2x влево (станет −2x), а −7 вправо (станет +7): 5x − 2x = 8 + 7.
  2. Приводим подобные: 5x − 2x = 3x, а 8 + 7 = 15. Получили чистый вид: 3x = 15.
  3. Делим обе части на коэффициент 3 (можно, ведь 3 ≠ 0): x = 15 / 3 = 5.
  4. Проверка: слева 5·5 − 7 = 18, справа 2·5 + 8 = 18. Совпало — значит, корень верный.
Ответ: x = 5.

Ещё пример со скобками: 4(x − 3) = x + 6. Раскрываем: 4x − 12 = x + 6; переносим: 4x − x = 6 + 12; приводим: 3x = 18; делим: x = 6. Проверка: 4·(6−3) = 12 и 6 + 6 = 12. Верно.

Тренажёр · решай сколько хочешь

Нажми «Новое», реши уравнение и введи корень. Проверь себя или посмотри пошаговое решение. Ответы всегда целые.

3x = 15

Проверь себя

1) Реши: 8x = 56.
Делим на коэффициент 8: x = 56 / 8 = 7. x = 7.
2) Реши: 3x + 5 = 20.
Переносим 5: 3x = 20 − 5 = 15; делим: x = 15 / 3 = 5. x = 5.
3) Реши: 9 − 2x = 1.
Переносим: −2x = 1 − 9 = −8; делим на −2: x = −8 / (−2) = 4. x = 4.
4) Найди ошибку: ученик решал 5x = −15 и записал x = 3.
Потеряли минус. x = −15 / 5 = −3. Верный ответ x = −3 — проверка это ловит: 5·(−3) = −15.
5) Реши: 7x + 4 = 3x − 8.
Переносим: 7x − 3x = −8 − 4 → 4x = −12; делим: x = −12 / 4 = −3. x = −3.

Ловушки

  • Перенос без смены знака. Из x + 5 = 12 нельзя писать x = 12 + 5. Слагаемое «переходит границу» знака «=» и меняет знак: x = 12 − 5 = 7.
  • Убирают коэффициент вычитанием. Из 3x = 12 нельзя x = 12 − 3. Коэффициент — множитель, снимаем его делением: x = 12 / 3 = 4.
  • Теряют минус. Из −2x = 6 получается не 3, а x = 6 / (−2) = −3. Всегда делай проверку — она ловит знак.
  • Делят раньше времени. В 2x + 4 = 8 нельзя сразу делить: сперва перенеси +4 (2x = 4), и только потом дели (x = 2).
  • Дробный коэффициент. Из (1/2)x = 5 ответ не 5/2: чтобы убрать 1/2, надо умножить на 2 → x = 10.

Запомни главное

ax = b ⟶ x = b / a (при a ≠ 0)

Приводи уравнение к чистому виду ax = b равносильными шагами (перенос со сменой знака, приведение подобных), а потом дели на коэффициент. И всегда делай проверку подстановкой.
