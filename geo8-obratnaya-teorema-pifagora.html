Обратная теорема Пифагора

Даны три стороны — и больше ничего. Как узнать, есть ли в треугольнике прямой угол, не измеряя углы вообще?

Признак прямого угла

если c2 = a2 + b2, то угол против c — прямой

c — обязательно наибольшая сторона треугольника

Зачем это нужно

Теорема Пифагора — билет в обе стороны

Прямая теорема отвечает на вопрос: «треугольник прямоугольный — чему равна гипотенуза?». А как быть наоборот: даны три стороны, и нужно узнать, есть ли прямой угол, а транспортира нет? Именно это и решает обратная теорема.

Это не абстракция, а инструмент строителей и разметчиков. Чтобы получить точный прямой угол на местности — угол дома, грядки, фундамента, — берут верёвку, отмеряют стороны 3, 4 и 5 (или 6, 8, 10) и натягивают треугольник. Угол между сторонами 3 и 4 получается ровно прямым. Этот «египетский треугольник» работает именно по обратной теореме.

Типичное заблуждение: «если в треугольнике есть сторона побольше, то угол напротив неё прямой». Нет. Прямой угол получается только при точном равенстве c² = a² + b², а не «на глаз».

Что вспомнить с прошлого шага

Прямая теорема Пифагора: если треугольник прямоугольный, то c² = a² + b², где c — гипотенуза, a и b — катеты.

Гипотенуза всегда больше каждого катета — она лежит против самого большого угла, прямого.

Понадобятся квадраты чисел до 25 наизусть: 12² = 144, 13² = 169, 17² = 289, 24² = 576, 25² = 625.

Ядро темы

Формулировка и порядок проверки

Обратная теорема Пифагора. Если в треугольнике квадрат одной стороны равен сумме квадратов двух других сторон, то этот треугольник прямоугольный, и прямой угол лежит против наибольшей стороны.

Обрати внимание, что здесь поменялось местами: в прямой теореме нам дан прямой угол и мы получаем равенство, а в обратной нам дано равенство и мы получаем прямой угол. Числовой факт превращается в геометрический вывод о форме фигуры.

Порядок работы всегда один и тот же:

  1. Найди наибольшую сторону — это кандидат в гипотенузы, обозначь её c. Две другие — a и b.
  2. Посчитай c².
  3. Посчитай a² + b².
  4. Сравни два числа и сделай вывод по таблице ниже.

Один тест — три ответа

Сравнение c² и a² + b² различает не два случая, а три. «Не сошлось» — это не ошибка, а тоже полноценный ответ:

c² = a² + b²
Прямоугольный
Угол против c равен ровно 90°. Сторона c — гипотенуза.
c² > a² + b²
Тупоугольный
Наибольшая сторона «переросла» — угол против c тупой.
c² < a² + b²
Остроугольный
Наибольшая сторона не дотянула — угол против c острый.

Условия применимости: единицы у всех трёх сторон одинаковые, и в роли c — обязательно самая длинная сторона. Кстати, если равенство c² = a² + b² выполнено при положительных длинах, такой треугольник заведомо существует — неравенство треугольника проверять отдельно не нужно.

Готовые наборы чисел

Пифагоровы тройки

Пифагорова тройка — три натуральных числа a, b, c, для которых a² + b² = c². Если увидел в задаче такие числа, проверку можно сделать за секунду — просто по памяти.

Покрути сам · интерактив

Три стороны — и форма треугольника

Двигай ползунки — треугольник строится по-настоящему, по заданным длинам сторон. Смотри, как один и тот же тест c² против a² + b² ловит все три случая. Ползунки сами держатся в разумных границах: из любых трёх чисел треугольник не сложишь, сумма двух сторон должна быть больше третьей.

угол против наибольшей стороны: 90° · прямоугольный

Поймай момент, когда угол ровно 90° — это и есть граница между остроугольным и тупоугольным. Попробуй так: поставь 3, 4, 5, а потом чуть увеличь только наибольшую сторону. Катеты те же, а угол уже тупой — вот насколько точным должно быть равенство.

Разбираем вместе

Эталонный пример

Стороны треугольника 9, 12 и 15 см. Прямоугольный ли он?

  1. Выбираем наибольшую сторону: c = 15. Почему именно её: прямой угол, если он есть, лежит против самой длинной стороны. Тогда a = 9, b = 12.
  2. Считаем квадрат наибольшей: c² = 15² = 225.
  3. Считаем сумму квадратов двух других: a² + b² = 9² + 12² = 81 + 144 = 225.
  4. Сравниваем: 225 = 225 — равенство верно. Именно точное равенство, а не «примерно похоже», и есть признак прямого угла.
Треугольник прямоугольный, прямой угол лежит против стороны 15 см. Это тройка (3, 4, 5), увеличенная в 3 раза.

Заметь: мы ни разу не измеряли углы и не смотрели на чертёж. Весь вывод — из арифметики.

Мини-практика

Допиши шаг: стороны 6, 8, 11понимание
Наибольшая сторона c = 11, значит c² = 121. Сумма квадратов других: 6² + 8² = 36 + 64 = 80. Сравниваем: 121 > 80, то есть c² > a² + b² → угол против стороны 11 тупой, треугольник тупоугольный, не прямоугольный.
5, 12, 13 — прямоугольный?применение
13² = 169; 5² + 12² = 25 + 144 = 169 → да, прямоугольный, прямой угол против стороны 13.
8, 15, 17 — прямоугольный?применение
17² = 289; 8² + 15² = 64 + 225 = 289 → да, прямоугольный, прямой угол против стороны 17.
4, 5, 6 — прямоугольный?применение
6² = 36, а 4² + 5² = 16 + 25 = 41. Здесь 36 < 41, то есть c² < a² + b² → угол против 6 острый, треугольник остроугольный. Нет, не прямоугольный.
10, 24, 26 — прямоугольный? Против какой стороны прямой угол?применение
26² = 676; 10² + 24² = 100 + 576 = 676 → да, прямой угол против стороны 26. Это тройка (5, 12, 13), увеличенная вдвое.
Предскажи, потом проверь: (3,4,5), (4,5,6), (5,5,8)анализ
Сначала угадай на глаз, какой прямоугольный, потом считай.
(3,4,5): 25 = 9 + 16 → прямоугольный.
(4,5,6): 36 < 41 → остроугольный.
(5,5,8): 64 > 25 + 25 = 50 → тупоугольный.
Совпала ли догадка? Это и разрушает иллюзию «сторона побольше — значит прямой угол».
Найди ошибку: стороны 8, 6, 10анализ
Ученик написал: «8² = 6² + 10², то есть 64 = 36 + 100 — неверно, значит не прямоугольный».
Промах в том, что он взял в роли c не наибольшую сторону. Надо c = 10: 10² = 100 = 36 + 64 = 6² + 8² → треугольник прямоугольный.
Что изменится, если у прямоугольного треугольника чуть увеличить гипотенузу?анализ
Катеты прежние, значит a² + b² не изменилось, а c² стало больше. Теперь c² > a² + b² → угол против c стал тупым, треугольник тупоугольный.
Один катет 7, гипотенуза 25. Найди второй катетанализ
Чтобы треугольник был прямоугольным, нужно 7² + b² = 25², откуда b² = 625 − 49 = 576, значит b = 24. Получилась тройка (7, 24, 25).

Где чаще всего ошибаются

Лови эти ловушки

  • Путают прямую и обратную теоремы. Прямая: «прямоугольный ⇒ равенство сторон». Обратная: «равенство сторон ⇒ прямоугольный». Спроси себя, что дано, а что надо доказать: если даны три длины и нужен вывод о форме — это обратная.
  • Берут в роли c не наибольшую сторону. Тогда равенство «не сходится» и делается ложный вывод «не прямоугольный». Всегда сначала найди самую длинную сторону и только её возводи в квадрат слева.
  • Делают вывод о прямом угле без проверки — «на глаз», по виду чертежа. Прямой угол подтверждает только точное c² = a² + b², а не похожесть рисунка.
  • Считают, что c² > a² + b² — это «ошибка». Нет, это рабочий случай: треугольник тупоугольный. А c² < a² + b² — остроугольный. Прямоугольный только при равенстве.
  • Складывают сами стороны, а не их квадраты — проверяют c = a + b. Сравнивать нужно именно квадраты.

Что дальше

Обратная теорема — это ключ, который открывает прямой угол там, где его не дали в условии. А как только прямой угол есть, работает вся тригонометрия острого угла:

sin, cos, tg — через катеты и гипотенузу

Схема типовой задачи ОГЭ: три стороны → проверил c² = a² + b² → доказал прямой угол → нашёл синус, косинус или площадь.
