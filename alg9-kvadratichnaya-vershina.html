Вершина параболы и ось симметрии

У каждой параболы есть одна главная точка — вершина. Найдёшь её — и сразу знаешь наибольшее или наименьшее значение функции и куда «смотрит» весь график.

Где встречается. Мяч летит вверх и падает — на какой высоте он окажется в верхней точке? Из проволоки заданной длины делают прямоугольник — при каких сторонах площадь наибольшая? При каком выпуске прибыль максимальна? Все такие задачи «на максимум и минимум» сводятся к одному — найти вершину параболы.

В вершине функция достигает своего наименьшего (если ветви вверх) или наибольшего (если вниз) значения. А ещё без вершины не построить аккуратный график — парабола «плавает».

Что вспомнить с прошлого шага

Квадратичная функция — это y = ax² + bx + c, где a ≠ 0, а её график — парабола.

a — при x² (задаёт направление ветвей), b — при x, c — свободный член.

Коэффициенты берём вместе со знаком: если в записи стоит − 6x, то b = −6. Это нам сейчас очень пригодится.

Суть темы

Парабола симметрична

Проведи вертикальную прямую через самую нижнюю (или верхнюю) точку параболы — левая и правая ветви наложатся друг на друга, как две половинки бабочки. Эта прямая называется осью симметрии, а точка на ней — вершиной.

Чтобы найти вершину, действуем в два шага: сначала находим её абсциссу x₀ (это «середина» параболы по горизонтали), потом подставляем x₀ в функцию и получаем ординату y₀ (высоту вершины). Ось симметрии — это вертикальная прямая x = x₀, проходящая через вершину.

Ядро — вся формула темы

Координаты вершины

Абсцисса вершины

x0 = −b2a

Минус перед b есть всегда. Затем ординату находим подстановкой: y0 = y(x0) — подставляем x0 в саму функцию.

x₀ = −b/(2a)

Шаг 1 — абсцисса

Выписываем a и b со знаками и считаем по формуле. Аккуратно с минусом.

y₀ = y(x₀)

Шаг 2 — ордината

Подставляем найденное x₀ в формулу функции и считаем — получаем высоту вершины.

Вершина — это точка, у неё две координаты: (x₀; y₀). Ответ «вершина = 3» неверен — это только абсцисса. А ось симметрии — вертикальная прямая x = x₀.

А знак старшего коэффициента a подсказывает, что за значение стоит в вершине:

∪ a > 0 — ветви вверх

Вершина внизу — это наименьшая точка. Значит y₀ — наименьшее значение функции.

∩ a < 0 — ветви вниз

Вершина вверху — это наибольшая точка. Значит y₀ — наибольшее значение функции.

Почему именно −b/(2a)? Если у параболы есть точки пересечения с осью Ox, они расположены симметрично относительно вершины, а их середина как раз равна −b/(2a). Поэтому вершина всегда стоит ровно посередине.

Разбираем вместе · думаю вслух

Эталонный пример

Найти вершину и ось симметрии параболы y = x² − 6x + 5.

  1. Выписываю коэффициенты со знаками: a = 1, b = −6, c = 5. — b это число перед x вместе со знаком минус.
  2. Считаю абсциссу: x₀ = −b/(2a) = −(−6)/(2·1) = 6/2 = 3. — минус перед b превращает −6 в +6, двойной минус не теряю.
  3. Считаю ординату подстановкой: y₀ = 3² − 6·3 + 5 = 9 − 18 + 5 = −4. — вершина лежит на самой параболе, её y = значение функции в точке x₀.
  4. Записываю вершину (3; −4) и ось симметрии x = 3.
  5. Проверка смысла: a = 1 > 0 — ветви вверх, значит −4 — наименьшее значение. Логично.
Вершина (3; −4) · ось симметрии x = 3 · наименьшее значение −4.

Найти вершину параболы y = −x² + 4x − 1 (ветви вниз).

  1. a = −1, b = 4, c = −1.
  2. x₀ = −b/(2a) = −4/(2·(−1)) = −4/(−2) = 2. — делим на отрицательное 2a, знак меняется.
  3. y₀ = −(2²) + 4·2 − 1 = −4 + 8 − 1 = 3.
  4. Вершина (2; 3), ось x = 2. Здесь a < 0 — ветви вниз, поэтому 3 — наибольшее значение.
Вершина (2; 3) · ось симметрии x = 2 · наибольшее значение 3.

Покрути сам · интерактив

Двигай a, b, c — лови вершину

Меняй ползунки и следи за оранжевой точкой — это вершина. Пунктирная прямая — ось симметрии x = x₀. Внизу видно, как x₀ = −b/(2a) считается вживую.

y = x² − 6x + 5

Поставь b = 0 — и вершина «прилипнет» к оси Oy (окажется на ней). Значит ось симметрии совпадает с Oy только при b = 0, а в остальных случаях сдвинута. При a = 0 это уже прямая, а не парабола.

Тренажёр · бесконечная практика

Найди вершину сам

Нажимай «Новое» — генерируются параболы с «красивыми» целыми координатами вершины. Впиши x₀ и y₀, проверь себя, а не вышло — посмотри пошаговое решение по формуле.

y = x² − 6x + 5

Минус вводи как обычный дефис - или знак − — оба поймёт. Иногда попадётся b = 0 — тогда вершина лежит прямо на оси Oy.

Проверь себя · от простого к анализу

Практика с ответами

Вершина в точке (−5; 2). Назови ось симметрии.понимание
Ось симметрии проходит через вершину вертикально: x = −5 (берём абсциссу вершины).
Найди вершину и ось параболы y = x² + 2x − 8.применение
a=1, b=2, c=−8. x₀ = −2/(2·1) = −1. y₀ = (−1)² + 2·(−1) − 8 = 1 − 2 − 8 = −9. Вершина (−1; −9), ось x = −1.
Наименьшее значение функции y = 3x² − 12x + 7?применение
Наименьшее значение — это ордината вершины. x₀ = −(−12)/(2·3) = 12/6 = 2. y₀ = 3·2² − 12·2 + 7 = 12 − 24 + 7 = −5. Наименьшее значение −5 (при x = 2).
Что станет с вершиной y = x² − 6x + 5, если прибавить ко всей функции +10?анализ
Новая функция y = x² − 6x + 15. Коэффициенты a, b те же → x₀ = 3 не изменится. А y₀ = 9 − 18 + 15 = 6. Вершина сдвинулась с (3; −4) на (3; 6) — вся парабола поднялась на 10 вверх, абсцисса вершины осталась прежней.
Найди ошибку: «Для y = x² − 4x: x₀ = −4/2 = −2».анализ
Потеряли минус в формуле. Здесь b = −4, и x₀ = −b/(2a) = −(−4)/(2·1) = 4/2 = 2. В решении взяли b вместо −b. Верный ответ x₀ = 2 (а не −2).
Обратная задача: ось параболы y = x² + bx + 3 — это x = 4. Найди b.анализ
x₀ = −b/(2a) = −b/2 = 4 → −b = 8 → b = −8. Проверка: у y = x² − 8x + 3 абсцисса вершины −(−8)/2 = 4. Верно.

Где чаще всего ошибаются

Лови эти ловушки

  • Теряют минус в формуле. Пишут x₀ = b/(2a) вместо −b/(2a) или забывают, что −(−6) = +6. Всегда сначала выпиши b со знаком, потом ставь минус: для b = −6 проговори «минус на минус — плюс».
  • Находят только x₀ и забывают y₀. Вершина — точка с двумя координатами. Ответ «вершина = 3» неполный: обязательно подставь x₀ в функцию и запиши пару (x₀; y₀).
  • Путают ось симметрии с осью Oy. Ось симметрии — это x = x₀, она проходит через вершину, а не всегда x = 0. Совпадает с Oy только при b = 0.
  • Забывают про знак a при разговоре о max/min. Вершина — не всегда минимум. Проверяй a: вверх (a > 0) — наименьшее, вниз (a < 0) — наибольшее значение.

Проверка понимания

Объясни своими словами

По какой формуле находят абсциссу вершины?вопрос
x₀ = −b/(2a) — минус перед b, делим на удвоенный старший коэффициент.
Сколько координат у вершины и как найти вторую?вопрос
Две. Ординату y₀ находим подстановкой x₀ в саму функцию.
Как связаны вершина и ось симметрии?вопрос
Ось симметрии — вертикальная прямая x = x₀, которая проходит ровно через вершину и делит параболу на две зеркальные половины.

Запомни главное

x₀ = −b/(2a), y₀ = y(x₀), ось: x = x₀

Абсциссу вершины считаем по формуле (минус перед b — всегда), ординату — подстановкой x₀ в функцию. Вершина — это пара (x₀; y₀), а ось симметрии — прямая x = x₀. Знак a говорит, наименьшее это значение (∪) или наибольшее (∩).
