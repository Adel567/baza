Линейные неравенства с одной переменной

Решаем почти как уравнение — те же переносы и деление. Но есть одно правило, из-за которого знак неравенства вдруг разворачивается.

Главное правило темы

Делишь на отрицательное число
→ разворачивай знак неравенства

−2x < 6  делим на −2  →  x > −3  (знак «<» стал «>»)

Зачем это нужно

Ответ — не число, а целый диапазон

Неравенство описывает не одно точное значение, а сразу целую область допустимого: «скорость не выше 60 км/ч», «нужно набрать хотя бы 70 баллов», «багаж не больше 23 кг». Всё это — неравенства.

Главное заблуждение: «решить неравенство — значит найти число». Нет. Решение неравенства — это, как правило, бесконечно много чисел, и записать их нужно промежутком. Например, для x > 3 подходит и 4, и 100, и 3,001 — а 3 и 2 уже нет.

Что вспомнить с прошлых шагов

Линейные уравнения. Умеешь переносить слагаемые и делить обе части на число — здесь ровно то же самое.

Числовые промежутки. (a; b) — концы не входят, [a; b] — входят; +∞ и −∞ всегда с круглой скобкой.

Знаки. > больше, < меньше — строгие; ≥ не меньше, ≤ не больше — нестрогие.

Ядро — три преобразования

Что можно делать с неравенством

С неравенством делают почти то же, что с уравнением. Разница — только в третьей карточке, и это самое важное место всей темы:

Перенос слагаемого x + 5 < 8  →  x < 8 − 5 Переехало через знак — сменило свой знак. Знак неравенства не трогаем.
÷ на ПОЛОЖИТЕЛЬНОЕ 2x < 10  →  x < 5 Знак неравенства сохраняется — остаётся таким же.
÷ на ОТРИЦАТЕЛЬНОЕ −2x < 10  →  x > −5 Знак неравенства МЕНЯЕТСЯ на противоположный. Это и есть отличие от уравнений.

Считалочка: делю на плюс — знак стоит, делю на минус — знак разворачиваю.

Покрути сам · интерактив

Ответ на числовой прямой

Выбери знак и граничное число — и смотри, как выглядит ответ. Обращай внимание на кружок: при строгом знаке он пустой (○, граница не входит), при нестрогом — закрашенный (●, граница входит). Луч показывает, в какую сторону идут подходящие числа.

x ≥ −1
−1

Приём «предскажи → проверь»: назови вслух, войдёт ли само граничное число в ответ, а потом посмотри на кружок.

Разбираем вместе · думаю вслух

Эталонный пример

5 − 3x ≤ 14

  1. Переносим 5 вправо (меняя знак числа): −3x ≤ 14 − 5. Убираем свободное слагаемое от переменной — знак неравенства не трогаем, мы только прибавили −5 к обеим частям.
  2. Считаем справа: −3x ≤ 9.
  3. Делим обе части на −3. Коэффициент отрицательный → знак разворачиваем: x ≥ 9 : (−3), то есть x ≥ −3. Деление на отрицательное меняет «≤» на «≥».
  4. Знак нестрогий — граница входит. Записываем промежуток: [−3; +∞).
Ответ: x ≥ −3, то есть [−3; +∞). Проверка: x = 0 → 5 − 0 = 5 ≤ 14 — верно, и 0 лежит в промежутке.

Мини-практика

x ≤ −2 — назови три подходящих числа и одно нетпонимание
Подходят, например, −2, −3, −10 (само −2 тоже входит — знак нестрогий). Не подходит 0. На оси −2 рисуем ● закрашенной точкой.
3x + 2 < 17применение
3x < 15 → делим на 3 (плюс, знак стоит) → x < 5, то есть (−∞; 5).
−5x ≥ 10применение
Делим на −5 (минус → знак разворачиваем): x ≤ −2, то есть (−∞; −2].
2(x − 1) ≤ x + 4применение
Раскрываем: 2x − 2 ≤ x + 4 → 2x − x ≤ 4 + 2 → x ≤ 6, то есть (−∞; 6].
Найди ошибку: «−2x < 6, делим на −2, получаем x < −3»анализ
Забыли развернуть знак при делении на отрицательное. Правильно: x > −3. Проверка: x = 0 → 0 < 6 верно, значит 0 обязан входить в ответ — и он входит в x > −3, но не в x < −3.
Что изменится в ответе −x < 4, если знак сделать −x ≤ 4?анализ
−x < 4 → x > −4, промежуток (−4; +∞) — граница НЕ входит. При −x ≤ 4 → x ≥ −4, промежуток [−4; +∞) — теперь само −4 добавляется в ответ. Направление то же, меняется только кружок: ○ → ●.
При каком 0·x > b решением будет вся прямая, а при каком — пусто?анализ
Переменная сократилась — осталось числовое неравенство 0 > b. Если оно верное (например 0 > −3) — подходит любое x, ответ (−∞; +∞). Если ложное (например 0 > 5) — не подходит ни одно x, ответ ∅.

Лови эти ловушки

  • Не поменяли знак при делении на отрицательное. Из −2x < 6 пишут x < −3 вместо x > −3. Перед делением на минус проговаривай: «делю на минус — разворачиваю знак» и проверяй подстановкой одного числа.
  • Путают кружок на границе. При строгом знаке (<, >) точка пустая ○, при нестрогом (≤, ≥) — закрашенная ●.
  • Теряют решение при a = 0. Получив 0·x > 5, пишут «x = 0» или «ошибка» — а надо просто проверить, верное числовое неравенство или нет: отсюда ∅ или вся прямая.
  • Перенесли слагаемое, не сменив его знак. Как и в уравнениях: переехало через знак — сменило свой знак.

Что дальше

Ты научился решать одно неравенство. Дальше — системы неравенств: решаешь каждое по отдельности, а потом ищешь общую часть промежутков на одной прямой.

{ x > −1  и  x ≤ 4 } → (−1; 4]

Тот же навык плюс умение пересекать промежутки. А ещё этот приём — фундамент метода интервалов в старших классах.
