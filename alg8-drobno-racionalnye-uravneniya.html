Дробно-рациональные уравнения

Уравнения, где неизвестная спряталась в знаменателе. Решать их умеешь — но есть один шаг, без которого ответ почти всегда лишний.

Главное правило темы

P(x)Q(x) = 0  ⟺  P(x) = 0  И  Q(x) ≠ 0

Дробь равна нулю, только когда числитель = 0, а знаменатель НЕ ноль. На ноль делить нельзя.

Зачем это нужно

Где прячутся такие уравнения

Дробно-рациональное уравнение — это уравнение, в котором неизвестная стоит в знаменателе. Они постоянно возникают в текстовых задачах, где величины связаны делением: движение (время = расстояние / скорость), совместная работа, концентрация и проценты. «Двое рабочих вместе делают работу за столько-то часов» — это оно.

Типичное заблуждение: «раз тут дроби — надо просто их сложить и всё». На самом деле идея другая: избавиться от знаменателей умножением, а потом обязательно проверить, что найденные корни не обращают знаменатель в ноль. Именно эта проверка отличает дробные уравнения от обычных — и именно её чаще всего забывают.

Что вспомнить перед стартом

Обыкновенные дроби. На ноль делить нельзя — значит, знаменатель никогда не должен равняться нулю.

Дробь равна нулю тогда и только тогда, когда её числитель равен нулю, а знаменатель — нет.

Квадратные уравнения. После умножения на знаменатель почти всегда получается квадратное — решаем его через дискриминант D = b² − 4ac и x = (−b ± √D)/(2a), либо раскладываем на множители.

Линейные уравнения. Иногда получается совсем простое kx + b = 0 — решаем за один шаг.

Ядро — алгоритм решения

Шесть шагов, и последний — главный

Решить дробное уравнение — значит найти такие x, при которых равенство верно И ни один знаменатель не равен нулю. Все допустимые x называют ОДЗ — область допустимых значений.

  1. Найди ОДЗ. Приравняй каждый знаменатель к нулю и выпиши запрещённые значения x. Делай это первым действием.
  2. Приведи к общему знаменателю (или перенеси всё в одну часть, чтобы слева осталась одна дробь = 0).
  3. Умножь обе части на общий знаменатель — дробное уравнение превращается в целое (обычно квадратное).
  4. Реши полученное уравнение (дискриминант или разложение на множители).
  5. Проверь каждый корень по ОДЗ. Если корень попал в запрещённые значения — он посторонний, отбрось его.
  6. Запиши ответ из оставшихся корней.
Шаг 5 — сердце темы. При умножении на знаменатель уравнение может «приобрести» лишний корень. Пропустишь проверку — впишешь чужой ответ.

Разбираем вместе · думаю вслух

Эталонный пример

x² − 9x − 3 = 0  →  найди x

  1. Смотрю на знаменатель: x − 3. Приравниваю к нулю → x = 3 запрещён. Значит ОДЗ: x ≠ 3 — на ноль делить нельзя.
  2. Дробь равна нулю, когда числитель равен нулю: x² − 9 = 0. Знаменатель я пока не трогаю — я его уже «обработал» в шаге 1.
  3. Решаю: x² = 9 → x = 3 или x = −3. Два корня, потому что и 3², и (−3)² дают 9.
  4. Проверяю по ОДЗ: x = 3 — запрещён, он зануляет знаменатель → посторонний, выбрасываю. x = −3 — допустим. Вот тот самый шаг 5.
Ответ: x = −3.  (Без проверки ОДЗ записали бы лишний корень x = 3 — самая частая ошибка.)

Наглядность · схема ОДЗ

Смотри, какой корень «падает в дырку»

Отметим на числовой оси запрещённую точку (корень знаменателя) выколотым кружком, а найденные корни — точками. Сразу видно: корень, попавший в дырку, — посторонний.

корень годится (в ОДЗ) выколото — знаменатель = 0, запрещено

Полезно и вести решение таблицей: слева «найденные корни», справа «проверка по ОДЗ (входит / посторонний)». Так шаг 5 не проскочит мимо.

Тренажёр · бесконечная практика

Реши дробное уравнение сам

Нажми «Новое уравнение». Найди ОДЗ, реши числитель и отсей посторонние корни. Введи ответ через точку с запятой (например 2; −5), или напиши нет, если корней не осталось. Осторожно: иногда один из корней совпадает с запрещённым значением — его надо выбросить.

Практика по нарастанию

ОДЗ уравнения 3 / (x − 7) = 0 ?понимание
Знаменатель x − 7 = 0 при x = 7 → ОДЗ: x ≠ 7. Посторонний корень — это значение, которое получилось при решении, но нарушает ОДЗ (зануляет знаменатель), поэтому в ответ не идёт. (Кстати, у этого уравнения корней нет: числитель 3 никогда не равен нулю.)
(2x − 6) / (x + 1) = 0применение
ОДЗ: x + 1 ≠ 0 → x ≠ −1. Числитель: 2x − 6 = 0 → x = 3. Проверка: 3 ≠ −1 — годится. → Ответ: x = 3.
(x + 5) / (x² − 25) = 0применение
ОДЗ: x² − 25 ≠ 0 → x ≠ 5 и x ≠ −5. Числитель: x + 5 = 0 → x = −5. Но x = −5 запрещён по ОДЗ → посторонний. → Корней нет.
1/(x − 2) + 1/(x + 2) = 1применение
ОДЗ: x ≠ 2 и x ≠ −2. Общий знаменатель (x − 2)(x + 2) = x² − 4, умножаем: (x + 2) + (x − 2) = x² − 4, то есть 2x = x² − 4 → x² − 2x − 4 = 0. D = 4 + 16 = 20, x = 1 ± √5. Оба корня не равны ±2 → Ответ: x = 1 ± √5.
Найди ошибку: x/(x − 4) = 4/(x − 4)анализ
Ученик сократил на (x − 4) и получил x = 4. Ошибка: x = 4 не входит в ОДЗ (x ≠ 4) — это посторонний корень. Сокращать на выражение с x опасно: так теряют или приобретают корни. Верно: перенести всё влево → (x − 4)/(x − 4) = 0, числитель x − 4 = 0 → x = 4 — запрещён. → Корней нет.
При каком a у (x − a)/(x − 3) = 0 нет корней?анализ
ОДЗ: x ≠ 3. Числитель даёт x = a. Этот корень станет посторонним ровно тогда, когда он совпадёт с запрещённым значением, то есть a = 3. → При a = 3 уравнение корней не имеет.

Где чаще всего ошибаются

Лови эти ловушки

  • Не находят ОДЗ и оставляют посторонний корень. Главная ошибка темы: решили числитель, выписали все корни, а проверку по знаменателю пропустили. Лекарство — писать ОДЗ первым действием и держать перед глазами до конца.
  • Теряют корни при умножении. Не сокращай уравнение на выражение с x — можно потерять корень. Лучше перенеси всё в одну часть и приведи к общему знаменателю.
  • Забывают, что ОДЗ надо вычислить. Запрещённые значения — это не «что-то формальное», а именно корни знаменателя: найти их = решить Q(x) = 0.
  • Сокращают дробь через слагаемое. В (x + 3)/(x + 5) нельзя «сократить x с x». Сокращать можно только общий множитель всего числителя и всего знаменателя, а не отдельное слагаемое.

Проверь себя · объясни своими словами

Три вопроса на понимание

Когда дробь P(x)/Q(x) равна нулю?проверка
Когда числитель = 0 И одновременно знаменатель ≠ 0. Одного «числитель = 0» мало.
Зачем вообще проверять корни по ОДЗ?проверка
Потому что корень, зануляющий знаменатель, недопустим — деление на ноль не определено. При умножении на знаменатель такой «фальшивый» корень мог появиться, и его надо отсеять.
В какое уравнение чаще всего превращается дробное в 8 классе?проверка
В квадратное — после умножения на общий знаменатель. Дальше решаем его привычными способами.
