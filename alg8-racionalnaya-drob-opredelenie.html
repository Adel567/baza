Рациональная дробь и её область определения

Дробь с буквами внизу — это спрятанное деление. А значит, у неё есть значения, при которых она просто перестаёт существовать.

Рациональная дробь

P(x)Q(x)

P и Q — многочлены, и обязательно Q(x) ≠ 0

Зачем это нужно

Дробь, которая иногда «ломается»

В 6 классе ты делил обыкновенные дроби, в 7 классе работал с буквенными выражениями. Теперь эти две темы соединяются: рациональная дробь — это «дробь с буквами», например (x + 1)/(x − 2).

Такие выражения появляются везде, где одна величина зависит от другой через деление: средняя скорость v = S/t (путь делим на время), производительность, концентрация раствора, плотность, цена за единицу.

И тут работает одно железное правило: на ноль делить нельзя. Если внизу оказался ноль — выражение теряет смысл. Смотри сам: если время t = 0, формула S/t не работает — за нулевое время путь не пройти.

Отсюда типичное заблуждение: «раз формула записана, она всегда даёт ответ». Нет. У любой дроби с переменной есть «запретные» значения, при которых знаменатель обращается в ноль. Уметь их находить — это и есть умение определять область определения.

Что вспомнить с прошлого шага

Многочлен — это выражение вроде x + 5, 2x, x² − 9, 7. Из двух таких и собирается рациональная дробь.

Черта дроби = знак деления. a/b значит «a разделить на b» — что в числах, что в буквах.

Линейное уравнение. Уметь решать x + 4 = 0: переносим 4 вправо со сменой знака, x = −4.

Ядро темы

Определение и главное условие

Рациональная дробь — это выражение вида P/Q, где P и Q — многочлены, а Q — не нулевой многочлен (содержит переменную или ненулевое число). Проще: «многочлен сверху делим на многочлен снизу».

Сверху — числитель, снизу — знаменатель, а черта дроби заменяет знак деления.

Область определения (допустимые значения переменной) — это все значения буквы, при которых дробь имеет смысл, то есть знаменатель не равен нулю. Числитель может быть любым, даже нулём — тогда дробь просто равна нулю, и это нормально. А вот знаменатель нулём быть не имеет права.

Смысл вот в чём: дробь — это команда «раздели». Деление на ноль не определено, поэтому те значения переменной, что обнуляют знаменатель, мы исключаем.

Правило в три шага

Шаг 1
Q(x) = 0
Приравниваем знаменатель к нулю. Числитель не трогаем вообще.
Шаг 2
Решаем
Находим все «запретные» значения — корни этого уравнения.
Шаг 3
Исключаем
Все остальные числа — допустимые. Пишем ответ: x ≠ …

Условие применимости: ограничение всегда только на знаменатель. Числитель на область определения не влияет — совсем.

Ответ можно записать словами: «x — любое число, кроме x = 2» — или коротко: x ≠ 2.

Разбираем вместе

Эталонный пример

Найти область определения дроби x + 5x − 3

  1. Смотрю на знаменатель x − 3 — потому что ограничение всегда на него: на ноль делить нельзя.
  2. Приравниваю его к нулю: x − 3 = 0. Я не «решаю дробь», я ищу, что её ломает.
  3. Решаю: x = 3. Вот оно, запретное значение: при x = 3 знаменатель равен нулю.
  4. Числитель x + 5 не трогаю: он на область определения не влияет.
Ответ: x — любое число, кроме x = 3 (то есть x ≠ 3).

Допиши шаг: 2xx + 4

  1. Ограничение ставим на знаменатель: x + 4 ≠ 0.
  2. Решаем уравнение x + 4 = 0, значит x = ____.
  3. Ответ: x ≠ ____
Подсказка и ответ
Перенеси 4 вправо со сменой знака. Должно получиться x = −4, ответ x ≠ −4.

Реши сам: x − 7x² − 9

Проверить себя
x ≠ 3 и x ≠ −3: знаменатель x² − 9 раскладывается как (x − 3)(x + 3) и равен нулю при x = 3 и при x = −3. Значит, запретных значений два.

Покрути сам · интерактив

Числовая прямая с «дырками»

Представь все числа как прямую. Запретное значение отмечают выколотой (пустой) точкой — дырка в прямой. Выбери знаменатель, а потом двигай синюю точку x и смотри, что происходит с дробью.

Дробь: x + 2x − 3

Проверь себя на этой картинке: сколько дырок на прямой у дроби с двумя запретными значениями? А у дроби, у которой знаменатель никогда не равен нулю?

Предскажи → проверь → объясни

Хитрая дробь (x − 4)/(x − 4)

Предскажи. Чему равна дробь (x − 4)/(x − 4) и при каких x она определена? Большинство говорит: «всегда равна 1».

Проверь. Подставь x = 4: сверху 4 − 4 = 0, снизу 4 − 4 = 0. Получается 0/0 — бессмыслица.

Объясни. При x = 4 дробь не определена, хотя «на вид» сокращается в единицу. Область определения: x ≠ 4. Это прямой мостик к следующей теме — сокращению дробей.

Теперь ты · нажми, чтобы проверить

Мини-практика

Какое из выражений — рациональная дробь: а) (x + 1)/x; б) 5x − 2; в) 7/(x − 1)?понимание
Дроби — это а) и в): многочлен делим на многочлен. А 5x − 2 — просто многочлен, деления в нём нет.
Назови у дроби (3x)/(x + 8) числитель и знаменательпонимание
Числитель — 3x (сверху), знаменатель — x + 8 (снизу). Ограничение ставим на знаменатель.
Найди область определения: 1/(x − 6)применение
x − 6 = 0 → x = 6. Ответ: x ≠ 6.
Найди область определения: (x + 2)/(2x)применение
2x = 0 → x = 0. Ответ: x ≠ 0.
Найди область определения: (x − 1)/(x + 10)применение
x + 10 = 0 → x = −10. Ответ: x ≠ −10.
Что изменится: у дроби 4/(x − 5) поменяли знаменатель на x + 5?анализ
Запретное значение изменится. Было x − 5 = 0 → x ≠ 5, стало x + 5 = 0 → x ≠ −5. Знак в знаменателе меняет знак запретного числа на противоположный.
Найди ошибку: «дробь (x − 2)/(x + 3) не определена при x = 2, потому что числитель равен нулю»анализ
Ограничение поставили не туда. Числитель на область определения не влияет: при x = 2 дробь спокойно существует и равна 0/5 = 0. Смотреть нужно на знаменатель: x + 3 = 0 → x ≠ −3.
Обратная задача: придумай дробь, у которой область определения — все числа, кроме x = 1анализ
Нужен знаменатель, который равен нулю ровно при x = 1 — например x − 1. Подойдёт любая дробь вида 5/(x − 1) или (x + 7)/(x − 1): числитель бери какой хочешь.

Тренажёр · бесконечная практика

Найди область определения сам

Нажми «Новая дробь» и найди запретные значения. Введи их через точку с запятой (например 3; −2), а если запретных значений нет — напиши «любое». Потом проверь себя или посмотри пошаговое решение.

Где чаще всего ошибаются

Лови эти ловушки

  • Не указывают ограничение на знаменатель. Записали дробь и сразу работают, забыв про допустимые значения. Заведи привычку: первым делом смотришь вниз и спрашиваешь себя — «при каком x знаменатель равен нулю?».
  • Считают, что дробь определена всегда. «Раз формула записана — годится при любом x». Помни правило «на ноль делить нельзя»: у дроби с переменной почти всегда есть запретные значения.
  • Путают рациональную дробь с обыкновенной. Обыкновенная дробь (например 3/4) — это число. Рациональная содержит переменную. Проверка простая: есть буква в записи — значит, рациональная.
  • Ставят ограничение на числитель. Запретное значение даёт только знаменатель. Числитель может быть нулём — тогда сама дробь равна нулю, и это нормально. «Опасно» только деление, то есть низ дроби.

Проверка понимания

Объясни своими словами

Из чего состоит рациональная дробь — что сверху, что снизу?своими словами
Сверху числитель — многочлен, снизу знаменатель — тоже многочлен. Черта дроби заменяет знак деления. Итого: отношение двух многочленов.
Какое условие обязательно должно выполняться для знаменателя?своими словами
Знаменатель не равен нулю: Q(x) ≠ 0. Потому что на ноль делить нельзя.

Что дальше

Ты научился видеть запретные значения. Дальше дроби начнём преобразовывать — и первое, что для этого нужно:

→ Основное свойство дроби
→ Сокращение дробей

Именно там и всплывёт история с (x − 4)/(x − 4): сокращать можно, но область определения при этом никуда не девается.

Итог одной фразой: рациональная дробь — это отношение двух многочленов, и она определена при всех значениях переменной, кроме тех, при которых знаменатель равен нулю.
