Длина окружности и длина дуги

Периметр круга и его кусок-дугу считают по двум формулам — и обе вырастают из одного числа π.

Длина окружности

C = 2πR = πd

Длина дуги в n градусов

l = (πRn) / 180

R — радиус, d — диаметр (d = 2R), n — центральный угол дуги, π ≈ 3,14

🎯 В ОГЭ · Задание 16
В первой части часто просят длину окружности или дуги по радиусу и центральному углу. Формулы C = 2πR и l = πRn/180 закрывают такие номера про окружность и круг за минуту.

Зачем это нужно

Периметр круга и путь по кривой

Длина окружности — это «периметр круга»: сколько пройдёт колесо за один полный оборот, сколько ленты нужно, чтобы обтянуть круглый стол, какой длины обод колеса. За один оборот колесо проезжает ровно одну длину окружности.

Длина дуги — это «кусок» окружности. Она нужна каждый раз, когда движение идёт по кривой: сколько проедет колесо, повернувшись на 60°; какой длины перила вдоль закруглённой части трибуны.

Главное заблуждение: «дуга — это про градусы, значит и ответ в градусах». Нет: градусы задают, какую долю окружности мы берём, а сама длина — линейная величина, в сантиметрах и метрах, как любой отрезок.

Что вспомнить с прошлого шага

Радиус R — расстояние от центра до окружности. Диаметр d проходит через центр, d = 2R.

π ≈ 3,14 — постоянное число. Отношение длины любой окружности к её диаметру всегда равно π: C / d = π.

Центральный угол n — угол с вершиной в центре; полный угол — 360°.

Ядро темы

Две формулы — под то, что дано

Формула длины окружности одна, но записана в двух видах — выбирай под то, что дано: радиус или диаметр.

C = 2πR
Дан радиус
Берём эту запись, если известен радиус R.
C = πd
Дан диаметр
Берём эту, если известен диаметр d. Помни: d = 2R.

А длину дуги не запоминают отдельно — её берут как долю n/360 от целой окружности:

l = (n/360)·2πR
Смысл: доля окружности
Дуга в n° составляет долю n/360 от полной длины.
l = (πRn)/180
Та же формула, свёрнутая
Потому что (n/360)·2πR = (πRn)/180. Считать удобнее так.

Проверка на краях: при n = 360 дуга — вся окружность, l = 2πR; при n = 180 — половина, l = πR.

Одна окружность, меняем только угол

Как дуга растёт вместе с углом

Радиус держим R = 6 см, крутим только центральный угол n. Дуга — это доля n/360 от полной длины C = 12π:

n = 90° доля 1/4 · l = (π·6·90)/180 = 3π ≈ 9,42 1/4 круга
n = 120° доля 1/3 · l = (π·6·120)/180 = 4π ≈ 12,56 1/3 круга
n = 180° доля 1/2 · l = (π·6·180)/180 = 6π ≈ 18,84 1/2 круга

Больше угол — больше доля — длиннее дуга, строго пропорционально. При том же угле, но большем радиусе дуга тоже растёт: l пропорциональна и n, и R.

Покрути сам · интерактив

Окружность, радиус и дуга — вживую

Двигай ползунки: R меняет размер круга, n — какую часть окружности выделить дугой. Смотри, как пересчитываются длина окружности и длина дуги.

Длина окружностиC = 10π ≈ 31,4 см
Длина дугиl = (π·5·90)/180 ≈ 7,85 см

Поставь n = 360 — дуга обходит всю окружность, и её длина совпадает с C. Поставь n = 180 — ровно половина.

Разбираем вместе

Эталонные примеры

Радиус R = 5 см. Найти длину окружности C. (π ≈ 3,14)

  1. Дан радиус — берём запись через радиус: C = 2πR.
  2. Подставляем R = 5: C = 2·π·5 = 10π — это точный ответ.
  3. Нужно число — заменяем π ≈ 3,14: C ≈ 10·3,14 = 31,4.
  4. Единицы: радиус был в см, значит и C ≈ 31,4 см.
Ответ: C = 10π ≈ 31,4 см.

Радиус R = 6 см, центральный угол n = 60°. Найти длину дуги l.

  1. Понимаю долю: 60/360 = 1/6 окружности. Дуга — та же доля от длины, что угол от 360°.
  2. Длина всей окружности: C = 2π·6 = 12π см.
  3. Беру 1/6 от неё: l = (1/6)·12π = 2π см.
  4. Проверка по свёрнутой формуле: (π·6·60)/180 = 360π/180 = 2π — совпало. Приближённо 2π ≈ 6,28 см.
Ответ: l = 2π ≈ 6,28 см.

Обратная: C = 18,84 см. Найди R.анализ
C = 2πR → R = C/(2π) = 18,84/(2·3,14) = 18,84/6,28 = 3 см.
Обратная: l = 4π см при R = 8. Найди n.анализ
4π = (π·8·n)/180 → 4·180 = 8n → n = 90°.
Найди ошибку: «R = 4, значит C = π·4 = 4π ≈ 12,56 см».анализ
Использована формула через диаметр (πd) вместо радиуса. Дан радиус, значит C = 2πR = 2·π·4 = 8π ≈ 25,12 см.
Найди ошибку: «R = 6, n = 90 → l = (π·6·90)/360 = 1,5π».анализ

Где чаще всего ошибаются

Лови эти ловушки

  • Путают 2πR и πd. Берут запись «через радиус», а подставляют диаметр (или наоборот). Спроси себя, что дано, и выбери формулу под это. Сомневаешься — переведи всё в радиус: R = d/2 и считай C = 2πR.
  • Забывают про π. Пишут C = 2R и считают это ответом. Без π получается просто диаметр, а не длина: множитель π обязателен.
  • Путают длину и площадь. Приписывают длине см² или берут формулу πR². Длина — линейная величина (см, м), с π в первой степени радиуса.
  • В дуге забывают делить на 360. Считают l = 2πR и берут всю окружность, игнорируя угол. Всегда сначала спроси: «какую долю n/360 это даёт?»
  • Путают деление на 180 и на 360. В формуле длины дуги стоит 180 (потому что 2π/360 = π/180). А на 360 делят в площади сектора — это уже другая величина.

Что дальше

От линии переходим к площади. Сколько места занимает весь круг:

S = πR²

А площадь сектора — это та же доля n/360, но уже от площади круга:

S = (πR²n) / 360

Сравни: у дуги делили на 180 (линия), у сектора — на 360 (площадь). Единицы подскажут, что именно ищут.

Проверка на выходе: запиши C через радиус и через диаметр по памяти · во сколько раз вырастет длина, если R увеличить втрое? · почему длину нельзя мерить в см²?
