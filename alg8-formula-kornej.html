Формула корней квадратного уравнения

Подставил три числа — получил корни. Универсальный ключ, который решает любое квадратное уравнение без подбора и угадывания.

Зачем это нужно. Квадратное уравнение ax² + bx + c = 0 можно решать выделением полного квадрата — но это долго и легко ошибиться. Формула корней делает всё за тебя: берёшь три коэффициента a, b, c — и сразу выходят корни.

Этот навык дальше нужен постоянно: теорема Виета, разложение на множители, дробно-рациональные и текстовые задачи, а в 9 классе — график параболы. Без уверенной формулы вся тема рассыпается.

Суть простыми словами

Чтобы найти корни, мы берём минус b, прибавляем и вычитаем корень из дискриминанта, и всё это делим на удвоенный старший коэффициент 2a.

Дискриминант D — это «измеритель» под корнем. Знак ± означает, что мы получаем сразу два значения: одно с плюсом, другое с минусом — это и есть два корня. А деление на 2a обязательно касается всего числителя целиком, а не только корня.

Геометрический смысл: корни — это точки, где парабола y = ax² + bx + c пересекает ось x. Две точки, одна (касание) или ни одной — зависит от знака дискриминанта.

Формула

x = −b ± √D 2a
D = b² − 4ac
a — старший коэффициент (при x², всегда ≠ 0) · b — при x · c — свободный член · коэффициенты берём со своими знаками

Порядок такой: сначала считаем D = b² − 4ac, смотрим на его знак — и уже по знаку решаем, сколько корней и как их искать.

D > 0

Два корня

x = (−b ± √D)/(2a)

Парабола пересекает ось x в двух точках.

D = 0

Один корень

x = −b/(2a)

Парабола касается оси x в одной точке.

D < 0

Корней нет

√(отриц.) — нельзя

Парабола не достаёт до оси x.

Разбор «думаю вслух»

Главный пример темы — реши 2x² − 7x + 3 = 0. Идём строго по шагам:

2x² − 7x + 3 = 0

  1. Выписываю коэффициенты со знаками: a = 2, b = −7, c = 3 (перед 7x стоит минус — значит b отрицательный).
  2. Дискриминант: D = b² − 4ac = (−7)² − 4·2·3 = 49 − 24 = 25. В квадрат возвожу именно (−7), поэтому 49, а не −49.
  3. D = 25 > 0 → два корня. √D = √25 = 5.
  4. Отдельно нахожу −b = −(−7) = 7 (тут чаще всего путают знак!). Знаменатель 2a = 2·2 = 4.
  5. x₁ = (7 − 5)/4 = 2/4 = 0,5
  6. x₂ = (7 + 5)/4 = 12/4 = 3
Ответ: x₁ = 0,5; x₂ = 3

А теперь случай, где корней нет — реши x² + 2x + 5 = 0. Тут важно вовремя остановиться:

x² + 2x + 5 = 0

  1. Коэффициенты: a = 1, b = 2, c = 5.
  2. D = 2² − 4·1·5 = 4 − 20 = −16.
  3. D = −16 < 0 → из отрицательного числа корень не извлекается.
Ответ: действительных корней нет

Покрути параболу сам

Двигай ползунки a, b, c и следи за дискриминантом. Корни — это точки, где парабола протыкает ось x. Смотри, как знак D управляет их числом.

Зелёный — два корня (D > 0), янтарный — один (D = 0, парабола касается оси), гранатовый — корней нет (D < 0, парабола не достаёт до оси).

Тренажёр · решай сколько хочешь

Нажми «Новое» и реши уравнение по формуле. Впиши корни через пробел (дробные — с запятой или точкой). Если корней нет — напиши нет.

x² − 5x + 6 = 0

Найди все корни уравнения

Проверь себя

1) В уравнении 5x² − 3x + 7 = 0 назови a, b, c и запиши формулу дискриминанта с этими числами.
a = 5, b = −3, c = 7. Дискриминант: D = (−3)² − 4·5·7. (Вычислять не требуется, но выйдет 9 − 140 = −131.)
2) Реши по формуле: x² − 6x + 8 = 0.
D = (−6)² − 4·1·8 = 36 − 32 = 4, √D = 2. x₁ = (6−2)/2 = 2, x₂ = (6+2)/2 = 4. Ответ 2 и 4.
3) Сколько корней у x² − 6x + 9 = 0 и чему они равны?
D = 36 − 36 = 0 → один корень. x = −b/(2a) = 6/2 = 3.
4) Найди ошибку: для 2x² + 3x − 2 = 0 ученик написал x = (−3 ± √25)/2 = (−3 ± 5)/2. Что не так?
Неверный знаменатель: 2a = 2·2 = 4, а не 2. Правильно x = (−3 ± 5)/4 → x₁ = −2, x₂ = 0,5.
5) Обратная задача: подбери c так, чтобы x² − 4x + c = 0 имело ровно один корень.
Один корень при D = 0: D = (−4)² − 4·1·c = 16 − 4c = 0 → c = 4.

Ловушки

  • Делят на 2a только часть числителя. Пишут −b ± √D / 2a, будто делится лишь корень. Заключай весь числитель в скобки: (−b ± √D) / (2a) — делятся оба слагаемых.
  • Теряют знак ±. Нашли √D и взяли только плюс. Помни: ± даёт два значения — сразу пиши две строки, для x₁ и x₂.
  • Путают знак −b. Если b = −7, то −b = 7. Сначала отдельно посчитай −b, потом подставляй.
  • Ошибаются в квадрате b. Пишут −7² = −49 вместо (−7)² = 49. Квадрат любого числа неотрицателен — бери b в скобки.
  • Забывают −4ac при отрицательном c. При c = −5 нужно −4·1·(−5) = +20, а не −20. Подставляй c со своим знаком в скобках.

Запомни главное

x = (−b ± √D) / (2a), где D = b² − 4ac

Сначала считаем дискриминант, потом по его знаку решаем: D > 0 — два корня, D = 0 — один, D < 0 — корней нет. Весь числитель делим на 2a, знак ± даёт сразу оба корня.
