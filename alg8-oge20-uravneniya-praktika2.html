Уравнения: практика №2

Второй тренировочный лист к семи методам из основного урока. Задачи новые, метод у каждого блока подсказан заголовком; в «солянках» метод выбираешь сам. Все ответы — в конце.

Два правила снова. Не теряй корень x = 0 при вынесении множителя (нельзя делить на x). В дробных — сначала ОДЗ, потом решай, в конце выброси посторонние корни. Ответ в системе — пары (x; y).

1 Вынесение общего множителя

Нет свободного члена. Перенеси всё влево, вынеси x (или 3x и т. п.), приравняй каждый множитель к нулю.

  1. 6x² = 24x
  2. 3x² + 15x = 0
  3. 5x³ − 45x = 0
  4. (x − 3)² = (x − 3)(2x + 1)

2 Группировка (уравнения с x³)

Четыре слагаемых, есть x³. Группируй попарно, выноси множитель — получится общая скобка. Остаток x² − a раскладывай по разности квадратов.

  1. x³ + 2x² − 9x − 18 = 0
  2. x³ − 3x² − 4x + 12 = 0
  3. x³ + 4x² − x − 4 = 0
  4. x³ − 2x² − 25x + 50 = 0

3 Замена переменной (биквадратные)

Есть x⁴ и x², нет x³ и x. Замена t = x² (t ≥ 0) → квадратное. Отрицательные t отбрасывай, положительные возвращай: x² = t → x = ±√t.

  1. x⁴ − 17x² + 16 = 0
  2. x⁴ − 26x² + 25 = 0
  3. x⁴ + 5x² − 36 = 0  (ловушка: t < 0)
  4. x⁴ − 20x² + 64 = 0

4 Дробно-рациональные (ОДЗ!)

Переменная в знаменателе. ОДЗ: знаменатель ≠ 0. Умножай на общий знаменатель, решай, в конце убери корни не из ОДЗ.

  1. (x² − 25) / (x − 5) = 0
  2. 15 / (x − 2) = x
  3. x / (x − 2) + 8 / (x² − 2x) = 1
  4. 12 / (x + 4) = x

5 Раскрыть скобки → квадратное

Скобки, квадраты, произведения. Раскрой, перенеси влево, приведи подобные. Дальше дискриминант или Виета; иногда x сокращаются и остаётся x² = a.

  1. x(x + 3) = 10
  2. (x − 3)² = 2x² − 7
  3. (x + 4)² = 8x + 65
  4. (x − 2)² + (x + 2)² = 40

6 Системы: подстановка

Нелинейная система (есть xy или x²). Вырази переменную из простого уравнения, подставь во второе. Найди одну — вернись за второй. Ответ — пары.

  1. {x + y = 5xy = 6
  2. {y − x = 2y = x² − 4
  3. {x + y = 8x² − y = 4
  4. {x − y = 2xy = 15

7 Системы: сложение

Оба уравнения линейные. Уравняй коэффициенты у одной переменной (домножь при необходимости) и сложи почленно — переменная исчезнет.

  1. {x + 3y = 10x − 3y = −2
  2. {2x − y = 33x + y = 7
  3. {5x + 2y = 163x − 2y = 0
  4. {4x + y = 142x − y = 4

С1 Солянка — метод выбираешь сам

Посмотри на вид уравнения → по карте методов реши, что применять. Разминочный уровень.

  1. 9x² − 16 = 0
  2. x³ − x² − 9x + 9 = 0
  3. x⁴ − 7x² − 18 = 0
  4. (x² − 1) / (x − 1) = 0
  5. x² − 9x + 20 = 0
  6. 2x³ = 18x

С2 Солянка — уровень ОГЭ, посложнее

Ближе к экзамену: следи за посторонними корнями и ловушками замены.

  1. (x + 3)² = (x + 3)(2x − 1)
  2. x⁴ − 40x² + 144 = 0
  3. x³ − 2x² − 16x + 32 = 0
  4. 6 / (x − 1) = x
  5. (x − 4)² − (x + 2)² = −24
  6. x⁴ = 2x² + 8
