Разложение квадратного трёхчлена на множители

Свернуть ax² + bx + c в произведение скобок — и длинные выражения вдруг начинают сокращаться и решаться в уме.

Главная формула темы

ax2 + bx + c = a(x − x1)(x − x2)

a — старший коэффициент · x₁, x₂ — корни трёхчлена

Зачем это нужно

Трёхчлен — это «сжатые» скобки

Квадратный трёхчлен ax² + bx + c — это свёрнутая запись произведения двух скобок. Научишься разворачивать её обратно — и станет проще многое:

  • Сокращение дробей. Дробь (x²−5x+6)/(x−2) выглядит страшно, но после разложения числителя это (x−2)(x−3)/(x−2) = x−3. Без разложения сократить нельзя.
  • Решение уравнений. Произведение равно нулю, когда один из множителей — ноль. Это самый быстрый способ найти корни.
  • ОГЭ и подготовка к 9 классу. При построении параболы разложение сразу показывает точки пересечения с осью Ox.

Главный миф: «любой трёхчлен можно разложить на множители». Нет. Если у трёхчлена нет корней (дискриминант D<0), на множители с обычными числами он не раскладывается.

Что вспомнить перед стартом

Корни квадратного уравнения. Разложить = сначала найти корни трёхчлена, то есть решить ax²+bx+c=0.

Дискриминант. D = b²−4ac. Он заранее говорит, есть ли корни: D>0 — два, D=0 — один, D<0 — нет.

Теорема Виета. Для приведённого x²+px+q корни подбираются устно: сумма = −p, произведение = q. Часто корни видно без дискриминанта.

Ядро темы · правило

Найти корни — и записать через скобки

Если x₁ и x₂ — корни трёхчлена ax²+bx+c (то есть корни уравнения ax²+bx+c=0), то

ax² + bx + c = a(x − x₁)(x − x₂)
aстарший коэффициент (при x²), a ≠ 0. Обязательно выносится множителем перед скобками.
x₁первый корень. Ставится в скобку со знаком минус: (x − x₁).
x₂второй корень. Тоже через минус: (x − x₂).

Знаки — место частых ошибок. Если корень отрицательный, например x₁ = −3, то скобка получается (x − (−3)) = (x + 3). Минус в формуле и минус корня дают плюс.

Сначала проверь, возможно ли разложение

Три случая по знаку D

Перед разложением всегда смотри на дискриминант — он решает, будет ли что раскладывать:

D > 0
Два разных корня
Раскладывается: a(x−x₁)(x−x₂).
D = 0
Один корень (кратный)
Раскладывается: a(x−x₁)².
D < 0
Корней нет
На множители не раскладывается.

Разбираем вместе · думаю вслух

Эталонный пример

Разложить 2x² − 10x + 12

  1. Выписываем коэффициенты: a = 2, b = −10, c = 12. Замечаю: a ≠ 1 — значит, его придётся вынести в ответ, не потерять.
  2. Считаю дискриминант: D = (−10)² − 4·2·12 = 100 − 96 = 4. D > 0 — корни есть, разложение возможно.
  3. Нахожу корни: x = (10 ± √4)/(2·2) = (10 ± 2)/4, значит x₁ = 3, x₂ = 2. Это значения, где трёхчлен равен нулю.
  4. Записываю по формуле: 2x² − 10x + 12 = 2(x − 3)(x − 2). Множитель a=2 спереди обязателен: без него скобки дали бы x²−5x+6 — в 2 раза меньше нужного.
  5. Проверка: 2·(x−3)(x−2) = 2·(x²−5x+6) = 2x²−10x+12. Совпало с исходным — значит, верно.
Ответ: 2x² − 10x + 12 = 2(x − 3)(x − 2)

Наглядность · корни на графике

Разложение = нули параболы

Корни трёхчлена — это точки, где парабола y = ax²+bx+c пересекает ось Ox. Разложение просто «называет» эти точки. А если корней нет (D<0) — парабола до оси не достаёт, и раскладывать нечего.

Зелёная и янтарная точки — это x₁ и x₂, те самые числа из скобок разложения.

Тренажёр · бесконечная практика

Разложи трёхчлен сам

Нажми «Новый трёхчлен». Найди его корни и впиши их через точку с запятой (a виден в самом трёхчлене — его выносить не нужно, только назови корни). Если корней нет — напиши «нет». Потом проверь себя или посмотри полное решение со скобками.

Практика по нарастанию · нажми, чтобы проверить

Реши сам

Вставь число: x² − 9x + 20 = (x − 4)(x − *)понимание
Корни в сумме дают 9, в произведении 20. Один корень 4, значит второй — 5 (4·5=20, 4+5=9). Ответ: *= 5.
Можно ли разложить x² + x + 1?понимание
D = 1² − 4·1·1 = 1 − 4 = −3 < 0 → корней нет → не раскладывается.
Разложить x² − x − 12применение
D = 1 + 48 = 49, корни x₁ = 4, x₂ = −3. Ответ: (x − 4)(x + 3). Внимание: x₂=−3 даёт скобку (x+3).
Разложить 5x² − 5применение
Здесь b=0, c=−5. Корни: 5x²=5 → x²=1 → x₁=1, x₂=−1. Не забудь множитель a=5: 5(x − 1)(x + 1).
Что изменится для x² − 6x + 9, если D = 0?анализ
D = 36 − 36 = 0 → один корень x = 3. Скобки совпадают: разложение (x − 3)², а не две разные скобки.
Найди ошибку: 2x² − 8x + 6 = (x − 1)(x − 3)анализ
Потерян множитель a = 2. Скобки дают только x²−4x+3 — всё в 2 раза меньше. Верно: 2(x − 1)(x − 3).
Обратная задача: трёхчлен разложился как (x + 5)(x − 2). Восстанови его.анализ
Раскрываем скобки: (x+5)(x−2) = x² − 2x + 5x − 10 = x² + 3x − 10.

Где чаще всего ошибаются

Лови эти ловушки

  • Забывают старший коэффициент a. Пишут 2x²−10x+12 = (x−3)(x−2), но скобки дают лишь x²−5x+6 — в 2 раза меньше. Если a≠1 — всегда выноси его спереди и проверяй раскрытием.
  • Путают знаки корней в скобках. Корень x₁=−3, а пишут (x−3) вместо (x+3). Подставляй корень в формулу механически: (x−(−3)) = (x+3).
  • Раскладывают, когда корней нет. При D<0 пытаются «подобрать» скобки. Сначала считай D — если D<0, пиши «не раскладывается».
  • Бросают деление на 2a. Находят (b±√D), но забывают разделить на знаменатель 2a. Проговаривай формулу корней целиком.

Что дальше

Теперь у тебя есть главный инструмент для сокращения рациональных дробей. Разложи числитель и знаменатель — и одинаковые скобки сократятся:

(x² − 5x + 6)/(x − 2) = (x − 2)(x − 3)/(x − 2) = x − 3

Отсюда прямая дорога к дробно-рациональным уравнениям — там разложение нужно на каждом шаге.

Итог: разложить трёхчлен — значит найти корни и записать ax² + bx + c = a(x − x₁)(x − x₂), не потеряв ни множитель a, ни знаки корней.
