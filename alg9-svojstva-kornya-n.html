Свойства корня n-й степени

Правила, по которым корень «дружит» с умножением, делением и степенью — и категорически не дружит со сложением.

Главное свойство

ⁿ√(a·b) = ⁿ√a · ⁿ√b

a ≥ 0, b ≥ 0, n — натуральное, n ≥ 2

Зачем это нужно

Корни почти всегда приходится преобразовывать

Сами по себе корни встречаются редко, а вот их преобразования — постоянно. В геометрии теорема Пифагора и диагонали дают ответы вида √8, √50 — их принято дописывать до аккуратного вида. В физике корни сидят в формулах периода маятника и скорости. Дальше в алгебре через корни определяется степень с дробным показателем.

Свойства корня — это грамматика темы. Они позволяют привести громоздкое выражение к короткому, сравнить два корня без калькулятора и подготовить выражение к дальнейшим вычислениям.

И сразу разберёмся с главным мифом. Многие думают: «корень раскрывается по каждому слагаемому, как скобка». Это неверно. Проверь на числах:

√(9 + 16) = √25 = 5
а √9 + √16 = 3 + 4 = 7
5 ≠ 7 — по сумме корень «разносить» нельзя.
√(9 · 16) = √144 = 12
и √9 · √16 = 3 · 4 = 12
12 = 12 — по произведению можно.

Запомни это сразу — считай, половина темы уже сделана. Свойства работают только для произведения и частного, а не для суммы и разности.

Что вспомнить с прошлого шага

Корень n-й степени. Арифметический корень n-й степени из неотрицательного числа — это такое неотрицательное число, которое в n-й степени даёт подкоренное.

Например ∛8 = 2, потому что 2³ = 8; √49 = 7, потому что 7² = 49.

В записи ⁿ√a: n — показатель корня, a — подкоренное выражение. Значок √a без индекса — это квадратный корень (n = 2).

Ядро темы

Шесть свойств — все правила разом

Пусть n — натуральное, n ≥ 2, а буквы под корнем — неотрицательные числа (a ≥ 0, b ≥ 0, причём b > 0 там, где b в знаменателе). Тогда:

Зелёное — работает всегда. Жёлтое — работает, но проверь знак. Красное — ловушка, так писать нельзя.

Почему так, а не иначе

Корень — это степень с дробным показателем. А степень произведения равна произведению степеней — значит и корень распределяется по множителям. Степень суммы так не раскладывается — значит и корень по сумме не раскладывается. Одна и та же причина в обоих случаях.

Условие применимости
Под чётным корнем всё должно быть неотрицательно
Именно поэтому √(a²) = |a|, а не просто a. Если по условию a ≥ 0 — модуль можно снять и написать √(a²) = a. Перед вынесением буквы всегда проверяй её знак.

Разбираем вместе · думаю вслух

Эталонный пример: упростить √72

√72 → привести к виду «число · корень»

  1. Раскладываю 72 на множители так, чтобы один из них был полным квадратом: √72 = √(36·2), ведь 36 = 6². Зачем: только квадрат сможет выйти из-под квадратного корня целым.
  2. Применяю свойство корня из произведения: √(36·2) = √36 · √2. Это законно — под корнем именно умножение, а не сложение.
  3. Извлекаю то, что извлекается: √36 = 6. Множитель 2 корня не имеет, поэтому остаётся под ним.
  4. Собираю ответ: 6√2.
Проверка: (6√2)² = 6² · (√2)² = 36 · 2 = 72 ✓

Пример 2: допиши шаг сам

Упростить ∛54

  1. Ищу множитель — точный куб (корень-то третьей степени): 54 = 27 · 2, где 27 = 3³.
  2. Раскрываю по произведению: ∛54 = ∛(27·2) = ∛27 · ∛2.
  3. А теперь сам: чему равен ∛27?
Проверить пропущенный шагэталон
∛27 = 3, потому что 3³ = 27. Значит ответ 3∛2. Проверка: (3∛2)³ = 27 · 2 = 54 ✓

Пример 3: решай сам

Вычислить √50 · √2

Подсказка: используй свойство корня из произведения в обратную сторону: √a · √b = √(a·b). Такой ход часто спасает: два некрасивых корня вместе дают красивое число.

Показать ответэталон
√50 · √2 = √(50·2) = √100 = 10

Практика по нарастанию

Какое равенство верное: √(9+16) = √9 + √16 или √(9·16) = √9·√16?понимание
Верное — второе. √(9·16) = √144 = 12 и √9·√16 = 3·4 = 12 — работает свойство корня из произведения. Первое — ловушка: √25 = 5, а 3 + 4 = 7.
Прочитай запись 5√3: что вынесли и что осталось?понимание
Из-под корня вынесли 5 (то есть под корнем был множитель 5² = 25), а под корнем остался множитель 3. Целиком: 5√3 = √(25·3) = √75.
Упрости: √48применение
√48 = √(16·3) = √16 · √3 = 4√3. Проверка: (4√3)² = 16·3 = 48 ✓
Упрости: √98применение
√98 = √(49·2) = √49 · √2 = 7√2. Проверка: (7√2)² = 49·2 = 98 ✓
Упрости: ∛16применение
∛16 = ∛(8·2) = ∛8 · ∛2 = 2∛2. Куб, а не квадрат: 8 = 2³. Проверка: (2∛2)³ = 8·2 = 16 ✓
Внеси множитель под корень: 2√5 и 3∛2применение
2√5 = √(2²·5) = √20; 3∛2 = ∛(3³·2) = ∛54. Обрати внимание: число возводится в степень, равную показателю корня.
Вычисли: √12 · √3 и √75 / √3применение
√12 · √3 = √36 = 6; √75 / √3 = √25 = 5. Оба раза свойство применили «справа налево»: два корня собрали в один.
Найди ошибку: «√(a²) = a для любого a»анализ
Верно только при a ≥ 0. При отрицательном a равенство ломается: при a = −3 слева √((−3)²) = √9 = 3, а справа −3. Правильная запись — √(a²) = |a|: арифметический корень неотрицателен всегда.
Что изменится в ответе √(a²·b), если убрать условие a ≥ 0?анализ
При a ≥ 0 ответ a√b. Без этого условия множитель выходит по модулю: √(a²·b) = |a|·√b — иначе при отрицательном a слева получилось бы неотрицательное число, а справа отрицательное.
Обратная задача: какое выражение под корнем дало после упрощения 4√2?анализ
Заносим множитель обратно: 4√2 = √(4²·2) = √(16·2) = √32. Значит исходно было √32.

Где чаще всего ошибаются

Четыре ловушки

  • Распределяют корень по сумме. Пишут √(a + b) = √a + √b — это ложь. Контрпример: √(9+16) = √25 = 5, но √9 + √16 = 3 + 4 = 7. Перед каждым «раскрытием» спроси себя: под корнем умножение или сложение?
  • Выносят неполный квадрат. Из √72 «выносят» что попало — например пишут √72 = 8√1 — или путают, какой множитель должен быть точным квадратом. Приём: всегда раскладывай подкоренное на (полный квадрат) · (остаток); из-под квадратного корня выходит корень именно из квадрата, из-под кубического — из куба.
  • Теряют условие неотрицательности. Пишут √(a²) = a, забывая модуль. Правильно √(a²) = |a|; убрать модуль можно, только если по условию a ≥ 0.
  • Путают показатель корня и показатель степени. В свойстве ⁿ√(ak) = (ⁿ√a)k меняют местами n и k. Помни: индекс корня n остаётся на месте, наружу выходит именно степень k.

Проверь себя · объясни своими словами

Три вопроса на понимание

  1. Сформулируй словами: чему равен корень из произведения двух неотрицательных множителей?
  2. Верно ли, что √(a + b) = √a + √b? Приведи числовой контрпример.
  3. Упрости √50 и объясни, какой множитель ты вынес и почему именно его.
Сверить ответысамопроверка
1) Он равен произведению корней из этих множителей: ⁿ√(a·b) = ⁿ√a · ⁿ√b.
2) Неверно. Контрпример: √(9+16) = 5, а √9 + √16 = 7.
3) √50 = √(25·2) = 5√2. Вынес 25, потому что это полный квадрат (25 = 5²) — только такой множитель выходит из-под квадратного корня целым числом.

Итог одним предложением: свойства корня позволяют распределять корень по умножению, делению и степени (но не по сумме!) и за счёт этого упрощать выражения, выносить множители и сравнивать корни.

Что дальше

Следующий шаг — степень с рациональным показателем. Там корень и степень окончательно сливаются в одну операцию:

ⁿ√(ak) = ak/n

И все шесть свойств, которые ты выучил здесь, превращаются в уже знакомые свойства степеней. Так что это не новая тема, а та же самая — записанная короче.
