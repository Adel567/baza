Арифметическая прогрессия

Числа, которые растут одинаковыми шагами. Одна формула находит любой член — хоть сотый, — а вторая складывает их все сразу.

Любой член прогрессии

an = a1 + (n − 1)·d

a1 — первый член, d — разность (шаг), n — номер

Сумма первых n членов

Sn = (a1 + an)·n / 2

полусумма краёв, умноженная на количество

Зачем это нужно

Одинаковый шаг — везде вокруг

Ты копишь деньги и каждый месяц кладёшь в копилку одну и ту же сумму. Или ряды кресел в кинотеатре: в первом ряду 12 мест, в каждом следующем на 2 больше. Или сосулька, что каждый час удлиняется на одинаковую величину. Везде, где к числу раз за разом прибавляется одно и то же, прячется арифметическая прогрессия.

Зачем формула, а не счёт «по пальцам»? Чтобы узнать, сколько мест в 30-м ряду, не выписывая все 30 строк. А чтобы узнать, сколько мест во всём зале, есть вторая формула — суммы. Считаешь в одно действие вместо сложения сотни чисел.

Главное заблуждение: «раз числа растут — это прогрессия». Нет. Арифметическая — только если растут (или убывают) на одну и ту же величину каждый шаг. Ряд 2, 4, 8, 16 растёт, но там каждый раз умножают на 2 — это уже другая история.

Что вспомнить с прошлого шага

Последовательность — это числа по порядку, у каждого свой номер: a1, a2, a3, … Номер n — всегда натуральное число (1, 2, 3, …), нет «члена с номером 2,5».

Отрицательные числа. Разность d бывает отрицательной, и тогда важно не потерять знак: прибавить −4 — это то же, что вычесть 4.

Суть темы

Начинаем с числа и шагаем одинаковыми шагами

Арифметическая прогрессия — это последовательность, где каждый следующий член получается из предыдущего прибавлением одного и того же числа. Это число называют разностью и обозначают d. Размер шага — это и есть d.

Символом смысл записывают так: an+1 = an + d — «следующий = текущий + шаг». А если прогрессия уже дана и надо найти шаг: d = an+1 − an — «из следующего вычесть предыдущий». В настоящей прогрессии результат для любой соседней пары один и тот же.

По знаку d прогрессия ведёт себя по-разному:

d > 0
Возрастает
Каждый член больше предыдущего. Пример: 3, 7, 11, 15…
d = 0
Постоянна
Все члены одинаковы. Пример: 5, 5, 5, 5…
d < 0
Убывает
Каждый член меньше предыдущего. Пример: 20, 16, 12…

Откуда берётся (n − 1)

Формула любого члена

Чтобы дойти от первого члена до n-го, нужно сделать не n, а (n − 1) шагов. До 2-го члена — 1 шаг, до 3-го — 2 шага, до n-го — (n − 1) шагов. Каждый шаг добавляет по d, поэтому всего прибавляем (n − 1)·d:

n-й член

an = a1 + (n − 1)·d

Проверь на первом члене: при n = 1 скобка (1 − 1) = 0, значит a1 = a1. Сходится.

Запомни как считалочку: шагов на один меньше, чем номер.

Разбираем вместе · думаю вслух

Эталонный пример: найти член

a1 = 5,  d = 3.  Найти a10.

  1. Записываю формулу n-го члена: an = a1 + (n − 1)·d. Почему именно её — она связывает номер члена с первым членом и разностью.
  2. Подставляю n = 10: a10 = 5 + (10 − 1)·3. Почему 10 − 1 — до 10-го члена от первого нужно 9 шагов, а не 10.
  3. Считаю скобку: 10 − 1 = 9, значит a10 = 5 + 9·3.
  4. Умножаю и складываю: 9·3 = 27, затем 5 + 27 = 32.
Ответ: a10 = 32.

a1 = 20,  d = −4  (убывает).  Найти a7.

  1. Та же формула: a7 = 20 + (7 − 1)·(−4).
  2. Скобка: 7 − 1 = 6, значит a7 = 20 + 6·(−4).
  3. Аккуратно со знаком: 6·(−4) = −24, а прибавить −24 — это вычесть: 20 − 24 = −4. Здесь легче всего потерять минус.
Ответ: a7 = −4.

Складываем с концов

Формула суммы

Маленького Гаусса попросили сложить все числа от 1 до 100. Он мгновенно дал 5050: сообразил, что 1 + 100 = 2 + 99 = 3 + 98 = … = 101, и таких пар ровно 50. Значит сумма — это 101·50.

Та же идея работает всегда. Если сумму переписать в обратном порядке и сложить с исходной, каждая пара (первый + последний, второй + предпоследний, …) даёт одно и то же число a1 + an. Таких пар n штук, но сумму мы взяли дважды — поэтому делим на 2:

Если знаешь a1 и an

Sn = (a1 + an)·n / 2

полусумма краёв × количество

Если знаешь a1 и d

Sn = (2a1 + (n − 1)d)·n / 2

то же самое, но an уже подставлен

Какую брать? Дан последний член an — удобнее первая. Дана разность d, а последний член неизвестен — вторая (или сначала найди an, потом первую).

a1 = 3,  d = 4.  Найти сумму первых 20 членов.

  1. Дана разность d, последний член не дан → беру вторую формулу: Sn = (2a1 + (n − 1)d)·n / 2.
  2. Подставляю a1 = 3, d = 4, n = 20: S20 = (2·3 + (20 − 1)·4)·20 / 2. n = 20 — это количество членов, не путать с самим членом.
  3. Считаю скобку по действиям: 2·3 = 6; 20 − 1 = 19; 19·4 = 76; 6 + 76 = 82.
  4. Домножаю: S20 = 82·20 / 2 = 82·10 = 820.
Ответ: S20 = 820.  (Проверка первой формулой: a20 = 3 + 76 = 79; (3 + 79)·20/2 = 820. Сошлось.)

Покрути сам · интерактив

Члены сидят на одной прямой

Двигай ползунки a1 и d. Каждый член — точка (номер; значение). Смотри: точки всегда ложатся на прямую, а промежуток между соседями — ровно d. Именно постоянный шаг делает прогрессию арифметической.

d = 3 > 0 · прогрессия возрастает

2, 5, 8, 11, 14, …

Поставь d = 0 — точки выстроятся в горизонтальную линию (все члены равны). Сделай d отрицательным — прямая пойдёт вниз, прогрессия убывает.

Тренажёр · бесконечная практика

Реши сам

Нажми «Новая задача». Введи ответ числом (отрицательное — с минусом), потом проверь себя или посмотри пошаговое решение.

a1 = 5, d = 3. Найди a10.

Где чаще всего ошибаются

Лови эти ловушки

  • Берут n вместо (n − 1). Пишут an = a1 + n·d. Тогда для a1 вышло бы a1 + d — а это уже a2. Проверяй на n = 1: должно получиться ровно a1.
  • Находят разность наоборот. d = (следующий) − (предыдущий), то есть из бо́льшего по номеру вычитаем меньший. Для 7, 11, 15 это 11 − 7 = 4, а не 7 − 11.
  • Путают разность d и первый член a1. В «7, 11, 15…» пишут d = 7 (взяли первое число) вместо d = 4. a1 — стартовое число, d — шаг между соседями.
  • Теряют минус при отрицательной d. В 20 + 6·(−4) пишут 20 + 24. Верно: 6·(−4) = −24, прибавить отрицательное — вычесть.
  • В сумме забывают делить на 2. Проверь на малом: 1 + 2 + 3 = 6, а (1 + 3)·3 = 12. Делить на 2 обязательно.
  • Путают номер n и сам член an. В формулу количества идёт n (например 20), а не значение члена (например 79).

Проверь понимание

Объясни своими словами

  1. Запиши формулу n-го члена и скажи, что означает каждая буква.
  2. Почему в формуле стоит (n − 1), а не n? Объясни на примере 3-го члена.
  3. В прогрессии 1, 4, 7, 10, … чему равны d и a5? (d = 3, a5 = 13)
  4. Почему в формуле суммы стоит деление на 2?

Итог одним предложением: арифметическая прогрессия — это последовательность с постоянным шагом d, любой член находят по an = a1 + (n − 1)·d, а их сумму — по Sn = (a1 + an)·n/2.

Что дальше

Есть и другой тип роста — когда числа не прибавляются, а умножаются на одно и то же число. Это геометрическая прогрессия:

bn+1 = bn · q

Тот же принцип «одинакового действия на каждом шаге», только вместо шага +d — множитель q. И у неё будут свои формулы n-го члена и суммы.

Проверка на выходе: запиши an по памяти · сколько шагов до 6-го члена? · найди d в 100, 93, 86…
