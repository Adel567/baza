Рациональные дроби: смысл, допустимые значения, основное свойство

Задания на две первые темы главы. Уровни идут по нарастанию: разминка за 7 класс → узнавание и вычисление → ОДЗ → основное свойство → задачи со звёздочкой. Ответы спрятаны — открывай только после того, как решил.

Уровень 0 · разминка

Без этого дроби не пойдут

Дроби целиком стоят на разложении на множители из 7 класса. Если здесь спотыкаешься — сначала чиним это.

разминка

Разложи на множители и посчитай

Цель: вспомнить вынесение множителя, ФСУ, группировку и действия с обычными дробями.

  1. Вынеси общий множитель: 5x² − 10x
  2. Разность квадратов: x² − 49
  3. Квадрат суммы: x² + 6x + 9
  4. Посложнее: 4x² − 25y²
  5. Группировка: ax + ay + 2x + 2y
  6. Посчитай в обычных дробях: 3/8 + 5/12 и 2/3 : 4/9
Ответы
1) 5x(x − 2) · 2) (x − 7)(x + 7) · 3) (x + 3)² · 4) (2x − 5y)(2x + 5y) · 5) a(x+y) + 2(x+y) = (a + 2)(x + y) · 6) 19/24 и 2/3 · 9/4 = 3/2

Уровень A · узнавание и вычисление

Что такое рациональная дробь

A · база

Целое или дробное · значение дроби

Цель: отличать дробное выражение от целого и подставлять числа.

  1. Какие из выражений дробные, а какие целые?
    (x − 3)/75/(x − 3)x² − 4x(a + b)/(ab)½·(x + 1)3/(x² + 1)
  2. Найди значение (2x − 1)/(x + 3) при x = 2, при x = 0, при x = −1
  3. Найди значение (a² − b²)/(a + b) при a = 7, b = 3
  4. Найди значение (x² + 1)/(x − 1) при x = 3
  5. При каком x дробь x/(x − 5) равна нулю?
  6. При каком x дробь (x − 4)/(x + 2) равна нулю?
  7. Найди значение 3m/(m² − 1) при m = 2
  8. Верно ли, что (x − 2)/(x − 2) = 1 при любом x? Объясни.
Ответы
1) дробные — 5/(x−3), (a+b)/(ab), 3/(x²+1) (в знаменателе переменная); остальные целые: деление на число дробным выражением не делает.
2) 3/5; −1/3; −3/2
3) (49 − 9)/10 = 4
4) 10/2 = 5
5) x = 0 (числитель ноль, знаменатель −5 ≠ 0)
6) x = 4
7) 6/3 = 2
8) Нет. При x = 2 знаменатель равен нулю — дробь не имеет смысла. Равенство верно при всех x ≠ 2.

Уровень B · допустимые значения

Когда дробь имеет смысл

B · ОДЗ

Найди значения переменной, при которых дробь не имеет смысла

Алгоритм один: приравнять знаменатель к нулю и решить.

  1. 7/x
  2. (x + 1)/(x − 4)
  3. 5/(2x + 6)
  4. (x − 1)/(x² − 9)
  5. 3/(x² + 4) — внимательно!
  6. 2a/(a² − 5a)
  7. x/((x − 1)(x + 7))
  8. (y + 2)/(y² + 6y + 9)
Ответы
1) x ≠ 0
2) x ≠ 4
3) 2x + 6 = 0 → x ≠ −3
4) x² − 9 = (x−3)(x+3) → x ≠ 3 и x ≠ −3
5) x² + 4 > 0 всегда → дробь имеет смысл при любом x, запретов нет
6) a² − 5a = a(a − 5) → a ≠ 0 и a ≠ 5
7) x ≠ 1 и x ≠ −7
8) y² + 6y + 9 = (y + 3)² → y ≠ −3

Уровень C · основное свойство вперёд

Домножаем верх и низ

C · приведение

Восстанови пропущенное выражение

Смотри, во сколько раз (или на что) вырос знаменатель — ровно на то же домножь числитель.

  1. 3/x = ? /(5x)
  2. 5/(x − 2) = ? /(2x − 4)
  3. 2/(a + 1) = ? /((a + 1)(a − 1))
  4. x/(x − 3) = ? /(x² − 9)
  5. 1/(x + 4) = ? /(x² + 8x + 16)
  6. Приведи к знаменателю 12x: 5/(4x) и 7/(6x)
  7. Приведи к общему знаменателю: 1/(x − 1) и 1/(x + 1)
  8. Приведи к общему знаменателю: 3/(x) и 2/(x + 5)
Ответы
1) знаменатель × 5 → 15
2) 2x − 4 = 2(x − 2), множитель 2 → 10
3) множитель (a − 1) → 2(a − 1) = 2a − 2
4) x² − 9 = (x−3)(x+3), множитель (x + 3) → x(x + 3) = x² + 3x
5) (x + 4)², множитель (x + 4) → x + 4
6) 15/(12x) и 14/(12x)
7) общий знаменатель (x − 1)(x + 1): (x + 1)/((x−1)(x+1)) и (x − 1)/((x−1)(x+1))
8) общий знаменатель x(x + 5): 3(x + 5)/(x(x+5)) и 2x/(x(x+5))

Уровень D · основное свойство назад

Сокращаем и играем со знаком

D · сложнее

Сократи дробь · перевороты знака

Главное правило: сокращать можно только множитель, а не слагаемое.

  1. 12ab/(18b)
  2. (5x − 15)/10
  3. (x² − 16)/(x + 4)
  4. (3a + 3b)/(a + b)
  5. (2 − x)/(x − 2)
  6. (x − y)/(y − x)
  7. Запиши −3/(x − 7) со знаменателем 7 − x
  8. Найди ошибку: ученик написал (x + 5)/x = 5. Что не так?
Ответы
1) 2a/3 (при b ≠ 0)
2) 5(x − 3)/10 = (x − 3)/2
3) (x−4)(x+4)/(x+4) = x − 4, при x ≠ −4
4) 3(a + b)/(a + b) = 3, при a + b ≠ 0
5) 2 − x = −(x − 2) → ответ −1
6) −1
7) домножаем верх и низ на −1: 3/(7 − x)
8) Он «сократил» x, но x — слагаемое в числителе, а не множитель всей дроби. Сокращать можно только то, на что верх и низ делятся целиком. Проверка числом: при x = 1 слева 6, справа 5 — не равно.

Уровень E · со звёздочкой

Подумать подольше

E · ★

Задачи на понимание, а не на технику

  1. При каких x дробь (x² − 9)/(x − 3) не имеет смысла? Чему она равна при остальных x?
  2. Докажи, что (x² + 2x + 1)/(x + 1) = x + 1 при всех допустимых x. Какие x недопустимы?
  3. При каких целых x значение дроби 6/(x − 1) — целое число?
  4. Сократи (x² − 4)/(x² + 4x + 4) и выпиши ограничения.
  5. Дробь (2x + 6)/(x + 3) после сокращения равна 2. Почему тогда нельзя сказать, что это выражение равно 2 при любом x?
  6. Придумай сам дробь, которая не имеет смысла ровно при x = 5 и x = −2.
Ответы
1) Не имеет смысла при x = 3. При остальных (x−3)(x+3)/(x−3) = x + 3.
2) x² + 2x + 1 = (x + 1)², делим на (x + 1) → x + 1. Недопустимо x = −1.
3) Нужно, чтобы x − 1 было делителем 6: ±1, ±2, ±3, ±6 → x ∈ {2, 0, 3, −1, 4, −2, 7, −5}.
4) (x−2)(x+2)/(x+2)² = (x − 2)/(x + 2), при x ≠ −2.
5) Потому что при x = −3 исходная дробь вообще не существует (знаменатель ноль). Сокращение не «возвращает» запрещённые значения.
6) Например 1/((x − 5)(x + 2)) — годится любая дробь с таким знаменателем.

Разбор ошибок

Три ловушки, в которые попадают почти все

1. Сокращают слагаемые. (a + b)/a = b — неверно. Проверяй числом: подставь a = 1, b = 1.

2. Прибавляют вместо умножения. Основное свойство — про умножение и деление верха и низа на одно и то же, никогда про сложение.

3. Забывают ОДЗ после сокращения. Запрет ставится по исходному знаменателю, до всех преобразований.

Что дальше

Маршрут по главе

Пройдено: определение дроби и допустимые значения · основное свойство.

  • Следующая тема — сокращение дробей. Она полностью держится на разложении на множители: если уровень 0 в этом листке шёл тяжело, отдельно добираем ФСУ и группировку, и только потом идём дальше.
  • Затем — сложение и вычитание с одинаковыми знаменателями (лёгкий шаг), потом приведение к общему знаменателю и разные знаменатели (самый трудный пункт главы).
  • После — умножение, деление и возведение дроби в степень: технически проще сложения, идёт быстро.
  • Замыкает главу — тождественные преобразования (многоэтажные дроби) и функция y = k/x.
