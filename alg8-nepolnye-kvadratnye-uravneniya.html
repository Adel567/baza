Неполные квадратные уравнения

Когда у квадратного уравнения не хватает одного кусочка — дискриминант не нужен. Такие уравнения решаются устно, за десять секунд.

Общий вид

ax² + bx + c = 0

неполное — это когда b = 0, или c = 0, или сразу оба. При этом a ≠ 0 всегда

Зачем это нужно

Не превращай простое в сложное

Квадратное уравнение в общем виде — это ax² + bx + c = 0. Но очень часто в задачах какой-то из коэффициентов b или c оказывается нулём. И тогда тащить тяжёлую формулу с дискриминантом просто незачем: есть приём короче, быстрее и точнее.

Такие уравнения вылезают постоянно: когда ищешь нули функции, в задачах на площадь («при каком x площадь квадрата равна нулю»), в физике при свободном падении — из s = ½gt² время находится из уравнения вида at² = s.

Главный миф: «раз уравнение квадратное — значит, всегда нужен дискриминант». Нет. Для неполных уравнений есть способы проще, и они дают точный ответ вообще без вычисления D.

Что вспомнить перед стартом

Квадратное уравнение — это ax² + bx + c = 0, где a — число при x², b — при x, c — свободный член.

Коэффициент a никогда не равен нулю — иначе x² исчезнет и уравнение перестанет быть квадратным.

Из простейшего уравнения x² = a: при a > 0 два корня ±√a, при a = 0 один корень 0, при a < 0 корней нет.

Сначала опознай вид

Три вида — три приёма

Уравнение называют неполным, если в нём нет слагаемого с x (b = 0), или нет свободного члена (c = 0), или нет ни того ни другого. У каждого вида — свой короткий приём:

ВидЧего нетЧто делаем
ax² + bx = 0нет cвыносим x за скобку
ax² + c = 0нет bвыражаем x² и извлекаем корень
ax² = 0нет b и cсразу x = 0

Главная идея одна: не потерять ни одного корня. Именно на потере корня тут ломается большинство.

Вид 1 · нет свободного члена

ax² + bx = 0 — выносим x за скобку

В обоих слагаемых есть общий множитель x. Выносим его:

x(ax + b) = 0

произведение равно нулю ⟺ хотя бы один множитель равен нулю

Значит, x = 0 или ax + b = 0, то есть x = −b/a.

У такого уравнения всегда два корня, и один из них — всегда ноль. Запомни это как факт: увидел «ax² + bx = 0» — сразу знай, что x = 0 в ответе будет.

Вид 2 · нет слагаемого с x

ax² + c = 0 — извлекаем корень

Переносим c вправо и делим обе части на a:

x² = −c / a

дальше всё решает знак правой части

А дальше — три варианта, и они зависят только от того, какое число получилось справа:

−c/a > 0
Два корня
x = ±√(−c/a). Это когда a и c разных знаков.
−c/a = 0
Один корень
x = 0.
−c/a < 0
Корней нет
Квадрат не бывает отрицательным. Это когда a и c одного знака.

Знак ± означает «плюс и минус», то есть сразу два значения. Забыл про него — потерял корень.

Корни x = 5 и x = −5 стоят симметрично относительно нуля, на одинаковом расстоянии. Вот почему их именно два и почему они противоположны по знаку.

Вид 3 · нет ни b, ни c

ax² = 0 — самый быстрый случай

Делим обе части на a (можно: a ≠ 0) и получаем x² = 0. А квадрат равен нулю только у самого нуля. Значит, один корень: x = 0. Никакого «двух корней» тут нет.

Покрути сам · интерактив

Корни — это точки, где парабола протыкает ось

Выбери вид уравнения, подвигай коэффициенты и смотри на зелёные точки: это и есть корни. Для вида ax² + c = 0 поймай момент, когда парабола отрывается от оси — и корни пропадают.

два корня

x² − 4x = 0

x = 0; x = 4

Обрати внимание: у вида ax² + bx = 0 парабола всегда проходит через начало координат — поэтому корень x = 0 там есть при любых a и b. А у вида ax² = 0 она касается оси ровно в одной точке.

Разбираем вместе

Эталонный пример: вид 1

3x² − 12x = 0

  1. Свободного члена нет → выносим x за скобку: x(3x − 12) = 0. Почему: общий множитель x есть в обоих слагаемых.
  2. Произведение равно нулю → приравниваем к нулю каждый множитель: x = 0 или 3x − 12 = 0. Почему: ноль получается, только если хоть один множитель — ноль.
  3. Из второго: 3x = 12, значит x = 4.
Ответ: x = 0 и x = 4. Корень x = 0 не теряем — это типичная ловушка.

Пример с пропущенным шагом: вид 2

2x² − 50 = 0

  1. Переносим свободный член: 2x² = 50.
  2. Делим на 2: x² = 25.
  3. __________ (допиши сам: извлеки корень и запиши оба ответа)
Что должно получитьсяпроверка
Извлекаем корень с двумя знаками: x = ±5, то есть x = 5 и x = −5.

Решай сам: вид 2, особый случай

x² + 9 = 0

Сначала предскажи: сколько корней?ответ
Переносим: x² = −9. Квадрат отрицательным быть не может → корней нет. Здесь a и c одного знака (оба плюс) — верный признак, что корней не будет.

Теперь ты · нажми, чтобы проверить

Мини-практика

Какое уравнение неполное: а) x² + 5x + 6 = 0; б) x² − 16 = 0; в) 7x² + 2x = 0?понимание
Неполные — б и в. В б) не хватает слагаемого с x (b = 0), в в) не хватает свободного члена (c = 0). А а) — полное: есть все три коэффициента.
5x² − 20x = 0применение
x(5x − 20) = 0 → x = 0 или 5x = 20, то есть x = 4. Ответ: x = 0, x = 4.
x² − 49 = 0применение
x² = 49 → x = ±7. Ответ: x = 7, x = −7.
4x² = 0применение
Делим на 4: x² = 0 → x = 0, один корень.
Что изменится, если… В x² − k = 0 при каких k два корня, при каком один, при каких ни одного?анализ
Переносим: x² = k. Два корня при k > 0 (это ±√k), один при k = 0 (сам ноль), ни одного при k < 0 (квадрат не бывает отрицательным).
Найди ошибку: «x² − 6x = 0, делим на x, получаем x − 6 = 0, x = 6»анализ
Ученик потерял корень x = 0. Делить обе части на x нельзя: x может оказаться нулём, а на ноль делить запрещено. Правильно — вынести x за скобку: x(x − 6) = 0 → x = 0 или x = 6. Ответ: два корня, 0 и 6.

Тренажёр · бесконечная практика

Реши неполное уравнение сам

Нажми «Новое уравнение», определи вид и реши. Корни вводи через точку с запятой (порядок не важен, минус можно любой), а если корней нет — напиши слово нет. Потом проверь себя или посмотри пошаговое решение.

3x² − 12x = 0

Где чаще всего ошибаются

Лови эти три ловушки

  • Делят на x и теряют корень x = 0. В уравнении ax² + bx = 0 нельзя делить обе части на x — ведь x может равняться нулю, а на ноль делить нельзя. Правильно выносить x за скобку: так корень x = 0 сохраняется.
  • При ax² + c = 0 теряют второй корень. Из x² = 25 пишут только x = 5, забывая x = −5. Помни про ±: корень из положительного числа даёт два значения.
  • Решают ax² = −c при разных знаках. Например, из x² = −4 пишут «x = 2». Так нельзя: если правая часть отрицательна, корней НЕТ. Сначала проверь знак правой части, потом извлекай корень.

Что дальше

Неполные уравнения — это быстрый случай. А когда все три коэффициента на месте, работает универсальный инструмент — формула корней:

x = (−b ± √D) / (2a)

Она решает любое квадратное уравнение, в том числе и неполное — просто дольше. Поэтому вид сначала опознаём, и только потом решаем.

Итог: неполное квадратное уравнение решается коротким приёмом под свой вид — вынесение x, извлечение корня или сразу x = 0. Главное — не потерять корень x = 0 и правильно учесть знаки.
