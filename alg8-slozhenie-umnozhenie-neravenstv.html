Сложение и умножение неравенств. Оценка выражений

Точное значение неизвестно — известны только границы. Научимся из границ слагаемых получать границы суммы, разности и произведения.

Два правила, которые надо знать наизусть

если a > b и c > d, то a + c > b + d
если a > b > 0 и c > d > 0, то a·c > b·d

Складывать неравенства одного знака можно всегда. Перемножать — только когда все четыре числа положительны.

Зачем это нужно

Когда точного числа нет, а ответ нужен

Ты измерил комнату: длина получилась где-то от 4,2 до 4,5 м, ширина — от 3,0 до 3,2 м. Какой может быть площадь? Точного числа нет ни у длины, ни у ширины — значит, и площадь получится не числом, а промежутком. Чтобы его найти, надо уметь «складывать» и «перемножать» неравенства: из оценок отдельных величин получать оценку результата.

Это базовый навык приближённых вычислений: периметр и площадь, стоимость покупки при скачущих ценах, физическое измерение с допуском. И дальше он понадобится в системах неравенств.

Главный миф, который надо разрушить прямо сейчас: «с уравнениями всё можно делать одинаково — значит, и неравенства можно вычитать и делить почленно так же». Нет. Вычитать и делить неравенства почленно нельзя, а умножать можно только при дополнительном условии. Об этом весь урок.

Что вспомнить с прошлого шага

Запись 3 < a < 5 читается «a больше 3 и меньше 5», то есть a лежит между 3 и 5.

К обеим частям неравенства можно прибавлять одно и то же число — знак сохраняется.

При умножении обеих частей на отрицательное число знак неравенства переворачивается: из 1 < y получается −1 > −y.

Вся тема на одной картинке

Три действия — три разных ответа

Запомни цвет-код: зелёное делаем смело, жёлтое — только с проверкой, красное — не делаем никогда.

a + c > b + d
Сложение — можно всегда
Неравенства одного знака складываем почленно. Никаких условий на знаки чисел нет.
a·c > b·d
Умножение — только для положительных
Нужно, чтобы все четыре числа были положительны. Иначе правило ломается.
a − c > b − d
Вычитание — почленно нельзя
И деление тоже. Разность оценивают иначе: сначала переворот, потом сложение.

Словами: «большее плюс большее даёт большее» — верно всегда. «Большее на большее даёт большее» — верно только для положительных чисел.

Задания 13 и 21. Оценка выражения — типовой вопрос «между какими числами лежит»: складывать и умножать неравенства можно, но только по правилам.

Правило крупно

Оценка выражения: границы результата

Пусть про величины известны их границы:

m < x < M   и   p < y < P

  1. Сумма (всегда): m + p < x + y < M + P. Нижняя граница суммы — сумма двух нижних, верхняя — сумма двух верхних.
  2. Произведение (только если все границы положительны): m·p < x·y < M·P.
  3. Разность: сначала переворачиваем неравенство для y, умножая на −1: −P < −y < −p. Затем складываем с неравенством для x: m − P < x − y < M − p.
Смысл: наименьшее значение суммы — когда оба слагаемых наименьшие; наибольшее — когда оба наибольшие.

В прикладных задачах единицы сохраняются: метры складываем с метрами, а при умножении длин получаем м2.

Покрути сам · интерактив

Две вилки на прямой — и что выходит в ответе

Двигай границы: a лежит где-то на своей полоске, b — на своей. Внизу видно, какая полоска получается у суммы и у разности. Смотри, какие концы складываются между собой.

a + b5 < a + b < 9
a − b−1 < a − b < 3
a · b6 < a · b < 20

Все четыре крайних произведения — из них и берутся границы:

b = 2b = 4
a = 3612
a = 51020

Поставь границы a отрицательными (например, от −5 до −3) и посмотри на таблицу: наименьшее произведение окажется совсем не в углу «нижняя × нижняя». Вот почему для отрицательных правило «перемножаем нижние с нижними» не работает.

Разбираем вместе · думаю вслух

Эталонный пример

Дано: 3 < a < 5 и 2 < b < 4. Оценить a + b и a·b.

  1. Смотрю на знаки: оба неравенства «меньше», значит смысл одинаковый — складывать можно.
  2. Складываю нижние границы: 3 + 2 = 5. Почему именно нижние с нижними: самая маленькая сумма получится, когда оба слагаемых самые маленькие.
  3. Складываю верхние: 5 + 4 = 9. Самая большая сумма — когда оба слагаемых самые большие.
  4. Записываю: 5 < a + b < 9.
  5. Теперь произведение. Проверяю условие: все четыре границы (3, 5, 2, 4) положительны — перемножать можно.
  6. Нижняя: 3·2 = 6; верхняя: 5·4 = 20. Произведение положительных чисел тем больше, чем больше множители.
5 < a + b < 9   и   6 < a·b < 20

Самое трудное место

Разность: переворот, потом сложение

Вычитать неравенства напрямую нельзя. Правильный путь — превратить вычитание в сложение.

Дано: 10 < x < 12 и 1 < y < 3. Оценить x − y.

  1. Замечаю: x − y = x + (−y). Значит, мне нужна оценка для −y, а не для y.
  2. Умножаю неравенство 1 < y < 3 на −1 и переворачиваю знаки: −3 < −y < −1. Обрати внимание: границы поменялись местами, «−3» стала нижней.
  3. Теперь складываю два неравенства одного знака: 10 + (−3) < x − y < 12 + (−1).
  4. Считаю: 7 < x − y < 11.
7 < x − y < 11

Короткий вывод из этой цепочки: у разности нижняя граница = нижняя x минус верхняя y, а верхняя = верхняя x минус нижняя y. Границы вычитаемого идут «крест-накрест».

А если бы вычли почленно?

Получилось бы 10 − 1 < x − y < 12 − 3, то есть 9 < x − y < 9 — бессмыслица. Проверь подстановкой: при x = 10,5 и y = 2,5 разность равна 8, и она в «ответ» 9 < … < 9 не попадает. Значит, почленное вычитание — ошибка.

Наглядность

Площадная модель произведения

Пусть у прямоугольника сторона a лежит между 3 и 5, а сторона b — между 2 и 4. Самый маленький прямоугольник — 3 × 2 = 6, самый большой — 5 × 4 = 20. Площадь любого промежуточного прямоугольника зажата между ними.

b = 2b = 4
a = 33·2 = 63·4 = 12
a = 55·2 = 105·4 = 20

Для положительных чисел наименьшее всегда в углу «нижняя × нижняя», наибольшее — «верхняя × верхняя». Именно эту картинку и описывает правило умножения.

Мини-практика

7 < a < 9, 3 < b < 5 → оцени a + bприменение
Складываем нижние и верхние: 7 + 3 = 10, 9 + 5 = 14. Ответ: 10 < a + b < 14.
2 < p < 4, 6 < q < 10 → оцени p·qприменение
Все границы положительны — перемножать можно: 2·6 = 12, 4·10 = 40. Ответ: 12 < p·q < 40.
5 < a < 6 см, 8 < b < 9 см → оцени P = 2(a + b)применение
Сначала сумма: 13 < a + b < 15. Умножаем всё на 2 (число положительное, знак не меняется): 26 < P < 30 см.
Что изменится, если −5 < a < −3, а 2 < b < 4?анализ
Правило умножения тут не работает: границы a отрицательны. Механически вышло бы «−10 < a·b < −12» — нижняя граница больше верхней, бессмыслица. Считаем перебором четырёх крайних произведений: (−5)·2 = −10, (−5)·4 = −20, (−3)·2 = −6, (−3)·4 = −12. Наименьшее −20, наибольшее −6, значит −20 < a·b < −6. Причина поломки: у отрицательных чисел «больше по модулю» значит «меньше», и умножение на положительное b переворачивает порядок.
Найди ошибку: из 10 < x < 12 и 1 < y < 3 ученик написал 9 < x − y < 9анализ
Ошибка — почленное вычитание, так делать нельзя. Правильно: переворачиваем 1 < y < 3 в −3 < −y < −1 и складываем: 7 < x − y < 11.
Известно: 5 < a + b < 11 и 1 < b < 3. Что можно сказать про a?анализ
Замечаем, что a = (a + b) − b. Переворачиваем неравенство для b: −3 < −b < −1. Складываем: 5 + (−3) < a < 11 + (−1), то есть 2 < a < 10.

Тренажёр · бесконечная практика

Оцени выражение сам

Нажми «Новая задача». Ответ — пара границ. Записывай как угодно: 3; 8, 3 8, от 3 до 8 или 3<x<8. Минус пиши обычным дефисом.

Где чаще всего ошибаются

Лови эти четыре ловушки

  • Перемножают неравенства с отрицательными частями. Из −5 < a < −3 и 2 < b < 4 пишут «−10 < a·b < −12» — нижняя граница вышла больше верхней, это уже не неравенство. Проверяй перед умножением: все четыре числа положительны? Если нет — разбирай случаи, перебирая крайние произведения.
  • Вычитают неравенства почленно. Из a > b и c > d делают «a − c > b − d». Неверно. Вычитать и делить неравенства почленно нельзя: разность оценивают через переворот и сложение.
  • Складывают границы «крест-накрест». Берут нижнюю границу одного и верхнюю другого. Помни: нижняя граница суммы — сумма двух нижних, верхняя — сумма двух верхних. Крест-накрест идут только границы вычитаемого.
  • Забывают перевернуть знак. Умножая неравенство на −1, пишут «1 < −y < 3» вместо «−3 < −y < −1». При умножении или делении на отрицательное число знак всегда переворачивается.

Проверь себя без подглядывания

Три вопроса на понимание

Сформулируй правило сложения двух неравенств одного знакаобъясни
Если a > b и c > d, то a + c > b + d. То же для знака «меньше». Ограничений на знаки чисел нет.
При каком условии два неравенства можно почленно перемножать?объясни
Когда неравенства одного знака и все четыре числа положительны: из a > b > 0 и c > d > 0 следует a·c > b·d.
Дано 1 < a < 2 и 4 < b < 5. Оцени a + b и a·bприменение
5 < a + b < 7; всё положительно, поэтому 4 < a·b < 10.

Что дальше

Итог одним предложением: неравенства одного знака можно почленно складывать всегда, перемножать — только когда все части положительны, а вычитать и делить почленно нельзя.

системы неравенств

Дальше два неравенства будут стоять не рядом, а связкой «и»: нужно найти числа, которые подходят сразу обоим. Оценка выражений — прямая подготовка к этому.
