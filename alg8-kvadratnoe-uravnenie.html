Квадратное уравнение и его коэффициенты

Первый шаг ко всему большому блоку 8 класса — научиться узнавать уравнение с x² и правильно называть его три числа: a, b, c.

Где встречается. Пока ты решал линейные уравнения — там x только в первой степени. Но как только речь про площадь, про разгон, про полёт брошенного мяча — появляется x². Например: «площадь участка 60 м², а одна сторона на 4 м длиннее другой» сразу даёт уравнение со второй степенью.

Весь дальнейший блок (формула корней, теорема Виета, разложение на множители) стоит на одном простом умении: узнать квадратное уравнение и верно назвать коэффициенты. С этого и начнём.

Суть простыми словами

Квадратное уравнение — это уравнение, где неизвестное стоит в квадрате (во второй степени), и эта вторая степень реально есть, не сокращается. Словами: «что-то, умноженное на x², плюс что-то, умноженное на x, плюс число равно нулю».

Три числа a, b, c полностью задают такое уравнение: зная их, потом найдёшь корни по готовой формуле. Поэтому твой первый навык — безошибочно вытащить эти три числа из любой записи.

Главный миф: «раз в записи есть x² — значит уравнение уже квадратное, читай коэффициенты как есть». Нет! Сначала уравнение приводят к стандартному виду — иначе коэффициенты выйдут неправильные.

Стандартный вид и три коэффициента

ax² + bx + c = 0
обязательное условие: a ≠ 0 (иначе x² исчезает и уравнение становится линейным)
a

Старший

Стоит при x². Обязан быть не нулём. Если a = 1 — уравнение называют приведённым.

b

Второй

Стоит при x (первой степени). Если члена с x нет — значит b = 0, а не «нет».

c

Свободный

Число без x. Если числа нет — c = 0.

Два железных правила:

1. Коэффициент берётся вместе со своим знаком. Стоит перед членом минус — коэффициент отрицательный.

2. Сначала приведи к стандартному виду ax² + bx + c = 0: перенеси всё влево (чтобы справа был 0), раскрой скобки, приведи подобные и упорядочь по убыванию степени. И только потом читай a, b, c.

2x² − 7x + 3 = 0
a = 2 b = −7 c = 3

Разбор по шагам — думаю вслух

Классическая ловушка: уравнение записано не в стандартном виде. Смотри, как привести его к порядку.

Назвать коэффициенты уравнения 5x − 3x² = 2

  1. Переносим всё влево, чтобы справа остался 0: 5x − 3x² − 2 = 0. Коэффициенты читают только из вида ax² + bx + c = 0.
  2. Упорядочиваем по убыванию степени — сначала x², потом x, потом число: −3x² + 5x − 2 = 0. Иначе легко перепутать a и b.
  3. Читаем со знаками: a = −3, b = 5, c = −2. Минус перед 3x² и перед 2 относится к самим коэффициентам.
Ответ: a = −3, b = 5, c = −2. Уравнение квадратное, ведь a = −3 ≠ 0.

А если есть скобки — сперва их раскрывают:

Привести к виду и назвать a, b, c: (x − 4)(x + 1) = 6

  1. Раскрываем скобки: x² + x − 4x − 4 = 6, приводим подобные: x² − 3x − 4 = 6.
  2. Переносим 6 влево (меняет знак): x² − 3x − 10 = 0.
  3. Читаем: a = 1, b = −3, c = −10.
Ответ: a = 1, b = −3, c = −10.

А если члена не хватает? В 2x² − 7 = 0 нет члена с x — значит b = 0. Полный ответ: a = 2, b = 0, c = −7. «Нет члена» = коэффициент ноль.

Тренажёр · приведи и назови a, b, c

Нажимай «Новое», приводи уравнение к стандартному виду в уме или на черновике и вписывай три коэффициента со знаками. Проверь себя или посмотри пошаговое решение.

5x − 3x² − 2 = 0

Приведи к виду ax² + bx + c = 0 и назови коэффициенты

Проверь себя

1) Назови a, b, c для 7x² − 3 = 0.
Члена с x нет → b = 0. Значит a = 7, b = 0, c = −3. Не забывай про нулевой b.
2) Выпиши только квадратные: а) 3x² − x = 0; б) 5x + 2 = 0; в) x³ − 1 = 0; г) 7x² = 0.
Квадратные — а и г: есть вторая степень и a ≠ 0. б — линейное (нет x²), в — третья степень (x³).
3) Найди ошибку: для 1 − 2x² + x = 0 ученик написал a = 1, b = −2, c = 1.
Он не упорядочил по степеням. Правильно: −2x² + x + 1 = 0 → a = −2, b = 1, c = 1. Число 1 — это свободный член c, а не старший коэффициент.
4) Обратная задача: придумай уравнение с a = 1, b = 0, c = −16.
x² − 16 = 0. Член с x отсутствует (b = 0), число −16 — свободный член.
5) Назови a, b, c для 2x − x² + 5 = 0.
Упорядочим: −x² + 2x + 5 = 0 → a = −1, b = 2, c = 5. Перед x² стоит минус, значит a = −1.

Ловушки

  • Теряют знак коэффициента. В −3x² + 5x − 2 = 0 пишут a = 3 вместо a = −3. Коэффициент берётся вместе со знаком перед членом.
  • Не приводят к стандартному виду. Для 5x − 3x² = 2 читают коэффициенты прямо из этой записи. Сначала перенеси всё влево и упорядочь по степеням.
  • Считают, что отсутствующего коэффициента «нет». В x² − 9 = 0 забывают про b. У пропущенного члена коэффициент b = 0.
  • Путают a, b, c местами. Записывают члены не по убыванию степени и приписывают a свободному числу. Всегда порядок: x², затем x, затем число.
  • Забывают условие a ≠ 0. Если после упрощения x² сократился и a = 0 — уравнение уже не квадратное, а линейное.

Запомни главное

ax² + bx + c = 0,  a ≠ 0

Чтобы назвать коэффициенты, сначала приведи уравнение к стандартному виду (всё влево, по убыванию степени), а потом прочитай числа при x², при x и свободный член — вместе с их знаками. Нет члена — его коэффициент 0.

👉 Дальше — неполные квадратные уравнения (когда b = 0 или c = 0, их решают проще), а затем формула корней через дискриминант, где эти самые a, b, c и пойдут в дело.
